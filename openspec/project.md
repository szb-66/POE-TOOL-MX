# Project Context

## Purpose
流放助手是一个为《Path of Exile》（流放之路）游戏开发的桌面辅助工具，主要用于自动制作游戏内物品和地图。通过Python脚本实现游戏界面的自动化操作，提供可视化配置界面，帮助玩家高效完成重复性的游戏任务。

### 核心功能
- **物品制作**：支持改造石、混沌石、点金石三种制作模式，自动匹配词缀和插槽要求
- **地图制作**：支持点金石和混沌石模式，自动处理地图稀有度、品质和词缀匹配，可选自动存入符合条件的地图
- **背包自动入库**：自动将背包（道具）物品存入仓库；支持可视化排除指定格子和原生背包左侧 1–6 列额外背包，先按列扫描原生 12×5 格，未提前结束时再从最左额外列向原生方向扫描
- **战斗辅助**：通过生命/魔力像素颜色自动触发药剂，支持持续回复与立即回复，并提供可配置的一键回城流程
- **覆盖层显示**：提供透明覆盖层，实时显示制作进度、物品信息和操作日志
- **预设管理**：支持多预设配置，方便切换不同制作方案
- **设置中心**：全局快捷键、通货坐标、操作延迟等配置
- **商城功能**：预留商城功能界面，为未来功能扩展做准备

## Domain Context
### 游戏机制理解
#### 物品制作系统
- **稀有度**：普通(0词缀) → 魔法(1-2词缀) → 稀有(3-6词缀)
- **通货类型**：
  - 改造石：重置魔法物品词缀
  - 混沌石：重置稀有物品词缀
  - 点金石：普通物品升级为稀有
  - 增幅石：魔法物品新增一个随机词缀
  - 崇高石：用一个新随机词缀强化一个稀有物品
  - 重铸石：将一件物品上的所有属性删除，变回普通物品
  - 链结石：重置一件物品上插槽的连接
  - 瓦尔宝珠：腐化一件装备有概率随机修改其属性
  - 蜕变石：将一件普通物品升级成魔法物品
  - 幻色石：重置一件物品上插槽的颜色
  - 知识卷轴：鉴定一件指定物品
  - 富豪石：将一件魔法物品升级成稀有物品
  - 工匠石：重置一件物品上插槽的数量
- **物品词缀**：魔法物品最多一条随机前缀和一条随机后缀；稀有物品通常最多三前缀三后缀。固定词缀不占随机前后缀上限，复合词缀可包含多条效果，物品等级会限制可出现的词缀等阶。参考：https://poedb.tw/cn/Modifiers
- **制作模式**：改造模式、混沌模式、点金模式

#### 地图系统
- **地图阶级**：1-17级，不同阶级有不同属性上限
- **地图品质**：0-20
- **地图基底**：物品数量、物品稀有度、怪物群大小、更多地图、更多圣甲虫、更多通货，具体数值与地图品质和外延词缀的数量正相关
- **地图外延词缀**：对地图内全局debuff或怪物状态的描述，正常制作最多6条，瓦尔宝珠有概率点出8条词缀
- **稀有度**：普通、魔法、稀有、传奇（无法修改）
- **特殊状态**：已腐化（无法修改）
- **制作模式**：点金模式、混沌模式

#### 游戏内操作
- **移动鼠标**：直接移动鼠标到指定坐标
- **通货使用方式**：右键点击通货 → 左键点击目标物品
- **复制物品信息**：将鼠标悬停至物品位置 - `Ctrl + C` - 复制物品信息到剪贴板
- **背包物品转移到仓库**：ctrl+左键点击背包物品 → 被点击物品存入仓库

### 物品制作流程

#### 改造石模式（重置魔法物品词缀）
1. **物品检查**：检测物品稀有度和特殊状态
2. **预处理**：
   - 确保物品为魔法物品
   - 普通物品：使用蜕变石 → 魔法品质
   - 稀有物品：使用重铸石 → 普通品质 → 蜕变石 → 魔法品质
   - 传奇物品：跳过（无法修改）
   - 已腐化物品：跳过（无法修改）
3. **词缀匹配**：检查剪贴板词缀是否满足必选和挑选条件
4. **插槽处理**：词缀匹配成功后，检查插槽要求
5. **辅助石处理**（可选）：
   - 增幅石：可在只有一条词缀的魔法物品上添加一条随机词缀
   - 富豪石：可以给魔法物品提升稀有度，并添加一条随机词缀
6. **循环处理**：
   - 使用改造石重置词缀
   - 复制物品信息到剪贴板
   - 检查词缀是否满足要求
   - 不满足则继续循环

#### 混沌石模式（重置稀有物品词缀）
1. **物品检查**：检测物品稀有度和特殊状态
2. **预处理**：
   - 确保物品为稀有物品
   - 普通物品：使用点金石 → 稀有稀有度
   - 魔法物品：使用重铸石 → 普通稀有度 → 点金石 → 稀有稀有度
   - 传奇物品：跳过（无法修改）
   - 已腐化物品：跳过（无法修改）
3. **词缀匹配**：检查词缀是否满足必选和挑选条件
4. **插槽处理**：词缀匹配成功后，检查插槽要求
5. **辅助石处理**（可选）：
   - 崇高石：可在词缀重置后，给魔法物品提升稀有度，并添加一条随机词缀，注意变成稀有稀有度后如果重新循环的话需要先进行预处理
6. **循环处理**：
   - 使用混沌石重置词缀
   - 复制物品信息到剪贴板
   - 检查词缀是否满足要求
   - 不满足则继续循环

#### 点金石模式（通过清空物品词缀再一次性添加3-6个物品词缀的方式达到洗词缀的效果）
1. **物品检查**：检测物品稀有度和特殊状态
2. **预处理**：
   - 确保物品为普通物品
   - 魔法物品：使用重铸石 → 普通稀有度
   - 稀有物品：使用重铸石 → 普通稀有度
   - 传奇物品：跳过（无法修改）
   - 已腐化物品：跳过（无法修改）
3. **词缀匹配**：检查词缀是否满足必选和挑选条件
4. **插槽处理**：词缀匹配成功后，检查插槽要求
5. **循环处理**：
   - 使用点金石升级稀有度
   - 复制物品信息到剪贴板
   - 检查词缀是否满足要求
   - 不满足则继续循环

#### 插槽制作流程
1. **开孔处理**：
   - 使用工匠石随机重置插槽数量
   - 检查插槽数量是否满足要求
   - 不满足则继续循环

2. **链接处理**：
   - 使用链结石随机重置插槽连接
   - 检查连接数量是否满足要求
   - 不满足则继续循环

3. **颜色处理**：
   - 使用幻色石随机重置插槽颜色
   - 检查各颜色数量是否满足要求
   - 不满足则继续循环

### 地图制作流程

#### 点金模式
1. **地图检查**：检测地图稀有度和特殊状态
2. **预处理**：
   - 确保地图为普通地图
   - 跳过已腐化地图、传奇地图
   - 魔法地图：使用重铸石 → 普通地图
   - 稀有地图：跳过（点金模式不处理稀有地图）

3. **地图稀有度升级**：
   - 使用点金石将普通地图升级为稀有地图

4. **地图基底检查**：
   - 复制地图信息到剪贴板
   - 检查基底词缀是否满足必选和挑选条件
   - 基底数值满足条件后进行外延词缀检查

5. **外延词缀检查**：
   - 复制地图信息到剪贴板
   - 检查地图外延词缀是否满足黑名单、白名单条件

6. **循环处理流程**：
     - 使用点金石将普通地图升级为稀有地图
      - 复制地图信息到剪贴板（Ctrl+C）
     - 检查地图基底词缀数值是否满足数量要求
     - 基底满足后检查外延词缀的黑白名单
     - 不满足则使用重铸石 → 点金石重新制作

7. **瓦尔宝珠处理**（可选）：
   - 词缀满足后，检查是否启用瓦尔宝珠
   - 使用瓦尔宝珠腐化地图
   - 重新检查词缀（腐化可能改变词缀）

8. **存储处理**：
   - 满足条件则按Ctrl+左键存入仓库
   - 不满足则留在原位置继续下一张地图

#### 混沌模式
1. **地图检查**：检测地图稀有度和特殊状态
2. **预处理**：
   - 确保地图为稀有地图
   - 跳过已腐化地图、传奇地图
   - 普通地图：使用点金石 → 稀有地图
   - 魔法地图：使用重铸石 → 普通地图 → 点金石 → 稀有地图

3. **地图基底检查**：
   - 复制地图信息到剪贴板
   - 检查基底词缀是否满足必选和挑选条件
   - 基底数值满足条件后进行外延词缀检查

5. **外延词缀检查**：
   - 复制地图信息到剪贴板
   - 检查地图外延词缀是否满足黑名单、白名单条件

6. **循环处理流程**：
   - 使用混沌石重置地图词缀
   - 复制地图信息到剪贴板
   - 检查地图基底词缀数值是否满足数量要求
   - 基底满足后检查外延词缀的黑白名单
   - 不满足则继续使用混沌石重置地图词缀

5. **瓦尔宝珠处理**（可选）：
   - 词缀满足后，检查是否启用瓦尔宝珠
   - 使用瓦尔宝珠腐化地图
   - 重新检查词缀

6. **存储处理**：
   - 满足条件则存入仓库
   - 不满足则留在原位置继续下一张地图

#### 统一地图基底模式
- 所有地图统一配置物品数量、物品稀有度、怪物群大小、更多地图、更多圣甲虫、更多通货六项基底
- 地图文本缺失的基底字段按0处理，系统不再保存或选择普通/高级地图类型
- 点金石或混沌石仍由用户根据地图情况手动选择
