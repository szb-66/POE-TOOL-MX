# Design

## Context

沿用现有国际服独立用户目录、Electron IPC门禁与阿里云反馈后台管理员认证。两个仓库均有已存在的未提交工作。动机见 proposal.md。

## Goals / Non-Goals

支持当前 Windows x64 Steam，以本地官方繁体为底、官方简体按条目覆盖。首期通过现有 SSH 隧道验收，不打包助手安装程序，不自动抓取游戏或联网更新，不迁移市场及开放未验证自动化。

## Decisions

- 原生 helper 固定 LibBundle3 2.7.5 commit 50c2d279b3806366f79e831acc1c03bc35bb6442，.NET 8自包含；JSONL protocolVersion=1。资源仅包含数据，解析引擎不热更。
- 表格按 table/id/field，词缀按 stat序列和变体匹配，源英文SHA256及结构不一致则回退。只替换可验证文本，不用行号进行跨服配对。
- 服务端协议为 entries 数组、按表隔离且每表16个稳定key哈希桶、gzip对象、SHA256内容寻址、Ed25519 canonical JSON签名。客户端只读取完整验签激活版本，整张名称表补齐不会导致未变化词缀表重新下载。
- 主进程组织扫描和资源缓存，独立helper负责读取、暂存、校验、事务提交和同版恢复。原版基线必须有Steam校验证据，baselineConfirmed不能单独绕过验证。
- 后台存储在独立持久资源目录，PostgreSQL存发布元数据，Nginx直接缓存分发对象。服务器先落齐对象再切频道；资源回退不覆盖不可变对象。
- 混合语言查价在国际服输入边界还原英文和国际交易标识，保留精确原文和未知诊断，不更改共享国服解析规则。

## Risks / Trade-offs

- 当前 DATc64和压缩依赖尚未实测：先完成真实资源解析/往返闸门，失败不得产生游戏写入或声称已验收。
- 官方译文滞后、结构变化：保留繁体/英文并展示覆盖统计，原生格式变化仍可能需要升级助手。
- 其他补丁污染、Steam更新竞争：完整性校验建立基线，写前重新检查版本/指纹，事务日志和同版本还原。
- 资源路径遍历和解压膨胀：固定哈希路径、数据结构白名单、长度/计数/解压上限。

## Migration Plan

先开发版和受影响测试，再全量回归、内部服务部署及本机 Steam 实测。无公网入口改动。恢复服务端频道不影响软件版本；游戏恢复只用同版本原索引。公开依赖来源与许可说明，临时测试移回收站。
