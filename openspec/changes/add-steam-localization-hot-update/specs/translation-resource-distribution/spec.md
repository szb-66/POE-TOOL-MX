# Spec Delta

## Purpose

将官方语言资源的提取、校验和发布独立于助手软件版本，通过管理后台维护可信翻译数据，以内容寻址的增量对象减少重复下载，并在网络或校验失败时保留已有可用资源。

## ADDED Requirements

### Requirement: 官方语言导出与受权发布
系统 SHALL 支持维护者从本机游戏资源导出带版本和结构信息的纯数据包，后台管理员校验后发布及回退，MUST NOT 导出账号或会话凭据。

#### Scenario: 导入非法资源
- **WHEN** 数据存在重复标识、无效结构或超限内容
- **THEN** 拒绝导入且活动版本保持不变

### Requirement: 内容寻址增量分发
系统 SHALL 发布签名清单和不可变哈希对象，客户端 MUST 仅下载缺少或损坏的对象，使用本地当前游戏生成补丁而非下载整份游戏索引。

#### Scenario: 跳版本与单块变化
- **WHEN** 最新清单中只有一个对象未命中本地缓存
- **THEN** 只下载该对象，不要求先安装中间版本

### Requirement: 资源校验与原子激活
系统 MUST 校验清单签名、引擎协议、对象大小、哈希和解压上限，全部成功后才激活资源；热更新 MUST NOT 下发执行代码或替换原生引擎。

#### Scenario: 下载中断或签名错误
- **WHEN** 候选版本缺少对象或验证失败
- **THEN** 保留原活动版本并允许再次手动下载
