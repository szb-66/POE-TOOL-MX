## ADDED Requirements

### Requirement: 批次中间完成不得关闭制作浮窗
系统 SHALL 在单件完成、首次识别即达标以及切换下一件期间持续显示制作浮窗并更新批次进度。系统 MUST 等整个批次完成后才展示流程完成状态；事件分块或合并传输 MUST NOT 改变结果。

#### Scenario: 连续制作两件
- **WHEN** 第一件完成并自动点击第二件
- **THEN** 浮窗保持显示，进度更新到第二件，外部点击关闭未启用

#### Scenario: 完成事件分块传输
- **WHEN** 批次结束事件跨多次输出传输或与其他日志一起传输
- **THEN** 完整接收后才进入完成状态，单件日志不造成提前完成
