## ADDED Requirements

### Requirement: 物品制作浮窗按流程级结果进入完成状态
系统 MUST 仅在物品制作流程整体完成后进入完成状态并启用外部点击关闭。阶段或单件的完成日志、单件属性达标 MUST NOT 表示流程完成。异常停止和主动停止 MUST 保持停止状态；重新启动或续作 MUST 解除外部点击关闭。

#### Scenario: 阶段完成仍有后续工作
- **WHEN** 词缀或插槽阶段达标但仍有制作步骤
- **THEN** 浮窗保持运行态，游戏点击不会关闭浮窗

#### Scenario: 流程结束
- **WHEN** 收到完整的流程完成结果
- **THEN** 浮窗显示完成状态，点击外部可关闭浮窗

#### Scenario: 达标后异常停止
- **WHEN** 已有单件达标但流程异常或主动停止
- **THEN** 浮窗显示停止状态且不启用外部点击关闭

#### Scenario: 重新启动
- **WHEN** 用户重新开始或继续批量制作
- **THEN** 浮窗解除外部点击关闭并恢复运行态
