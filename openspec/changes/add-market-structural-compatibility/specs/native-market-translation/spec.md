# Spec Delta

## Purpose

为 Windows x64 Steam 国际服的原生市集提供可核实的简繁文字替换与查询名称还原，在游戏小更新后复用仍兼容的组件和词库，并在关键结构或来源无法确认时停止翻译和明确提示，保留游戏原有交易身份与条件。

## ADDED Requirements

### Requirement: 按已验收结构判断市集兼容性

系统 SHALL 根据已验收 ABI 基准的关键完整函数、可靠函数边界、字段读取上下文、调用目标和字段键判断当前客户端兼容性。系统 MUST NOT 仅因 BuildID、完整 EXE 哈希或 PE 时间戳不同而拒绝，也 MUST NOT 仅凭短前导相同或固定地址增量启用。

#### Scenario: 小更新保留全部关键代码
- **WHEN** 游戏版本信息或非关键区域发生变化，但所有关键完整正文与字段读取关系可唯一核实
- **THEN** 系统允许当前游戏使用兼容组件，并保留实际目标身份用于状态核验

#### Scenario: 关键正文或调用关系发生变化
- **WHEN** 任一关键完整正文、函数边界、字段键或调用目标不符合基准
- **THEN** 系统停止启用并提示结构无法确认兼容及需要等待适配

#### Scenario: 指纹不存在或出现多个候选
- **WHEN** 任一关键指纹没有唯一候选
- **THEN** 系统拒绝选择地址，不猜测最接近的版本或位置

### Requirement: 启用前执行独立的目标核验

系统 MUST 在控制端及游戏内组件分别核验当前目标结构，并检查 PE 边界、节权限和重定位保护范围。目标路径、受管索引、未完成事务、进程与管道身份或第三方 Hook 检查失败时 MUST NOT 启用翻译。渲染进程 MUST NOT 指定任意 PID、DLL 或挂钩地址。

#### Scenario: 文件通过但内存结构不一致
- **WHEN** 磁盘兼容性检查通过，但游戏内实际映像不能独立通过相同基准
- **THEN** 组件保持原调用，控制端报告失败，不将组件加载计为启用成功

#### Scenario: 游戏处于未完成汉化事务
- **WHEN** 当前资源状态未验证或存在未完成事务
- **THEN** 系统暂停市集翻译并提示先完成受管语言操作

### Requirement: 按精确原文复用市集词库

系统 SHALL 将词库的 Build、EXE 哈希和汉化发布版本保留为来源记录，允许在已确认兼容的目标版本复用。动态物品和词缀 MUST 具备可靠的精确法语原文；词缀还 MUST 匹配稳定交易 ID。没有可靠证据或当前原文不同的条目 MUST 保留原文，MUST NOT 仅按旧 ID 猜译。

#### Scenario: 新版本原文保持不变
- **WHEN** 当前目标结构兼容且条目的原文、稳定身份与已验证词库相符
- **THEN** 系统复用该译文，无需维护者为相同内容重新上传词库

#### Scenario: 同一交易ID的原文发生变化
- **WHEN** 当前显示原文不等于候选规则记录的精确原文
- **THEN** 该条目保持当前原文，不借用同 ID 的其它变体译文

#### Scenario: 固定分类及筛选元数据
- **WHEN** 条目属于明确列出的二十个固定分类标签或受所属筛选字段限制的稳定选项
- **THEN** 系统仅在其固定身份和字段范围内使用既有译文，不开放任意无原文的动态规则

#### Scenario: 官方交易词缀提供完整英法原文
- **WHEN** 同一官方交易ID的英文模板与已知翻译语义完全相符，法语原文及参数证据可靠
- **THEN** 生成器绑定准确ID与精确法语source，并记录英法快照URL、UTC时间及原始字节哈希

#### Scenario: 官方英文语义漂移或身份有歧义
- **WHEN** 同一交易ID的官方英文已改变，或同一ID存在无法区分的多种官方英文
- **THEN** 生成器跳过该候选，不能用旧本地CSD模板绕过本次语义核对

#### Scenario: 官方综合词缀的数字参数拼写不同
- **WHEN** 已核实官方词缀使用X而不是#表示数字参数
- **THEN** 生成器仅允许维护表中的准确ID、准确英文及准确法语全文组合，不对未知X文本做全局通配

#### Scenario: 综合词缀完整覆盖审计
- **WHEN** 为当前官方综合词缀生成或发布修复目录
- **THEN** 验证全部298项的精确法语原文均有简体规则，逐项输出简繁缺失原因，不以局部截图通过替代完整覆盖，也不猜测缺少的繁体译文

### Requirement: 不兼容时停止并保留用户偏好

系统 SHALL 保留用户的市集开关选择。无法确认兼容、运行期间目标发生变化或检测到冲突时 MUST 停止当前会话、返回原调用并显示具体原因；MUST NOT 在同一失败 PID 上反复尝试注入。未知条目的正常原文回退 MUST NOT 被误报为整个组件不兼容。

#### Scenario: 小更新不受支持
- **WHEN** 自动监听的新游戏无法证明结构兼容
- **THEN** 开关偏好保留，当前翻译不启用，错误提示持续至状态改变或用户处理

#### Scenario: 当前游戏已初始化相同配置
- **WHEN** 用户保持游戏运行并重启助手，游戏中的同路径组件保留相同语言和完整规则
- **THEN** 系统允许核验后接回会话，不重新注入或改变当前配置

### Requirement: 保留查询身份及可追溯来源

系统 MUST 只替换展示文字及已知物品名称的精确反向映射，保留交易 ID、选项值、数值和查询结构。物品反查 MUST 以本会话实际观察到与规则完全相同的原文为前提；仅存在于离线词库的名称 MUST NOT 自动获得反查资格。词库生成 MUST 记录官方来源指纹及覆盖报告，缺少可靠原文的候选 MUST 明确统计；静态检查、模拟回归与真实显示或查询验收 MUST 分别记录。

#### Scenario: 物品法语原文已发生变化
- **WHEN** 当前目录展示原文不同于离线规则，或当前会话没有实际观察到该规则的精确物品原文
- **THEN** 不建立对应中文名称的反查映射，不把名称还原成旧词库的法语原文

#### Scenario: 官方接口不可读取
- **WHEN** 官方法语接口不可用，但本地官方数据存在可核实的同形英法模板
- **THEN** 系统可使用本地证据生成候选并记录来源，无法核实的汇总条目保留原文，不宣称完整覆盖

#### Scenario: 未验证在线搜索
- **WHEN** 本轮只完成结构检查和真实中文显示
- **THEN** 验收记录明确在线搜索仍未重复验证，不将显示替换计数作为查询成功证据

### Requirement: 变异宝石完整名保留基础查询身份

系统 SHALL 为能由官方英法items快照、可靠基础EN→FR类型和已验签完整英文名证明的变异宝石生成items/text简繁规则。配对 MUST 限定gem组、基础类型和discriminator，且双边唯一；MUST NOT 按数组位置或仅凭discriminator猜测。完整变异名 MUST 只反查term，type.option MUST 继续使用基础名并保留discriminator、数值及其余查询键值。itemsComplete MUST 同时要求可靠的变异完整text，不能仅以基础类型已翻译计为完整。

#### Scenario: 完整中文变异名检索
- **WHEN** 官方法语完整变异名与已证实规则精确匹配，用户输入对应中文名
- **THEN** 市集可显示该完整中文候选，选择后查询基础类型还原为法语，discriminator保留原值

#### Scenario: 瓦尔复合候选名称
- **WHEN** 官方英文明确是基础名与变异名的括号组合，两个中文部分均有可靠译文
- **THEN** 系统生成中文完整组合，法语source仍使用官方完整text，不能通过拼接猜测法语大小写或全文

#### Scenario: 变异配对缺失或存在歧义
- **WHEN** 缺少可靠法语来源、基础类型不符、双边配对重复、英文变化、discriminator不符或受管译文有歧义
- **THEN** 系统保守跳过对应条目或语言，并在覆盖报告记录原因

#### Scenario: 官方条目先于旧国际列表
- **WHEN** 新官方变异项尚未收录在旧国际列表，但双语身份与已验签英文名称、译文均可核实
- **THEN** 系统允许生成可靠规则，只有繁体译文时保留既有简体到繁体回退，不猜测缺失简体译文
