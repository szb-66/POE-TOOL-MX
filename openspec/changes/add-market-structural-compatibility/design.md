# Design

## Context

现有市集目录、host、DLL 和构建输出绑定 Build `26694821` 的精确 EXE。磁盘验证只使用四个函数前导和十二个调用点；三个筛选作用域地址已由兼容资料生成。现有目录中的动态词缀主要只按交易 ID 匹配，不能据此直接放开跨版本词库。动机见 proposal.md。

## Goals / Non-Goals

**Goals:**
- 仅自动接受关键完整代码与已验收基准一致的目标，允许版本元数据及可独立核实的位置变化。
- 将组件结构证据、词库原文证据与当前受管游戏状态分开核验，任一必要证据失败即关闭。

**Non-Goals:**
- 不分析未知指令语义，不为关键正文变化自动生成新 ABI，不承诺全部小更新兼容。
- 不修改交易 ID、价格、筛选数值或游戏资源备份事务，不发起交易。
- 不把模拟版本或离线覆盖当成未来版本的真实游戏验收。

## Decisions

### 七个完整函数证明基准ABI

兼容资料增加 `structureVersion: 1`、固定 ABI 家族，以及 lookup、searchBuilder、stringCtor、stringDtor、itemsReader、statsReader、filtersReader 的完整正文长度与 SHA-256。先以长前导在代码节中唯一定位，再核实异常目录中的函数入口、完整长度和完整正文。十二个完整上下文必须位于各自 reader，CALL 指向已解析 lookup，LEA 取得对应只读字段键；关键范围不得覆盖 ASLR 重定位。

不采用“去掉哈希检查”或仅匹配短前导，也不通配相对位移。完整正文任何字节变化都要求重新适配。这会保守拒绝部分实际可用的小更新，但避免把陌生调用关系或数据布局判为兼容。

### 磁盘与内存独立核验

C# host 解析当前磁盘 PE，DLL 在挂钩前独立核验内存映像和相同基准；二者不信任渲染进程提供的地址。仍核对 Steam 安装、当前 Build 对应的受管索引、事务日志、进程和管道身份，并拒绝已有第三方 Hook。配置变化及停止继续使用现有会话清理机制。

解析结果以 `referenceValidatedInGame` 追溯基准验收，以 `structurallyCompatible` 表达当前结构检查；目标哈希不同于基准时，目标的 `validatedInGame` 为 `false`。这避免把自动结构判断当成新版本已完成真实游戏验收。

### 词库版本为来源，原文为使用条件

客户端继续核实组件、基准兼容资料和目录来源完整性，但不以目录来源 Build 或汉化 release 与目标不同为唯一拒绝理由。动态 stats/items 必须有精确法语 `source`；stats 同时保留交易 ID。原生匹配时要求当前文字与来源完全一致。

二十个既有 stats/items 分类 label 采用共享精确白名单；固定筛选字段和选项继续使用明确 scope/ID，不能推广为任意动态无原文规则。未知动态条目透传当前文字。查询只精确还原当前会话实际观察到相同物品原文的名称，不能仅凭离线规则开放反查；数值和 ID 不变。

### 官方交易快照与本地官方模板共同提供原文证据

最初直接访问法语接口返回403，后续正常浏览器成功读取英法官方交易stats API，没有绕过验证。原始快照以gzip维护，来源清单保留URL、UTC记录时间及解压后字节SHA-256。生成前校验哈希，以同一官方交易ID对照当前英文模板；当前英文改变或存在同ID多种英文时，不用旧CSD证据恢复译文。英法来源与参数可核实时，生成精确API法语source。

本地四十八张CSD的26,090个同形English/French模板继续作为独立原文变体证据，每个表保留内容哈希。完整审计全部298项综合词缀后，确认24项官方综合词缀用`+X`代替`+#`：Mana/ES两项及插槽宝石等级22项。准确ID、准确EN全文和准确FR全文维护在独立对照表，并记录官方来源哈希；只在三者同时符合时接受，不做全局X通配。最初截图24项已核对术语在准确英文匹配时优先于同义CSD译文，避免表述差异造成误判。

最新修复候选34,092条规则，简体词缀11,453、繁体8,960；全部298项官方综合词缀均绑定精确法语原文及简体译文，繁体覆盖52项、其余246项缺少可靠繁体译文。审计脚本逐项记录ID、原文及简繁缺失原因，发布目录测试要求298项简体完整覆盖。全目录仍有1,046个原可翻译候选缺少可靠来源，另有391个英文漂移模板被拦下，生成报告明确保留这些统计；这不是组件结构校验失败。来源版号仍追溯已验签基准，不将新快照或模拟小更新计为目标实机验收。

### 变异宝石完整候选名与查询身份分开

用户发现“远程之幻化武器”完整中文名没有市集候选。基础items/type已有译文，但不同discriminator的完整items/text未生成；仅翻译基础类型不能覆盖变异名检索。

持久保存官方英法items原始gzip快照及URL、UTC记录时间、字节哈希。配对限定gem组，先按官方本地表身份及准确英文核实基础EN→FR类型，再按基础类型与discriminator建立双边唯一关系；禁止数组位置或仅disc配对。完整英文必须精确命中受管activeskills.DisplayedName或gemeffects.Name，译文歧义按语言拒绝。官方英文明确构成基础名与变异名的括号组合时，才用可靠中文部分组合瓦尔候选；法语始终取官方完整text。

完整变异名仅反查term；type.option仍还原基础法语名，并保留discriminator与数值等其他字段。已验签名称足以证明新官方条目时，不因旧国际列表尚未收录而拒绝。当前265个官方变异项全部生成，含50个瓦尔组合；263项有简体、265项有繁体，Fireball of Radiation及其瓦尔项缺简体时使用已有繁体回退。覆盖报告区分官方数量、当前列表数量、匹配及跳过原因；itemsComplete必须同时满足可靠变异完整text，避免基础名掩盖漏译。

## Risks / Trade-offs

- [关键代码未变但相对位移字节变化] → 保守拒绝并提示适配，不在用户机器上猜测新指令。
- [源文件与运行映像不一致] → 控制端和 DLL 双重核验，保留实际目标文件身份检查。
- [跨版本交易ID语义漂移] → 动态规则同时匹配精确原文，缺证据不翻译。
- [原文约束降低覆盖率] → 记录缺少来源数量并保留原文，后续获得官方原文证据后再补齐。
- [游戏已缓存旧目录] → 同配置接续沿用原规则，更新 DLL 或目录后完整重启游戏。

## Migration Plan

1. 在隔离构建目录重建原生组件并执行结构和词库专项回归。
2. 用户正常退出游戏及持有旧 DLL 的助手后，整体更新组件、兼容资料、分发元数据和目录。
3. 启动助手后再启动新游戏，验证中文显示、停止和正常开关接管；真实查询单独记录。
4. 若出现未确认结构，保持停用与提示；回退必须整体恢复同代组件和目录，并完整重启游戏。
