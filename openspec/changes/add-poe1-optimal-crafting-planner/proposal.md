## Why

当前物品功能只能按用户预先配置的条件自动洗装，无法根据底材、词缀权重、工艺规则和国服价格比较多条制作策略。新增本地做装规划器后，用户可以从目标装备反推一条可解释、可估价且能随赛季数据更新的低成本制作路径。

## What Changes

- 新增独立侧栏入口“做装规划”，保留现有物品自动制作页面。
- 提供按“大类 → 物品类型 → 底材”分层的 POE1 中文底材目录，支持武器、护甲、首饰、普通珠宝和星团珠宝，以及合法的势力、破裂、追忆和异能起始状态。
- 提供按底材和物品等级过滤的中文词缀搜索，用户可为每条目标设置最低 T 级及天然、工艺台或任一来源；所有目标必须同时满足。
- 使用普通核心通货、元工艺、工艺台和与显式词缀相关的花园工艺生成候选策略，并按期望耗材成本排名。
- 展示一条推荐路径和两条备选路径，包括步骤、失败分支、成功率、期望尝试次数、资源明细、风险分位与置信区间。
- 内置一份可离线使用的数据快照，并提供带校验、原子切换和回滚的 POEDB 手动更新机制。
- 接入 poecurrency.top 的 POE1 当前赛季公开均价；异常或缺失价格允许本地覆盖，底材成本不计入结果。
- 提供数据源、工艺动作和策略模板扩展接口，为后续精髓、化石、隐匿等工艺预留能力。

## Capabilities

### New Capabilities

- `crafting-data-catalog`: 管理底材、词缀、工艺定义、赛季清单、离线快照与纯文字手动更新。
- `crafting-cost-pricing`: 获取、校验、缓存并覆盖国服耗材价格，将多种计价单位统一为混沌石成本。
- `crafting-path-optimization`: 校验做装目标、生成并模拟受支持的候选策略，持续返回快速与精算后的前三条路径。

### Modified Capabilities

无。

## Impact

- 前端新增路由、侧栏项、做装规划页面、状态管理和结果展示组件。
- Electron 主进程新增文字数据更新、价格访问、规划任务与进度事件 IPC；重计算在 Worker Thread 中执行。
- 新增可版本化的数据快照、POEDB HTML 解析与构建时数据生成脚本，并增加 HTML 解析依赖。
- 新增规划领域模型、工艺 Provider 注册表、策略模板、概率模拟器及相关单元/集成测试。
- 外部依赖为 POEDB 页面和 poecurrency.top 公开 API；该能力按个人非商业、简体中文、POE1 国服当前赛季设计。
