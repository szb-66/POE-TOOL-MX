直接粘贴删除的固定等待：再次移动 100ms + 双击后等待 100ms + Ctrl+A 110ms = 310ms。此数值为代码等待量，并非游戏实测。

当前未检测到 PathOfExile 游戏进程，未完成游戏内数字替换、双向通货切换和前后耗时比较，未打包。自动化中的选区模拟不替代游戏验收。

需要采样时，在启动开发版的 PowerShell 中设置 `$env:FAUSTUS_TIMING='1'`，再运行 `npm run electron:dev`。正常运行不需要启用该变量。

开发终端输出 FAUSTUS_TIMING：ocr 为截图和 OCR 时间及像素面积；price_context 为完整或局部识别路径；right_click_to_price_written 为右键发出至粘贴完成的时间；open_to_submission_result 为右键发出至提交结果截图识别完成的时间。日志不包含价格或剪贴板内容。

使用同一显示设置及相同物品样本比较修改前后版本，分别记录首件和后续物品，覆盖同通货及双向切换，检查不同位数价格能完整替换、单位正确、每件只提交一次。OCR 收益以该实测为准。
