## ADDED Requirements

### Requirement: 模板文件按运行模式隔离
系统 SHALL 依据运行模式为白名单模板目标解析保存文件名：安装版 MUST 保持既有固定文件名（如 `stash_title.png`、`inventory_title.png`、`junfeng_reward_title.png`），开发版 MUST 在扩展名前插入 `.dev` 后缀（如 `stash_title.dev.png`）。框选保存与手动上传两条写入路径 MUST 使用同一解析规则，使开发版与安装版在共享用户数据目录中各自维护独立的模板文件、互不覆盖。系统 MUST NOT 迁移或重命名既有模板文件以适配新模式。

#### Scenario: 安装版保存模板
- **WHEN** 打包安装版中用户框选或上传模板成功
- **THEN** 模板写入共享模板目录下的既有固定文件名，既有安装版配置无需重新框选

#### Scenario: 开发版保存模板
- **WHEN** 开发版中用户框选或上传模板成功
- **THEN** 模板写入带 `.dev` 后缀的文件名，且安装版固定文件名内容保持不变

#### Scenario: 手动上传遵循同一规则
- **WHEN** 任一运行模式中用户手动上传本地图片作为模板
- **THEN** 目标文件名与该模式的框选保存规则一致，仅保留用户文件的原始扩展名

#### Scenario: 不迁移既有模板文件
- **WHEN** 共享模板目录中已存在旧固定文件名的模板且开发版配置仍指向它
- **THEN** 系统不重命名、不复制该文件，开发版按既有校验流程提示重新框选，安装版继续正常使用原文件
