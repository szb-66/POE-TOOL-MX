## Why

当前商城模块只有占位界面，玩家需要离开应用并使用外部工具生成 NPC 商店搜索正则。将 Vendor 正则生成能力整合进商城模块，可以让国服玩家在现有工具内完成条件选择、预设复用和一键复制。

## What Changes

- 将商城占位页替换为面向当前国服 PoE 1 简体中文客户端的 Vendor 正则生成器。
- 支持孔色与连接、移动速度、+1 技能法杖、伤害词条和武器基底筛选。
- 实时生成、优化并展示正则，提供字符计数、超长警告、重置和点击复制。
- 增加独立的商城预设类型，支持新建、切换、自动保存、重命名和删除。
- 随应用内置带版本标识的中文 Vendor 数据快照，功能离线可用。
- 参考 poe.re Vendor 的公开行为独立实现，不嵌入外部网页，也不直接引入其 React 源码。

## Capabilities

### New Capabilities

- `vendor-regex-shop`: 定义中文 Vendor 筛选选项、正则生成与长度反馈、剪贴板复制，以及商城预设的持久化行为。

### Modified Capabilities

无。

## Impact

- 前端商城领域将新增 Vendor 数据、纯函数正则生成器和完整商城界面。
- Pinia 预设 Store 与通用预设选择器将扩展 `shop` 类型及对应 localStorage 数据。
- Electron preload、IPC 注册和前端 API 封装将增加安全的文本剪贴板写入接口。
- 不新增运行时网络依赖；现有物品与地图预设数据保持兼容。
