## Why

腾讯国服官方交易目录在当前版本保留了大量“类型和中文文案完全相同、但 stat ID 不同”的记录，查价器会把这些记录作为无法理解的候选交给用户；其中部分 ID 实际无法查到挂单，使用户即使手动选择也可能得到错误的零结果。需要在不猜测非等价词缀、也不增加额外探测请求的前提下，把相同官方语义稳定映射为可用查询。

## What Changes

- 为腾讯国服交易目录增加按 Provider 与游戏版本约束的不可查询 stat 元数据；记录继续参与覆盖审计，但不得进入解析候选、可信模型或官方请求。
- 根据官方 stat 类型、标准化中文文案和数值占位结构建立等价组，在既有上下文消歧后把仍然完全等价的多个 ID 表示为一个逻辑词缀。
- 单一有效 ID 继续使用普通 `and` 条件；多个有效等价 ID 使用独立的 `count`、`min=1` 查询组，并分别保留可信数值方向。
- 浮窗对等价组只显示一条可编辑词缀，不再展示无法理解的内部 ID 选择按钮；非等价歧义继续走现有人工选择流程。
- 扩展目录与查询覆盖审计，报告重复组、等价组和版本化不可查询记录，确保官方记录没有静默丢弃。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `price-check-stat-coverage`: 增加国服重复 stat 的版本化不可查询标记、等价分组、可信模型清理和 `count/min=1` 查询行为，并收紧可自动分组的安全边界。

## Impact

- 影响交易目录 schema、固定目录生成和在线刷新、词缀解析/消歧、查价模型清理、官方查询序列化及查价浮窗展示。
- 查价模型新增内部等价查询变体字段，但不新增或改名 IPC 通道，不改变认证、快捷键、分页、价格分布和默认勾选策略。
- 内置交易目录需要按当前 3.29 数据重新生成；用户无需迁移设置或本地数据。
- 实施仅在开发版验证，不打包、不发布，并保留当前工作区其他未提交修改。
