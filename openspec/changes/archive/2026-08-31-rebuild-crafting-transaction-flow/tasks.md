- [x] 2.2 重构请求文件监听为 `fs.watch` 低延迟通知加固定内部轮询，按成功解析的完整内容和 `commandId` 去重；空文件、写入中间态和损坏 JSON 不更新去重基线，轮询不读取 `operationDelayMs`。

## 3. 实现共享 Python 制作事务引擎

- [x] 3.1 新增生成期共享事务协议，注入单调时钟、剪贴板证据、输入动作和 v2 transport，并为每次脚本启动、通货动作、解析传输生成独立 `sessionId`、`transactionId`、`requestId` 和 `commandId`。

- [x] 3.4 将解析结果规范化为结构化 `CraftingSnapshot`，实现目标身份校验与排除传输、UI、统计字段的结构化指纹；缺失必要字段时 fail closed。

- [x] 3.6 实现改造石、混沌石、工匠石、链结石、幻色石和古灵直接通货的当前事务稳定策略：首次结构变化可确认，结构相同时必须取得第二个新鲜且一致的当前事务快照。
- [x] 3.7 实现 `read_baseline` 和 `run_currency_transaction` 状态机，强制一个事务只执行一次通货动作，并在候选验证后显式提交、获得 publication ack 后才返回 `confirmedSnapshot`。
