# primary-page-layout Specification

## MODIFIED Requirements

### Requirement: 主窗口侧栏使用固定深色分组布局
系统 SHALL 将主窗口侧栏固定为 76px 宽，并 SHALL 在不增加可点击分类层级的前提下，以间距和分隔线形成首页、业务模块、工具站、设置四个视觉区段。侧栏 SHALL NOT 保留帮助中心入口。

#### Scenario: 查看侧栏入口
- **WHEN** 用户打开主窗口
- **THEN** 侧栏保留除帮助中心外的全部既有正式入口的名称、路由和顺序
- **AND** 首页、制作至海图、工具站、设置按照既定区段显示
- **AND** 侧栏不显示帮助入口

#### Scenario: 查看开发入口
- **WHEN** 用户在开发版打开主窗口
- **THEN** 模型训练入口继续显示在原有相对位置
- **AND** 正式版继续隐藏该入口

#### Scenario: 选择导航入口
- **WHEN** 用户通过鼠标或键盘选择侧栏入口
- **THEN** 当前项使用品牌色标记、表面变化和高对比文字表达选中状态
- **AND** 原有路由预加载与导航行为保持不变

#### Scenario: 低高度窗口导航
- **WHEN** 侧栏入口高度超过可用窗口高度
- **THEN** 侧栏允许纵向滚动
- **AND** 全部入口及其焦点状态仍可访问
