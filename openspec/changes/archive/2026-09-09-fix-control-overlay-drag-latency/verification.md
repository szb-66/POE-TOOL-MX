## 失败尝试与处理

- 旧测试将 sync 之后整段源码都匹配为禁止偏移赋值，误判新拖动提交逻辑。删除该源码模式断言，补充真实管理器行为测试验证 null 默认偏移和非拖动保存位置不变。

- 独立 Vite middleware 转换成功但关闭时出现 unsettled top-level await 警告；改为请求正在运行的开发服务验证两个模块，HTTP 200。无对应产品补丁残留。
- 第一轮回放遗漏测试 IPC 状态处理器，修正回放脚本后重新记录基线。生产代码中未引入诊断分支或临时节流逻辑。
