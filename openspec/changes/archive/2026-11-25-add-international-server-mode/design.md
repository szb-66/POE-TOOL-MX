## Context

见 proposal.md。账号实际实现位于 chaosRecipe/auth.js；交易目录已有国际服官方目录生成基础。窗口标题和日志已有部分英文支持，物品与业务匹配仍大量依赖中文。

## Goals / Non-Goals

Goals: 单进程只运行一个服务器上下文，中文界面，英文国际服；共享计算与组件，隔离环境数据。
Non-Goals: PoE2、主机、英文助手界面、双进程同时运行、首期 OAuth 系统。

## Decisions

- 服务器描述放 shared，主进程启动读取唯一设置文件；通过 preload 向所有渲染窗口发布只读上下文，禁止渲染端任意指定请求域名。
- 国服沿用当前存储键及数据目录；国际服增加命名空间。共享主题、外观、延迟、快捷键，其余业务状态按服隔离。优先明确存储键映射，避免复制 store。
- 切换采用严格清理后持久化与开发版受管重启；清理失败不写模式。不在运行中替换客户端，避免异步回调串服。
- 配置包升级为 v2 并强制服务器标识，同时接收归属国服的 v1 包；旧助手会拒绝 v2，避免忽略服务器字段而误导入国际服预设。
- 客户端注入固定服务器描述；共用网站会话实现，支持逐接口验证，401/403/429 分别报告，不把网页 HTML 当成功 JSON。
- 英文输入归一化到现有业务字段和值，官方交易英文词缀保留原文以匹配对应目录；不逐字猜译词缀。
- 国际服除海图与做装模拟外使用 ready 能力状态并正常开放；ready 表示代码适配和离线验证，不表示游戏内实测。IPC、快捷键、页面及浮窗共享能力，原始脚本和跨服请求仍禁止。
- 查价共用捕获与浮窗，保留独立手动入口；关闭快捷查价不影响手动查询。配方复用官方结构属性与尺寸，开放原有取件控制。
- 国际服交易目录通过应用独立 Session 获取并按用户目录缓存；API 未提供补丁号时标记 live，仅供在线查询，不沿用国服补丁号或推断 PoB 版本。英文 PoB 输入只跳过已有英文的重复翻译，保留共用预处理、身份消歧与完整性检查，调用后恢复翻译器状态。
- 数据生成参数化并记录版本、语言、来源和哈希，输出候选通过校验后原子替换；两服不共用活动目录。

## Risks / Trade-offs

- 离线验证不能证明真实画面、DPI 和游戏输入效果；明确未进行游戏实测，但不将其作为功能禁用条件。
- 已有业务状态分散 → 审计 localStorage、文件存储与 Python 生成路径，保持国服路径兼容。
- 现有停止流程部分是尽力清理 → 切换使用严格成功检查；不直接用忽略异常的退出回调作为停止成功证据。

## Migration Plan

默认 cn，保留当前会话分区及存储。国际服独立目录与会话。回退国服不合并或删除国际服数据。旧配置包归属国服，跨服导入只允许明确共享区块。

## 3.30.0 六项功能补全

- 英文制作、地图词库和技能目录使用独立当前快照，记录来源哈希；制作候选与对应英文词缀共用现有计算和匹配流程。Atlas Drops、Threads 单独建字段，保留旧国服属性；异界地图补词仍六词，腐化结果允许九词。英文地图理论可行性覆盖不足时报告未知，不使用国服上限。
- 自动化能力默认允许用户正常启用，不要求开发参数；旧参数仅保留兼容，不改变正常权限。国际服启动不自动恢复存取任务，仍按用户开关和原有运行环境检查执行。
- 背包自动入库、仓库取件和君锋镇拆成子能力；国际服启动只监听状态，不恢复保存的启用配置。标题、网格和 DPI 重新校准。严格已知占位表记录真实旧尺寸来源并与本服目录取交集，本服 API 实测尺寸优先，未知不可选、不猜单格。
- 仓库取件、君锋镇和批量扫描的模型消费者按服选择同一模型；国际服训练、测试与发布目录隔离，测试未通过不得发布，不能改写国服内置模型的报告。
- 主进程使用固定内置战斗模板和共用纯制作生成器，忽略渲染端原始脚本与脚本路径；制作只允许主窗口或当前已注册且未销毁的制作浮窗、固定任务类型及内部通信路径，其他窗口和失效浮窗一律拒绝。错误请求在停止现有任务前拒绝。
- 海图与做装模拟排除；圣所、浮士德和独立当前 PoB 数据纳入本轮。既有模型可复用，训练产物与发布门槛仍按服隔离。

## 受管汉化与完整恢复（2026-11-15）

- 共用精确别名、参数模板和源文哈希校验。只读取已应用且本机验证有效的资源；ready 候选不得用作运行映射。物品同时保留原文与英文规范文本，未知关键身份和词缀失败停止，不猜译。
- 主进程覆盖制作脚本中的语言快照、通信文件及任务版本；Python 只接收可信名称与结构字段。资源版本变化取消旧查询、刷新联想并停止自动化，制作解析逐次检查版本。
- 制作/古灵/底材及地图联想按当前词库搜索简繁英文，保存稳定身份及英文模式；自由关键词兼容原文与可靠别名。地图的数值、黑白名单判断与 Python 统计使用同一规范内容，不重复计算别名。
- 浮士德使用 ClientStrings2 稳定 ID 和 BaseItemTypes 通货身份。圣所使用独立版本目录、原文和规则审核指纹，保留识别未知及不支持计算的条目；补齐经过验证的圣所文本导出白名单，不改结构字段。
- PoB 固定官方上游提交并保存每源哈希，国际服使用独立 3.30 普通/无情树、身份和技能数据。转换期间切换上游库上下文后在 finally 恢复，不污染国服 3.29。
- 通过离线文本、日志、OCR 行、图像 fixture 与假输入控制器验收，不安排游戏内操作、打包安装或外部部署。
- 按用户最新分类，Low、Mid、Top、Uber 全部规范为同一异界地图类；目录、预设、正则及制作策略不再分普通/T17。旧region只作为迁移输入，不作为运行时过滤或点金门禁；显式Item Tier保留为元数据，不据此推导任务类型。
