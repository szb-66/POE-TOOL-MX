## Why

状态栏第 2 个浮窗被裁成 339×149 的地图背景区域，奖励文字落在底边之外，导致空 OCR 被报告为无法确定状态。完整用户截图可由现有解析器正确读出工匠石 60、改造石 30，故修复应落在浮窗定位。

## What Changes

- 校验完整面板边界及悬浮前后变化，排除地图背景和内部小块。
- 高分辨率比较原尺寸与标准尺度定位候选，防止错误小区域阻断完整候选。
- 保存截图与 OCR 继续使用同一裁剪，无法可靠定位则明确失败。
- 加入反馈图、错误裁剪及多尺度回归，奖励分流和账本语义保持一致。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `sanctum-recognition`: 状态栏完整浮窗候选验证及多尺度选择。

## Impact

主要影响 Python 浮窗定位及对应 Node/Python 回放测试，无新增依赖、公共 API 或持久化迁移。现场重采单独验收，不以静态 OCR 替代。
