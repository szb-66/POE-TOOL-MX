## 实机验收限制

只读原生环境预检返回“游戏不在前台”。启动 `npm run electron:dev -- --diagnostic-exit-after-interactive` 时，已有开发实例占用 3000 端口，启动按既有规则退出。没有关闭用户已有实例或绕过预检。

主进程和 Python 改动需要重启现有开发版。后续需在同机器、同分辨率、同场景及相近负载下，对首次、连续、奖励密集和状态栏密集场景各执行至少五组交替实机采集。采集结果新增 `roundTripMs`（包含准备与最后清理）、`prepareMs`、`captureMs`、`mouseOwnedMs` 和 `cleanupMs`，目标级继续记录定位、排队、OCR、图标及解析耗时。整轮中位耗时必须减半，同时检查准确率、覆盖、失败率与 P95；在完成前任务 3.2 保持未勾选。
