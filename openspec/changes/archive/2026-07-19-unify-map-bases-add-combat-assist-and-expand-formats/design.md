## Context

地图配置当前用 `quantityNormal/quantityT17` 等两套键和 `tiers.t17` 决定运行时规则，页面与 Python 模板都包含相同分支。现有桌面自动化由 Vue 配置、Electron IPC 和 Python 子进程组成；制作/洗图共享单一脚本进程，背包功能已有独立进程模式。旧 AHK 自动喝药通过固定像素红/蓝分量判断并发送按键，一键回城则执行按键、等待和坐标点击。

本变更横跨预设迁移、前端路由、快捷键、IPC、Python 进程、物品解析和项目文档，且必须兼容已有本地设置。应用仅支持 Windows；战斗脚本只依赖 Python 标准库，通过 `ctypes` 调用 Windows GDI 和输入 API。

## Goals / Non-Goals

**Goals:**

- 让所有地图使用同一套六项基底条件，同时安全迁移旧预设。
- 将自动喝药与一键回城做成可视化、可测试、可独立启停的战斗辅助。
- 让用户提供的常见物品与地图结构能被准确说明、分组解析并纳入回归测试。
- 保持旧匹配数组和现有制作/洗图进程接口兼容。

**Non-Goals:**

- 不自动判断地图应使用点金石还是混沌石。
- 不迁移旧 AHK 的背包入库功能，也不引入 AutoHotkey 运行时。
- 不从游戏进程内存读取生命、魔力或物品数据。
- 不建立在线词缀数据库或同步 PoEDB 数据。

## Decisions

### 1. 地图基底采用单一规范化结构

预设只保存 `quantity`、`rarity`、`packSize`、`moreMaps`、`moreScarabs`、`moreCurrency`。页面始终展示六项，Python 匹配器不再接收地图类型。相比继续隐藏两套配置，这能移除状态分叉，并符合用户自行选择通货的实际流程。

迁移在 preset store 加载时完成且保持幂等。必选与挑选各自迁移；公共三项从 Normal/T17 候选中取“任一启用则启用、阈值取已启用候选最大值”，三个 `more*` 键原样保留。迁移成功后删除带后缀键、`tiers` 与无效 `strategy`。

### 2. 战斗辅助使用独立领域和独立进程

新增 `/combat` 页面与战斗辅助 store/服务。自动喝药拥有专属 Python 子进程句柄，不复用制作/洗图的 `currentScriptProcess`；因此两者能并行，原有全局结束键只停止制作/洗图。应用退出时主进程同时清理两类进程。

相比直接运行 AHK，沿用 Python 能复用应用现有的环境检测、IPC、日志和打包路径；使用 Windows 原生输入 API 则避免额外安装自动化库。相比把喝药循环合并进制作模板，独立进程不会让战斗功能受到制作任务生命周期影响。

### 3. 检测模型保持简单且可校准

生命检测读取目标像素红色分量，魔力检测读取蓝色分量，低于配置阈值即视为不足。两项分别保存坐标、启用状态、按键序列、回复模式和间隔。

“持续回复”触发后进入该资源自己的恢复冷却；“立即回复”只等待安全最小间隔即可再次触发。两种模式仍受每秒最大触发次数和保护冷却约束。页面复用坐标选取器，并通过调用 Windows GDI `GetPixel` 的单像素采样 IPC 显示当前 RGB、判定分量和是否会触发；该实现不要求用户额外安装截图依赖。

### 4. 输入只在游戏前台发送

Python 通过 Windows 前台窗口标题判断“流放之路”或“Path of Exile”。失焦时继续存活和采样，但不发送药剂按键；恢复焦点后自动继续。启停快捷键由 Electron 全局快捷键处理，保证在游戏中可操作且能统一检测重复绑定。

### 5. 回城采用两段按键配置

默认区分“宏触发键”和“游戏内开启传送门键”。触发后发送游戏键，等待配置时长，再左键点击配置的传送门位置；页面按钮走同一 IPC。该选择避免全局快捷键拦截并转发同一个键时可能发生的递归或丢键问题。

### 6. 词缀解析增加结构化结果并保留兼容字段

解析器新增 `modifiers`，每项保存种类、名称、等阶、标签和完整多行效果。现有 `explicitMods`、`implicitMods`、`craftedMods` 由结构化结果和普通复制文本继续生成，现有匹配器无需一次性重写。

详细复制中的括号机制说明、奖励区、使用说明和固定状态不进入可匹配显式词缀；`不可改变` 单独形成不可制作标志。页面示例按“文本结构”而非每个装备槽位组织，避免重复且能覆盖用户样本的关键差异。

## Risks / Trade-offs

- [旧预设两套公共阈值可能表达不同意图] → 取更严格值避免意外放宽，并用迁移测试保证确定性和幂等性。
- [像素颜色受分辨率、DPI和界面主题影响] → 提供坐标选取、即时颜色采样、阈值显示和可编辑默认值。
- [持续按键可能过快] → 始终启用最小间隔、每秒上限和保护冷却，配置校验拒绝非正数。
- [独立进程增加清理复杂度] → 使用专属注册表、幂等启停、退出钩子和异常退出状态事件。
- [前台窗口标题在不同客户端可能变化] → 支持中英文标题子串，并将不匹配视为暂停而非进程错误。
- [结构化词缀可能改变旧匹配结果] → 保留旧数组接口，以用户样本建立表驱动回归测试后再替换解析路径。

## Migration Plan

1. 先加入纯函数地图预设迁移与测试，再在加载路径启用。
2. 更新地图页面和 Python 匹配器，只消费规范化六键结构。
3. 加入战斗辅助设置默认值、IPC、独立进程和页面；旧用户首次加载自动补齐配置。
4. 扩展解析器、示例和文档，运行完整测试与生产构建。
5. 若需回滚，旧版无法识别规范化公共键；因此迁移前保留 localStorage 原始值的内存副本，只有成功规范化后才保存。代码回滚时用户可重新配置地图预设。
