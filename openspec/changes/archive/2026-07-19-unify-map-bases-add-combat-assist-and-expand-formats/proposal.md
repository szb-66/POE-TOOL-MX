## Why

地图制作仍沿用“普通地图/高级地图”两套基底条件，但当前游戏流程已经改为统一查看六项地图基底并由用户手动选择点金石或混沌石，旧分类增加了重复配置和误选风险。同时，已有 AHK 自动喝药与回城脚本缺少应用内可视化配置、进程管理和格式化测试支持，需要整合进现有桌面助手。

## What Changes

- **BREAKING**：移除地图页的普通/高级地图 tab 和两套独立基底键，所有地图统一配置六项基底。
- 自动迁移已有地图预设；公共三项从两套旧配置中取已启用的更严格阈值，保留另外三项地图基底。
- 新增独立“战斗辅助”页面，提供血量/蓝量像素检测、持续或立即回复模式、按键序列、运行控制、颜色测试和一键回城配置。
- 自动喝药使用独立后台进程，可与制作和洗图并行，并仅在游戏窗口位于前台时发送输入。
- 扩充通用物品与地图剪贴板解析、格式示例和回归测试，补充词缀领域文档并移除“高级地图”旧概念。

## Capabilities

### New Capabilities

- `unified-map-base-matching`: 统一六项地图基底的配置、旧预设迁移和运行时匹配行为。
- `combat-assist`: 可视化配置并控制自动喝血/蓝药、像素检测和一键回城。

### Modified Capabilities

- `supported-item-format-guidance`: 扩展受支持物品/地图结构、状态、详细多行词缀及完整六字段地图的说明和受测样例。

## Impact

- 地图页面、地图预设 store、地图脚本生成与运行时匹配逻辑需要统一数据结构。
- 新增战斗辅助 Vue 领域页面、设置结构、全局快捷键、IPC、独立 Python 进程与脚本模板。
- Electron 主进程需要管理战斗辅助进程、像素采样、状态事件和退出清理。
- 物品解析器、帮助面板、README、OpenSpec 项目上下文及 Node/Python 回归测试需要更新。
- 使用 `ctypes` 调用 Windows 原生 GDI 与输入 API，不引入 AutoHotkey 或新的 Python 运行时依赖。
