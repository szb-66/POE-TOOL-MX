## Why

海图识别参数当前写死，不同机型在颜色亮度、图标位置和框选习惯上的差异会导致大量格子方位误判；自动放置又会在运行时重新识别来源并覆盖用户手动修正，导致用户改完后仍然无法可靠放入。

## What Changes

- 新增海图识别强度设置（敏感/标准/严格），持久化到海图配置，并在分析时生效。
- 分析结果增加网格置信度与低置信提示，帮助用户判断是否需要重新框选，但不自动修改区域。
- 方向识别探针优先使用绿色图标质心，替代固定格内位置，提高不同机型的方位识别稳定性。
- 自动放置优先使用用户当前方案选中的修正来源，旋转确认失败时对已修正来源重试后继续，不再直接中止。
- 自动放置停止或失败后同步仓库时保留用户手动修正的格子，避免修正被覆盖。

## Capabilities

### New Capabilities
- `puzzle-recognition-settings`: 海图识别强度档位、网格置信度提示与持久化配置。

### Modified Capabilities
- `nine-grid-puzzle-solver`: 方向识别使用图标质心探针，并在识别结果中返回网格置信度。
- `atlas-auto-placement`: 自动放置使用用户修正来源、对修正来源允许旋转重试并保留修正结果。

## Impact

- 渲染层：海图页/设置页增加识别强度选择与网格置信度展示。
- 主进程服务：分析请求与自动放置请求携带识别配置和来源格。
- Python 识别器：读取强度参数、计算网格置信度、调整方向探针。
- Python 自动放置脚本：使用传入的来源格并调整旋转校验行为。
- 测试：识别器、自动放置、配置迁移测试。
