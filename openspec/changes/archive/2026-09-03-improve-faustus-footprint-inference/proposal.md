## Why

浮士德市集改价目前把视觉模型的逐格非空结果作为物品尺寸矩形的硬约束；多格物品只要有一格被误判为空，或相邻物品形成连续非空区域，就会频繁记录“物品占位与视觉格子不一致”并跳过。系统已经能够从复制文本解析物品身份和可信尺寸，应让这些证据参与局部占位消歧，而不是仅用于否决。

## What Changes

- 视觉初扫只跳过高置信空格，低置信空格继续接受剪贴板确认。
- 已知尺寸物品出现视觉不完整或相邻占位时，对可能包含当前格的矩形执行局部剪贴板补探测。
- 仅当完整复制文本与尺寸约束唯一确认一个矩形时打开价格窗口；未知、越界、不完整或多解仍安全跳过。
- 移除较早歧义格对后续消歧的永久阻断，同时保持每个已确认物品最多改价一次。
- 保持现有 IPC、结构化日志字段、原因码、前台门禁和紧急停止契约不变。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `faustus-market-repricing`: 将物品占位确认从严格依赖完整视觉矩形，改为高置信视觉排空与局部剪贴板、尺寸联合消歧。

## Impact

主要影响浮士德 Python 自动化脚本及其回归测试，并更新对应 OpenSpec 行为契约。运行时会在视觉证据不足时增加少量鼠标移动和复制操作；不新增依赖、用户配置、公开 API 或持久化数据。
