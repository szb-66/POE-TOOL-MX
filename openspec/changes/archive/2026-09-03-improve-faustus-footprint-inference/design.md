## Context

参见 proposal.md。当前浮士德脚本把模型逐格 `argmax` 为非空的集合当成完整占位硬约束，随后要求已知尺寸矩形完全包含于该集合且只有一个解。该做法会放大单格视觉假阴性，并在相邻占位中失去物品身份信息。自动改价属于安全敏感输入流程，覆盖率改善不能以猜测坐标为代价。

## Goals / Non-Goals

**Goals:**

- 用本轮局部剪贴板证据和冻结尺寸目录修复视觉漏格、相邻占位造成的误跳过。
- 保持唯一确认、最多提交一次、前台门禁与有限日志契约。
- 让补探测结果可通过纯 Python 适配器确定性回归测试。

**Non-Goals:**

- 不重新训练通用格子模型，不加入浮士德专用模型。
- 不增加用户配置、IPC、持久化身份或完整复制文本日志。
- 不处理整件物品所有格都被模型以高置信判空的场景。

## Decisions

### 视觉只承担高置信排空

以 `0.995` 为空格排除门槛；模型 `argmax` 非空或空格概率未达门槛的格子都进入扫描。该值与模型清单的保守基准门槛一致，优先避免假阴性。备选的“所有 argmax 空格均跳过”正是当前根因；完全扫描 144 格则会明显增加正常运行时间。

### 使用局部完整复制文本建立临时身份

首次复制到物品后，规范化 NFKC、换行和首尾空白后的完整文本只保存在本轮内存缓存。枚举所有包含当前格、尺寸正确、未越界且不与 `resolved_slots` 重叠的矩形，并按需复制这些矩形的并集。一个矩形仅在全部格子都与当前临时身份相同时成立；只接受唯一成立矩形。备选的视觉连通块无法区分相邻物品，尺寸直接优先则可能对错误格右键。

### 对预期格的首次空结果重试一次

空剪贴板既可能表示空格，也可能是短暂复制失败。探测当前候选矩形时，首次为空的格子立即重试一次；持续为空即视为该矩形不成立。非空但不同文本不重试，避免无意义输入。缓存最终探测结果，后续候选复用，减少重复移动与复制。

### 歧义只标记已尝试坐标

移除“较早歧义格位于可能前驱区域就否决后续矩形”的规则。歧义坐标本身不重复扫描，但其他尚未处理格仍可使用缓存证据重新枚举；唯一确认后由完整 `resolved_slots` 阻止重复操作。这样边缘格可能消除中间格的多解，同时仍保证已确认物品最多处理一次。

## Risks / Trade-offs

- [低置信空格和补探测增加运行时间] → 仅探测尺寸候选矩形并缓存每格结果，高置信空格仍快速排除。
- [相邻完全相同物品可能无法划分] → 多解时继续安全跳过，不降低提交安全边界。
- [复制文本含不稳定展示内容] → 只在短时局部扫描内比较规范化完整文本，不跨运行或持久化复用。
- [模型对整件物品高置信误判为空] → 本变更无法从零候选启动探测；开发版验收若复现，再独立采集浮士德样本评估模型。

## Migration Plan

无数据迁移。通过更新脚本与回归测试直接启用；回滚时恢复旧候选筛选与严格视觉矩形函数即可。只在开发版验证，不执行打包。
