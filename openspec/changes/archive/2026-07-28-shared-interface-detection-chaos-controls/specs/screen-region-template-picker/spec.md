## MODIFIED Requirements

### Requirement: 混沌配方仓库网格校准
系统 SHALL 分别保存根目录普通、根目录大型、文件夹普通和文件夹大型仓库的物理屏幕矩形。

#### Scenario: 保存四类仓库区域
- **WHEN** 用户为任一仓库布局完成有效矩形选取
- **THEN** 系统独立保存该区域及显示器/DPI元数据，并按普通12×12或大型24×24网格换算

#### Scenario: 自动识别文件夹仓库
- **WHEN** 仓库标签页包含 `parent` 或 `folder` 归属
- **THEN** 系统将其识别为文件夹内仓库，并贯穿物品与取件计划选择文件夹校准

#### Scenario: 迁移旧校准
- **WHEN** 用户已有普通或大型仓库校准但尚无文件夹校准
- **THEN** 系统保留旧校准作为根目录区域，且文件夹区域保持未校准

#### Scenario: 缺少所需校准
- **WHEN** 取件计划包含尚未校准的仓库布局
- **THEN** 系统返回 `CALIBRATION_REQUIRED` 且不得开始自动取件
