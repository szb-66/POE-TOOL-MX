# screen-coordinate-picker 变更

## ADDED Requirements

### Requirement: 取点前后窗口焦点保障
系统 SHALL 在显示取点层之前最小化应用主窗口并将游戏窗口激活到前台；游戏窗口激活失败时 SHALL 中止本次取点并提示用户；取点结束后 MUST 还原并聚焦应用主窗口。

#### Scenario: 发起取点时激活游戏
- **WHEN** 用户点击任意点位的取点按钮
- **THEN** 系统先最小化应用主窗口、将游戏窗口激活到前台，之后才显示取点层

#### Scenario: 游戏窗口激活失败
- **WHEN** 游戏未运行或系统找不到游戏窗口导致激活失败
- **THEN** 系统中止本次取点、还原应用主窗口，并提示用户先启动游戏，不显示取点层

#### Scenario: 取点成功后还原主窗口
- **WHEN** 用户完成取点并返回坐标
- **THEN** 系统还原应用主窗口并将其聚焦到前台

#### Scenario: 取点取消或异常后还原主窗口
- **WHEN** 用户取消取点或取点窗口异常关闭
- **THEN** 系统同样还原应用主窗口并将其聚焦到前台

#### Scenario: 非 Windows 平台跳过激活
- **WHEN** 应用运行在非 Windows 平台
- **THEN** 系统跳过游戏窗口激活，仍执行主窗口最小化与结束后的还原
