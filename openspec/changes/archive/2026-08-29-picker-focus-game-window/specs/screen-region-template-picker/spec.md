# screen-region-template-picker 变更

## ADDED Requirements

### Requirement: 框选前后窗口焦点保障
系统 SHALL 在打开框选层之前最小化应用主窗口并将游戏窗口激活到前台；游戏窗口激活失败时 SHALL 中止本次框选并提示用户；框选结束后 MUST 还原并聚焦应用主窗口。

#### Scenario: 发起框选时激活游戏
- **WHEN** 用户点击任意区域配置的框选按钮
- **THEN** 系统先最小化应用主窗口、将游戏窗口激活到前台，之后才捕获截图并显示框选层

#### Scenario: 游戏窗口激活失败
- **WHEN** 游戏未运行或系统找不到游戏窗口导致激活失败
- **THEN** 系统中止本次框选、还原应用主窗口，并提示用户先启动游戏，不捕获截图也不显示框选层

#### Scenario: 框选成功后还原主窗口
- **WHEN** 用户完成框选并返回选区结果
- **THEN** 系统还原应用主窗口并将其聚焦到前台

#### Scenario: 框选取消或异常后还原主窗口
- **WHEN** 用户取消框选或框选窗口异常关闭
- **THEN** 系统同样还原应用主窗口并将其聚焦到前台

#### Scenario: 非 Windows 平台跳过激活
- **WHEN** 应用运行在非 Windows 平台
- **THEN** 系统跳过游戏窗口激活，仍执行主窗口最小化与结束后的还原

## MODIFIED Requirements

### Requirement: 干净屏幕截图与精确裁剪
系统 MUST 在将游戏窗口激活到前台之后、显示选区层之前捕获目标显示器的干净画面，并从该画面生成模板 PNG。

#### Scenario: 捕获游戏画面
- **WHEN** 用户发起框选且游戏窗口激活成功
- **THEN** 系统在游戏位于前台后捕获屏幕画面，截图内容为前置后的游戏画面

#### Scenario: 裁剪模板
- **WHEN** 用户确认有效选区
- **THEN** 模板图片不包含选区蒙层、提示框或边框，且像素尺寸严格等于物理选区尺寸

#### Scenario: 截图缩放换算
- **WHEN** 截图 thumbnail 尺寸与显示器物理尺寸不同
- **THEN** 系统按实际宽高比例换算裁剪坐标并输出选区目标尺寸的图片

#### Scenario: 截图不可用
- **WHEN** 截图为空、尺寸无效或像素内容无法作为模板
- **THEN** 系统返回明确错误且 MUST NOT 生成或覆盖模板文件
