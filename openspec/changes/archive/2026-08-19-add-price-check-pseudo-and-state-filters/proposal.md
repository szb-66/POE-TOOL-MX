## Why

现有国服查价浮窗只能展示由物品文本确定的布尔状态，用户无法按“任意/是/否”调整官方状态过滤；词缀来源仅以弱化文字展示，也没有把同一属性的多条来源汇总成官方市集可查询的 `pseudo.*` 综合条件。补齐这些能力可让稀有装备查价更接近官方市集和成熟查价器的条件表达，同时继续保持查询 ID 可验证、结果可解释。

## What Changes

- 为查价模型增加白名单化的三态状态过滤，覆盖已鉴定、腐化、复制、分裂之物、分裂、秽生、忆境、焚界者、灭界者、工艺和影匿；浮窗允许逐项选择“任意/是/否”。
- 保留解析出的物品事实，并把用户选择的状态条件独立序列化到腾讯国服官方 `misc_filters`；复制默认“任意”，其余可识别状态默认严格匹配当前物品。
- 按官方 stat namespace 为原始词缀显示稳定的彩色来源标签，未知或歧义词缀继续走现有安全消歧流程。
- 将交易目录升级为包含稳定 stat ref 和版本化综合规则的 schema，并从固定版本的 Awakened PoE Trade 规则生成可审计的综合属性。
- 汇总不同来源对抗性、属性、生命、魔力、能量护盾、速度、伤害、暴击、恢复和偷取等属性的贡献；仅在活动目录存在合法 `pseudo.*` ID 时展示，并把启用项作为真实官方 stat 过滤提交。
- 保留原始来源词缀供查看和手动选择；综合条件默认启用时取消其来源词缀的自动启用，避免重复约束。
- 更新第三方来源说明、目录覆盖审计和开发版回归测试，不执行安装包构建。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `cn-price-check`: 增加三态状态模型、综合 stat 生成与官方查询序列化契约。
- `cn-price-check-overlay`: 增加状态下拉、彩色来源标签和综合条件的可编辑交互。
- `cn-trade-catalog`: 增加 stat ref、综合规则、schema 校验和规则覆盖审计。
- `price-check-stat-coverage`: 增加所有受支持官方 stat 类型的展示映射及综合规则可查询覆盖要求。

## Impact

- 影响物品详细文本解析、查价目录生成和加载、查价模型清理、官方查询构造、浮窗展示与测试语料。
- 查价模型新增 `stateFilters`，stat 模型增加派生来源信息；目录 schema 升级，需要同步重建内置目录并保持在线刷新与降级目录一致。
- 综合规则固定采用 Awakened PoE Trade 3.29.102（提交 `91b5a05b14cda3a632a306b5f606ca1cced8b4a9`）的 MIT 规则语义，并继续以腾讯国服官方 stats/filters 目录作为有效 ID 与过滤字段的权威来源。
- 不改变既有 IPC 权限边界、账号认证、快捷键捕获、挂单结果或价格分布协议。
