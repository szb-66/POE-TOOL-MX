## Context

当前 schema v4 的 `state.implicits` 只是字符串数组，不能区分底材固定词缀、焚界者隐式与灭界者隐式，也不能表达 T1–T6 或支配关系。POEDB 当前 `Eldritch_implicit` 页面包含两张 1,980/2,070 行表；每行给出等级、中文效果、标签及按物品类别和排除阶级标签表达的权重。现有底材变体把 `eldritch` 当成互斥 kind，但古灵隐式实际上能与破裂装备共存，因此执行状态必须与底材 kind 解耦。

## Goals / Non-Goals

**Goals:**

- 从当前 POEDB 表格生成可校验的两侧六阶真实隐式池。
- 让八种直接隐式通货及四种支配通货准确改变同一装备会话。
- 保留显式词缀、破裂、工艺台元工艺、撤销/重做/重置的现有语义。
- 页面始终解释支配方、目标侧、候选数、成本与随机后果。

**Non-Goals:**

- 不恢复价格或自动路径计算。
- 不支持传奇物品、古灵祭坛掉落物或永恒斗争的传奇特例。
- 不声称冲突石的内部随机公式为官方精确常数。
- 本变更不重做追忆、腐化或普通底材固定词缀池。

## Decisions

1. **新增专用 `eldritchImplicitFamilies` 数据域并升级到 schema v5。** 每个家族保存来源、效果键、适用物品类别、标签以及六个阶级的文本、等级、权重与数值范围。相比把 4,050 行伪装成通货 craft，这能保留“家族→阶级”关系并支持冲突石只升降同一家族。

2. **装备状态使用 `eldritchImplicits: { exarch, eater }`。** 每侧最多一个实例，实例引用 family/tier 并保存掷出的文本和值。`state.implicits` 继续保存普通文本固定词缀；首次使用任一灼烙/灵液会清除普通固定词缀，但保留对侧古灵隐式。古灵状态不依赖 `variant.kind`，从而允许破裂装备使用，但拒绝六势力和腐化装备。

3. **直接隐式通货按 T1–T4 精确抽池。** 低阶、高阶、卓越、宏伟分别映射 T1–T4；使用时从当前底材类别、物品等级和指定阶级的正权重家族中加权抽取并重掷数值，只替换同来源侧。

4. **支配是纯函数。** 缺失侧视为 T0；较高阶一侧支配；两侧同阶时无支配。焚界者支配指向前缀，灭界者支配指向后缀。

5. **显式词缀通货使用各自元工艺矩阵。** 异能混沌石忽略前后缀锁，先清空目标侧，再从仍保留的对侧重建元工艺，按新的随机数量重铸目标侧；因此仍存在的无法骰出攻击/法术会限制候选。异能崇高石遵守无法骰出攻击/法术但不把“无法变更”视为禁止添加。异能无效石遵守目标侧锁定，并保护带攻击/法术标签的现有词缀。

6. **冲突石保留家族，只改变阶级。** 两侧都存在才可用；选中一侧升级、另一侧降低，T1 降低时移除，T6 的升级被浪费但对侧仍降低。公开实测模型使用 `clamp(0.5 - 0.11 × (目标阶级 - 对侧阶级), 0.05, 0.95)`，页面和帮助明确标注其为社区估计；历史记录动作前概率及实际升降。

7. **在线更新与内置快照共享同一解析器。** 页面结构变化、任一来源为空、阶级无法解析或 checksum 不匹配都会拒绝激活。fixture 覆盖两侧、六阶、多个物品类别和未知行安全行为。

## Risks / Trade-offs

- [冲突石内部概率未公开] → 将公式集中为常量和纯函数，显示估计标签，保留替换入口和固定种子测试。
- [4,050 行原始记录会扩大快照] → 规范化为家族和六阶，只保留四种受支持护甲类别的正权重记录。
- [旧 schema 无结构化古灵状态] → 用户活动 schema v4 快照回退内置 v5，不猜测迁移；会话状态缺字段时规范化为空两侧。
- [POEDB 中文命名与英文资料不同] → 内部使用稳定 `exarch/eater`，显示名称取当前简体中文页面。

## Migration Plan

1. 增加解析器、模型和 fixture，生成 v5 数据并验证家族完整性。
2. 更新内置快照和在线更新器；旧活动快照安全回退。
3. 接入状态机、服务和页面，再运行真实快照流程、全量测试与构建。
4. 若新快照无法加载，回滚代码与内置数据；旧用户目录保持不删除。

## Open Questions

- 冲突石内部权重若出现新的权威数据，应只替换集中概率函数和帮助依据，不改变会话/API 结构。
