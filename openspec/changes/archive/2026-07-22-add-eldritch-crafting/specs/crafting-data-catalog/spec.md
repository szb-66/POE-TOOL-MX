## ADDED Requirements

### Requirement: 快照保存当前古灵隐式目录
系统 MUST 从 POEDB 当前 `Eldritch_implicit` 页面解析焚界者与灭界者的中文隐式家族，为每个家族保存稳定 ID、效果结构、适用护甲类别、标签以及 T1–T6 的等级、文本、权重和数值范围。只有头盔、手套、鞋子和身体护甲的正权重记录 SHALL 进入可执行池。

#### Scenario: 解析六阶家族
- **WHEN** 六行记录具有相同效果结构和适用类别，且排除阶级标签依次对应六阶
- **THEN** 系统生成一个包含 T1–T6 的古灵隐式家族
- **AND** 每阶保留自身中文文本、数值、等级和类别权重

#### Scenario: 排除非装备特例
- **WHEN** 页面记录只对项链、传奇特例或四种支持护甲之外的标签具有正权重
- **THEN** 该记录不进入手动古灵通货候选池

### Requirement: schema v5 校验古灵数据完整性
系统 SHALL 使用 schema v5 保存古灵隐式目录，并 MUST 在两侧来源、引用、稳定 ID、阶级连续性、正权重、适用类别和 checksum 全部验证后才激活快照。旧 schema v4 活动快照 SHALL 回退内置 v5 快照且不删除旧目录。

#### Scenario: 古灵页面结构变化
- **WHEN** 更新器无法解析任一来源，或家族缺少合法阶级和类别
- **THEN** 更新失败、暂存目录被清理且此前活动快照保持不变

#### Scenario: 旧活动快照
- **WHEN** 用户活动目录仍为 schema v4
- **THEN** 系统回退内置 schema v5 并提示重新更新
