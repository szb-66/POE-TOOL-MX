## Context

见 proposal.md。当前一级导航直接写在 `Sidebar.vue`，路由与首页模块又各自维护一份清单；主运行时在应用挂载时整体初始化监听、快捷键和多个后台服务。若只按视图隐藏菜单，会继续保留快捷键及 Electron 侧自动化，因此需要把功能目录、持久化状态与运行时生命周期统一起来。工作区当前还包含未提交的正则/配方导航改造，实现必须基于工作树现状增量合并。

## Goals / Non-Goals

**Goals:**

- 让单一功能目录驱动导航展示、路由归属、快捷键过滤和运行时控制。
- 用可测试的事务式停用流程确保运行任务先停止、状态后提交，安全停止始终可用。
- 保留模块原始业务配置，把“模块已添加”作为业务开关之外的独立上层门禁。
- 让纯页面功能与含后台能力的功能使用一致的用户交互。

**Non-Goals:**

- 不拆分存取页面等一级入口内部的子功能，不增加拖拽排序。
- 不删除路由、业务配置或数据，不将模块偏好加入配置传输。
- 不改变自动化现有前台窗口、坐标、DPI、模板和运行环境预检。
- 不进行安装包构建或发布。

## Decisions

### 1. 使用静态功能目录与运行时适配器分层

新增纯数据目录，定义稳定 ID、路由、名称、图标键、顺序、开发环境限制和快捷键键名；图标组件映射留在 Vue 层，避免纯逻辑测试依赖组件。运行时协调器另外维护按 ID 注册的 `isBusy/suspend/resume` 适配器，使目录可供路由和页面同步使用，又不把 Pinia/Electron 实例耦合进静态模块。

替代方案是继续在侧边栏、路由和启动器分别维护条件；该方案容易遗漏入口或快捷键，无法满足统一门禁要求。

### 2. 持久化停用集合而不是启用集合

`featureModules:v1` 保存 `{ version: 1, disabledFeatureIds: [] }`。加载时只接受当前环境目录中的字符串 ID，非法结构整体回退，未知 ID丢弃。持久化停用集合可使未来新增功能自然默认添加；若保存启用集合，每次新增功能都需要迁移。

### 3. Pinia store 作为响应式状态，协调器负责副作用

功能 store 暴露可用目录、已添加/未添加列表、路由到模块映射和状态读写。协调器执行停用/恢复：运行中先由 UI确认；停用时先调用适配器，再过滤快捷键，全部成功后才写入停用集合。失败不提交；恢复时先将入口设为可达，再尝试恢复运行时，失败以警告返回并保持页面可配置。

### 4. 快捷键注册与分发双重门禁

从设置生成注册表时按功能目录过滤专属键，但无条件保留 `end`。快捷键触发处理器在分发前再次检查所属模块，覆盖注销与事件到达的竞态。更新停用模块快捷键只更新设置，下次模块恢复时统一注册。

### 5. 路由和非路由入口共用门禁

路由前置守卫根据目标路径查询目录；停用时取消导航并发出中文提示。首页模块状态标记为“未添加”，点击不自动恢复。主运行时中的扫描请求、拼图更新等程序事件在导航或启动前调用同一门禁，避免绕过侧边栏。

### 6. 一级模块运行映射

- 制作/地图分别按脚本 store 的 `mode` 停止共享脚本；制作额外停止背包扫描和监听。
- 存取统一停止背包检测与入库、仓库取件、君锋镇取件和相关覆盖层，但不改各子功能保存的 enabled 配置。
- 战斗停止药剂、循环和回城自动化；剧情关闭覆盖层；配方停止混沌配方并关闭控制覆盖层；查价暂停运行时并关闭结果浮窗。
- 浮士德、海图和开发版模型训练停止各自进行中的任务和浮窗。
- 正则、模拟和工具站只有路由门禁，无额外后台副作用。

若现有 renderer API 无法在不改业务配置的情况下暂停某个模块，补充最小的 Electron IPC suspend/stop 入口；不复用会同时清空用户配置的页面开关动作。

## Risks / Trade-offs

- [多个模块共享脚本进程或停止能力] → 通过运行状态中的模块/模式判断只停止所属任务；紧急停止仍作为独立全局安全路径。
- [恢复后台服务时配置或环境已失效] → 入口先恢复，运行时恢复失败明确提示，仍执行既有预检且不产生输入。
- [停用过程部分成功] → 停止动作设计为幂等；未全部成功不提交停用状态，并重新同步仍应启用的快捷键与运行时状态。
- [现有多份模块清单继续漂移] → 侧边栏、更多面板、路由门禁和快捷键归属必须消费统一目录，测试断言所有正式一级路由均被目录覆盖。
- [工作区已有未提交修改] → 只增量编辑相关块，验证差异中不包含回退或覆盖既有正则/配方改造。

## Migration Plan

1. 新存储键不存在时按空停用集合启动，不迁移任何旧数据。
2. 先引入目录、存储和测试，再接入侧边栏与路由，最后接入运行时协调与模块适配器。
3. 开发版验证失败时可移除新存储键并回退新目录/协调器引用；原业务配置与路由数据未被迁移。
