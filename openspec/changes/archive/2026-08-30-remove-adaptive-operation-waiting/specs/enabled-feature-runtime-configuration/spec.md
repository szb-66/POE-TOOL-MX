## MODIFIED Requirements

### Requirement: 现有持续功能保持热同步
系统 SHALL 让背包检测、仓库取件、君锋取件、战斗辅助、商店配方和国服查价在开启状态下继续同步有效详细配置，并让所有游戏输入消费者接收完整全局自动化时序，采用相同的失败回滚语义。

#### Scenario: 已开启但没有执行动作
- **WHEN** 用户修改仓库取件、君锋取件、商店配方、战斗辅助或查价配置且当前没有输入动作执行
- **THEN** 主进程接收最新配置且功能无需关闭或重新开启

#### Scenario: 更新全局自动化时序
- **WHEN** 用户修改 `operationDelayMs` 或 `fixedTiming`
- **THEN** 系统把规范化后的完整时序作为一个修订同步给所有已启用游戏输入消费者
- **AND** 任一同步失败时保留上一份已生效时序并显示失败原因

#### Scenario: 查价设置更新
- **WHEN** 用户在查价开启期间成功修改查询设置
- **THEN** 下一次捕获、重查或加载结果使用最新设置
