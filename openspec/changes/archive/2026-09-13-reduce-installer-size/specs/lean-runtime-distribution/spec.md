## Purpose

约束 Windows 应用分发内容，在保留离线识别、自动化、训练及业务资源完整性的前提下移除重复依赖和非运行文件，并提供可核对的体积证据，避免将未压缩收益误报为安装包下载收益。

## ADDED Requirements

### Requirement: 精简分发保持离线完整性
分发内容 MUST 排除重复前端依赖、Python 字节码缓存以及 NumPy、Shapely、Colorama、Certifi 的 tests 目录；MUST 保留运行模块、模型、元数据、许可证和业务脚本。

#### Scenario: 离线识别
- **WHEN** 使用筛选后的内置运行时且禁止联网
- **THEN** 全部所需依赖可导入，固定 OCR 样本可识别，模型无需下载

#### Scenario: 发布资源污染或缺失
- **WHEN** 发布内容含禁止分发的依赖或测试缓存，或遗漏必需运行文件
- **THEN** 发布结构检查失败并报告相对路径

### Requirement: 可复核的体积证据
验证 MUST 输出同一版本筛选前后的文件清单和未压缩字节数，MUST NOT 将该差值描述为安装包压缩收益。

#### Scenario: 开发环境验证
- **WHEN** 执行分发审计
- **THEN** 报告筛选前后文件与体积差异，开发运行时原件不被删除，无需生成安装包
