## Context

前端经 Vite 编译，但五个前端包仍位于生产依赖。Python extraResources 无过滤器。已有 release:smoke 只检查部分文件和模块导入。当前旧安装包不是当前版本，不能直接比较压缩收益。

## Goals / Non-Goals

**Goals:** 分发过滤可验证、可复现，保留开发原件与全部业务行为。

**Non-Goals:** 不更换引擎、版本、模型，不下载组件，不裁剪业务数据或训练脚本。

## Decisions

- 使用开发依赖分类而不是手工删除 node_modules，保留主进程依赖闭包。
- 使用 extraResources 的明确过滤规则，而不是修改 runtime:prepare 输出。缓存可以在开发或用户运行时重新生成。
- 用构建工具同款 glob 匹配器生成临时运行时副本和前后清单；发布检查核对所有应保留文件及禁止路径。保留 numpy/testing，仅排除 tests。
- OCR 探测在 Python 进程内阻断网络连接，执行固定图像识别；开发回归使用临时副本作为解释器。
- 记录依赖闭包和运行时两项体积差异，不将源目录大小称为压缩包收益。

## Risks / Trade-offs

- [依赖重分类遗漏主进程引用] → 核对生产闭包、模块解析和开发版行为。
- [过滤范围过宽] → 保留文件测试、实际复制清单与离线 OCR 回归。
- [缓存重建影响启动] → 仅排除分发缓存，不禁止运行时正常缓存。

## Migration Plan

无用户数据迁移。随下一次正常发布生效；回退依赖分类和过滤器即可恢复原分发内容。
