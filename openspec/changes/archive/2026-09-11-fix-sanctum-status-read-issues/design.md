## Context

见 proposal.md。旧完成态将空类别转成失败；合并时丢失浮窗来源，导致目标失败和分类失败重复输出。

## Goals / Non-Goals

分离分类展示、读取完成与可信完整性；不改变游戏输入、重试、截图存储和路线计算规则。

## Decisions

- 增加采集 finished 标记；分类结束后空类别为 absent，已识别条目独立展示，未知内容仍保留在 effects 中。complete/classificationComplete 继续决定完整性。
- 解析组和采集目标共享 targetId、evidenceId、入口序号；共享命名和原因格式化供错误及截图使用。源目标和阶段归并错误，混合浮窗合并不同原因。
- 旧记录无来源时通过原文或原因匹配已有目标，旧编号可生成中文名称；不虚构未识别词条。尚未采集保持待确认。

## Risks / Trade-offs

- 空类别“无”仅指当前分类结果 → 保留整体不完整提示及未知效果，避免提升路线可信度。
- 历史记录来源不足 → 优先已有目标证据，没有对应证据时保留独立缺口。

## Migration Plan

兼容增加字段，无存档迁移；开发版验证，不打包。回退本变更代码即可回滚。
