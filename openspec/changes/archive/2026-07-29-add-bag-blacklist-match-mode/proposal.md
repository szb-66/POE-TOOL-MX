## Why

背包黑名单当前只支持包含匹配，导致类别规则“地图”同时命中“地图碎片”。用户需要按规则选择精确或模糊匹配，才能准确保留目标物品而不误伤名称存在包含关系的其他物品。

## What Changes

- 为每条背包物品黑名单规则增加“模糊匹配”和“精确匹配”模式。
- 在规则编辑器和规则列表中展示匹配模式。
- JavaScript 配置规范化、预览匹配与 Python 实际入库执行采用一致的匹配语义。
- 兼容既有黑名单配置：缺少匹配模式的旧规则继续按原有模糊匹配执行。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `bag-auto-stash`: 物品黑名单规则新增可持久化的逐条匹配模式，并明确模糊、精确及旧规则迁移行为。

## Impact

影响背包页面规则编辑器、背包配置规范化与持久化、运行时配置、Python 自动入库脚本及相关自动化测试；不新增外部依赖。
