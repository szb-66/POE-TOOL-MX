# Proposal: 升级查价器高价值智能预选引擎

## Why

当前查价器的 `auto` 自动初选策略仅以“前后缀 T1/T2 + 无门槛总抗/总生命”一刀切方式勾选词缀，导致低价值 T1/T2 词缀（如荆棘、照亮范围、晕眩回复）和极低数值综合词缀（如 +15 生命、+12% 抗性）频繁触发 0 结果，同时遗漏了大量真正决定装备价格的维度（如 6L、高 DPS / 高三防、高等级/高品质宝石、84+ 底材、星团大天赋、普通/深渊珠宝、腐化/忆境基底、变体型传奇词缀与核心 Roll）。此外，普通稀有装备默认锁定具体底材以及将“工艺 / 焚界者 / 灭界者 / 影匿”等低价值状态强制初始化为“是”，也会进一步造成查价条件过度收窄。

## What Changes

- **声明式高价值智能预选引擎**：新增独立、纯本地的声明式预选规则引擎（基于稳定英文 `ref`、物品大类、词缀来源/类型、`tier` 与数值门槛，国服/国际服通用），替代原有的 T1/T2 一刀切逻辑作为 `initialSelection = 'auto'` 的默认策略，并保持 `auto / all / none` 三档设置不变。
- **高价值白名单与优先级上限**：普通未收录的 T1/T2 词缀默认不再自动预选；当命中的高价值项过多时，按优先级截断（如普通稀有装备最多预选 4~5 项），避免过拟合导致 0 结果。
- **聚合属性预选与局部词缀吸收**：高 pDPS / eDPS 武器与高护甲 / 闪避 / 能量护盾防具自动预选对应聚合属性，并抑制已被其覆盖的局部伤害/防御词缀；6L、高等级/高品质宝石（如 20+/20% 或觉醒 5+）、高物等做装底材（84+/86+）及 84+ 星团自动预选对应属性。
- **综合词缀（Pseudo）按部位阈值与分裂保护**：为总生命、总元素抗、总混沌抗以及扩展的高价值综合项（移速、单/全属性、全域暴伤、攻施速、攻击元素伤、饰品/珠宝 ES 等）按物品部位设置数值门槛；来源包含高价值分裂词缀（`fractured`）时保留分裂词缀本身不被普通综合项吞掉；纯工艺来源构成的综合项不默认启用。
- **特殊品类与特殊基底精细化**：
  - 传奇装备自动预选腐化基底（`sourceSubtype === 'corrupted'`）、多变体传奇的核心随机词缀（如禁断之火/肉、守望之眼、先祖之声、巨光谱等）及极少数关键 Roll（如法师之血药剂数）；
  - 星团珠宝自动预选附魔 + 全部大天赋（Notables），对“增加 # 个天赋技能”自动设置精确上下限 `min = max = 原值`，84+ 物等同时预选 `ilvl`；
  - 普通/深渊珠宝、药剂/酊剂、忆境基底及高价值焚界/灭界基底纳入专属白名单预选。
- **BREAKING（规格升级）稀有装备底材与状态过滤默认策略优化**：
  - 普通稀有装备（武器/防具/饰品/普通与深渊珠宝）在 `auto` 模式下默认取消具体底材改按大类查价，仅保留传奇、通货、宝石、地图/海图/日志、星团、白/蓝做装底材及高价值特色底材的默认底材勾选；
  - 状态过滤保留高价值结构状态为“是”（未鉴定=否、忆境、分裂之物、秽生、复制），将易造成误过滤的 `工艺`、`焚界者`、`灭界者`、`影匿` 以及普通黄装上的非关键腐化/单势力默认放宽为“任意”（或按物品底材类型决定是否默认勾选经典势力）。
- **浮窗可解释性与快捷操作**：保持浮窗紧凑布局与原顺序，为属性与词缀行补充轻量 tooltip 解释预选/未预选原因（如“高价值词缀”“已被总护盾覆盖”“超过自动预选上限”），并在词缀区标题旁提供当前物品级别的“恢复自动 / 清空”快捷按钮。

## Capabilities

### New Capabilities
- `price-check-auto-selection`: 定义基于稳定英文 ref 与物品大类的声明式高价值智能预选规则引擎，覆盖白名单评分、优先级上限、聚合属性吸收局部词缀、综合词缀部位门槛与分裂保护、特殊品类（传奇变体与腐化基底、星团大天赋与精确天赋数、普通/深渊珠宝、药剂/酊剂、忆境与双王基底）及预选原因元数据。

### Modified Capabilities
- `cn-price-check`: 修订自动初选词缀/属性规则、非传奇普通稀有装备的具体底材默认策略、以及 `stateFilters` 与经典势力的默认初始化行为；补充星团珠宝大天赋预选、84+ 物等预选与精确天赋数上限。
- `cn-price-check-overlay`: 补充查价浮窗的预选原因 tooltip 展示、词缀区“恢复自动 / 清空”快捷操作，以及与稀有装备默认大类查价一致的名称行初始状态约定。

## Impact

- 核心模块：新增 `electron/modules/priceCheck/autoSelect.js`（及规则配置 `autoSelectRules.js`），更新 `electron/modules/priceCheck/query.js`、`electron/modules/priceCheck/pseudo.js`、`shared/priceCheckMetadata.js`。
- 浮窗前端：更新 `src/domains/priceCheck/PriceCheckOverlayView.vue`（保持向后兼容，预选原因仅作为可选展示元数据，不影响官方查询协议）。
- 测试与规范：新增覆盖全品类与边界场景的智能预选单元测试，同步更新受既有默认策略变更影响的现有查价测试与 OpenSpec 规格文档。
