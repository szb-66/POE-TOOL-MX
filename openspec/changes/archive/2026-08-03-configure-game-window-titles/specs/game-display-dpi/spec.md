## MODIFIED Requirements

### Requirement: 自动检测游戏窗口 DPI
系统 MUST 在 Windows 上使用用户配置的游戏窗口名称列表识别顶层窗口，并读取所选游戏窗口的实际 DPI 倍率；跨名称候选 MUST 先按配置顺序选择，同一名称内再按前台状态和可见面积选择。

#### Scenario: 高优先级名称窗口存在
- **WHEN** 存在分别匹配不同配置名称的多个候选窗口，即使低优先级名称窗口位于前台
- **THEN** 系统选择匹配最靠前配置名称的可用窗口并返回其 DPI、倍率和标题

#### Scenario: 同一名称的前台候选
- **WHEN** 同一配置名称存在多个匹配候选且其中一个位于前台
- **THEN** 系统返回该前台游戏窗口的 DPI、倍率和标题

#### Scenario: 同一名称的多个非前台候选
- **WHEN** 同一配置名称存在多个可见匹配窗口且均非前台
- **THEN** 系统选择可见面积最大的非最小化窗口

#### Scenario: 未找到游戏窗口
- **WHEN** 没有可用的匹配窗口或检测环境不可用
- **THEN** 系统返回结构化失败结果而不阻断应用启动
