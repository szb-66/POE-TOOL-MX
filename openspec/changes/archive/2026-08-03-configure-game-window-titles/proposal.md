## Why

游戏窗口识别目前在主进程和多个 Python 自动化脚本中分别硬编码中文、英文标题，用户无法适配其他客户端标题或明确控制多个候选窗口的选择顺序。需要提供统一、可持久化且可热更新的窗口名称配置，避免不同模块识别结果不一致。

## What Changes

- 在系统设置中提供游戏窗口名称列表，支持新增、编辑、删除和拖拽排序。
- 使用不区分大小写的包含匹配，并以列表顺序作为跨名称候选窗口的最高优先级。
- 将配置同步到主进程与所有 Python 自动化脚本，运行中的长期任务无需重启即可读取更新。
- 缺失或损坏的旧配置回退到“流放之路”“Path of Exile”默认列表。

## Capabilities

### New Capabilities

- `game-window-title-configuration`: 定义窗口名称列表的编辑、校验、持久化、优先级匹配和运行时热更新行为。

### Modified Capabilities

- `game-display-dpi`: DPI 自动检测改为使用可配置名称及其优先级选择游戏窗口。
- `combat-assist`: 前台安全校验改为使用可热更新的窗口名称列表。
- `map-rolling-foreground-start`: 地图洗练的窗口查找与激活改为使用可配置名称优先级。

## Impact

- 设置 Store、系统设置页、渲染进程 Electron API、preload IPC 与主进程系统处理器。
- 主进程 DPI 窗口选择和用户数据目录中的共享运行时配置。
- 制作、地图、战斗、背包、仓库取件、混沌配方、九宫格与仓库页选择 Python 脚本。
- 新增配置规范化、IPC、候选排序、脚本热更新和设置交互测试；不新增第三方依赖。
