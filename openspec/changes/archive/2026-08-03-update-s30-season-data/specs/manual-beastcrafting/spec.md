## MODIFIED Requirements

### Requirement: 装备野兽工艺目录可审计
系统 SHALL 提供以 POE1 3.29 规则为版本基线的装备相关野兽工艺目录，并为每条配方显示作用、条件、主要野兽、后果、可执行状态和不可执行原因。系统 MUST NOT 将缺少可靠底材或结果池的数据伪装成可执行模拟。

#### Scenario: 查看 S30 配方边界
- **WHEN** 用户进入野兽工艺页签
- **THEN** 系统列出 3.29 当前的可执行装备配方
- **AND** 旧二分与三分配方不再作为可执行动作出现

### Requirement: 魔符破裂替代旧分裂配方
系统 SHALL 按 3.29 规则声明破裂至少四条或六条词缀稀有魔符的配方已替代旧二分/三分配方。由于当前装备模型不包含魔符底材，系统 MUST 禁用这两条新配方并显示准确原因，且 MUST NOT 生成 Split 副本。

#### Scenario: 查看魔符破裂配方
- **WHEN** 用户查看 3.29 野兽目录
- **THEN** 两条魔符破裂配方显示为不可执行
- **AND** 原因说明缺少魔符底材模型

#### Scenario: 调用旧分裂 ID
- **WHEN** 客户端尝试执行旧二分或三分配方 ID
- **THEN** 系统将其作为未知当前配方拒绝
