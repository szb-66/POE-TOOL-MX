## Context

JavaScript 匹配器及 Python 模板分别判断制作类别，两处均只接受异界地图与地图。解析器已有通用数量、稀有度和详细词缀字段。

## Goals / Non-Goals

目标：两端同步放行裂隙之石并统一扫描和制作等级日志。
非目标：新增配置、预设迁移、页面说明及专用词缀目录。

## Decisions

- 在两端现有 atlas 类别白名单加入裂隙之石，保留原始类别，不伪装为地图。
- 增加任务物品标记排除；其他制作状态机保持复用，避免复制通货流程。
- 扫描及鉴定等级日志调用既有等级辅助函数，裂隙之石使用解析结果 level。
- 统一识别不同长度分隔线；详细邀请文本仅从属性头内收集词缀，防止背景描述参与筛选。
- 按用户确认共用完整地图联想，而非创建独立邀请目录。

## Risks / Trade-offs

- 共用目录包含邀请无法生成的词缀 → 保留用户已确认的完整联想策略。
- 地图专属属性无法满足 → 按既有零值规则，由用户关闭不适用条件。

## Migration Plan

无需数据迁移。开发版回归验证，撤回类别和等级调整即可回滚。
