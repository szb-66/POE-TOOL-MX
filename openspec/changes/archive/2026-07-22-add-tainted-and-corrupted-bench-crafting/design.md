## Context

装备状态已能表达品质、孔色、连接、腐化和瓦尔隐式，动作系统也支持注入确定性随机数与复合成本。缺口是：普通通货会被腐化门禁挡住，但当前没有受控的污秽动作；工艺台目录主要面向显式词缀，没有独立表示腐化装备孔位工艺的双通货成本。

当前可靠资料只完整公开部分污秽通货的结果概率。污秽工匠石与链结石增减各 50%，幻色石忽略属性需求；品质通货只公开随机值上限 20%，没有公开分布；污秽崇高、混沌和神泪的精确结果权重也没有官方可用公式。准确模拟要求把“知道作用”和“知道概率”分开。

## Goals / Non-Goals

**Goals:**

- 实现三种结果边界可证实、且现有装备状态能够完整表达的污秽孔位通货。
- 实现腐化装备确定性的孔数、连接和颜色工艺台操作与双成本。
- 所有随机动作可注入随机数、可预见、可撤销，并给出清楚的结果摘要。
- 对未知权重、缺少传奇库或已从游戏删除的通货给出准确状态。

**Non-Goals:**

- 不猜测污秽崇高、污秽混沌、污染神泪的精确结果概率。
- 不实现污秽神秘石的传奇转化/摧毁结果，也不建立传奇物品库。
- 不恢复已移除的污秽祝福。
- 不实现全部历史工艺台配方或通货市场价格。

## Decisions

1. **污秽动作使用独立规则层。** 新增纯函数集中处理腐化、物品类别、孔位上限与边界；动作提供器只负责成本、随机源、历史和词缀生成。这样不会通过放宽普通通货门禁意外允许其它通货修改腐化装备。

2. **只执行概率已知或结果无需未知分布的动作。** 幻色石为每个孔独立等权抽取红/绿/蓝；工匠石和链结石在两种方向都合法时各 50%，到达边界时只执行仍合法的方向。品质通货不伪造均匀随机分布，作为已知作用但未支持概率的动作展示。污秽崇高、混沌、神泪和神秘石同样禁用并说明各自缺口。

3. **连接状态保持为标准链组。** 污秽链结石只修改最大连接组：增加时把一个未连接孔并入最大组，减少时从最大组移出一个孔；不足两孔时不可使用。相同大小的最大组用确定性随机数选取，确保预见与执行一致。

4. **腐化工艺台是独立确定性动作集。** 动作直接设置目标孔数、最大连接数或指定颜色约束，成本同时保存普通通货和等量瓦尔宝珠。定孔数配方按游戏规则忽略物品等级、但继续受底材孔上限限制；连接与颜色配方验证当前孔数。不会把这些操作伪装成显式工艺词缀。

5. **支持级别进入动作元数据。** 通货记录区分 `supported`、`known-effect-unknown-odds`、`missing-item-model` 和 `removed`。前端保留不可执行卡片和原因，帮助用户知道通货作用，同时避免把缺失能力误解为游戏规则禁止。

## Risks / Trade-offs

- [边界时增减概率是否重抽没有完整官方文字] → 只在唯一合法结果时执行该结果，并在帮助页披露；核心 50/50 只用于两侧都合法的状态。
- [污秽幻色石公开资料只说明忽略属性需求] → 采用社区长期验证的三色等权模型并标注来源级别，不影响孔数和连接。
- [工艺台配方成本可能随版本变化] → 动作定义绑定当前数据版本并用快照测试锁定，不从价格服务读取。
- [旧状态缺少动作支持级别] → 该字段只属于目录/动作定义，不需要迁移用户装备状态。

## Migration Plan

1. 加入纯规则和动作目录，再接入既有装备状态与历史生命周期。
2. 增加腐化工艺台双成本与界面分组，不改变原显式工艺动作。
3. 补齐帮助、禁用原因、确定性和全量回归测试。
4. 若验证失败，删除未接通的动作注册和兼容分支，保留上一阶段的瓦尔实现。

## Open Questions

- 污秽崇高、混沌、品质通货和神泪的服务端权重是否会由可审计数据源公开；公开前保持不可执行。
