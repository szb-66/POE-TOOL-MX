## ADDED Requirements

### Requirement: 花园数据更新合并 3.28 憎恨结晶目录
数据生成器 MUST 从当前 POEDB 花园表格保留憎恨结晶参与的 11 项装备工艺与 1 项宝石转换，按稳定 ID 去重并保存完整多资源成本。复合中文效果中的保证标签 MUST 按实际标签语义解析，重新生成内置快照不得丢失或错分这些条目。

#### Scenario: 掉落属性标签
- **WHEN** 花园效果为“其中包括一个掉落属性”
- **THEN** 生成结果将保证标签保存为 `drop` 而不是 `attribute`
- **AND** 保存活性黄晶命能与憎恨结晶两项成本

#### Scenario: 重复稳定记录
- **WHEN** 抓取页面返回稳定 ID 相同的工艺行
- **THEN** 生成器只保留一项，并保留完整效果参数和多资源成本
