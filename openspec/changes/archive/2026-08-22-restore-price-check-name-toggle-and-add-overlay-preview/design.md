## Context

查价浮窗目前由 `PriceCheckOverlayView.vue` 同时负责渲染、维护本地筛选状态和桥接 Electron 查价 API。名称行使用带 `role="checkbox"` 的 `div` 模拟复选框，而组件的生命周期会无条件读取真实浮窗状态、注册监听并在设置变化时持久化。设置页“覆盖层”已经用 `business-overlay-theme` 内嵌制作覆盖层预览，但尚不能安全复用查价浮窗。参见 `proposal.md` 的动机和三个 delta spec 的行为边界。

物品大类由共享查价元数据映射到官方 trade API 枚举；解析器能识别“地图”和“异界地图”，但当前映射仅覆盖“地图”，因此“异界地图”模型缺少 `map` 约束并触发名称不可关闭的安全保护。

本次变更跨越共享查价元数据、查价浮窗组件和设置页，因此需要在不改变真实 IPC、持久化结构及网络查询契约的前提下显式隔离预览运行环境。工作区存在其他未提交改动，实施时只修改本变更所需文件并保留其余状态。

## Goals / Non-Goals

**Goals:**

- 让名称筛选使用浏览器原生可访问交互语义，同时沿用当前物品级 `identity.nameEnabled` 状态。
- 让真实查价浮窗组件可以在设置页以纯本地状态运行，且从结构上阻断 Electron、网络、设置同步和外部窗口副作用。
- 让预览样例可重复、可重置，并能覆盖名称、属性、状态、词缀、折叠区及查询设置的主要布局。
- 保持真实浮窗默认入口和既有调用方行为不变。

**Non-Goals:**

- 不在预览中显示真实挂单、模拟登录状态或读取剪贴板/游戏窗口。
- 不新增或修改 IPC 通道、查价设置字段、查询 payload 结构或服务器接口。
- 不将预览中的任何修改写入 Pinia、磁盘或真实查价浮窗。
- 不重构所有模拟复选行；本次仅修复名称行的回归。

## Decisions

### 1. 名称行改为整行 `label` 包裹原生 `input[type="checkbox"]`

名称行保留现有 `filter-row`、`enabled` 和 `disabled` 视觉状态，但交互核心改为原生复选框。整行 `label` 让点击文字和空白区域都切换控件；Space 由浏览器原生处理，Enter 通过控件键盘处理函数显式切换。状态写入函数接收目标布尔值，避免 `label` 点击和 `change` 事件造成双重反转。大类不可用时控件保持选中并设置 `disabled`，旁边继续显示原因。

选择原生控件而不是继续增强 ARIA `div`，因为原生控件提供稳定的焦点、Space、禁用和辅助技术语义，也让选中标记不再依赖整行背景是否明显。不会把所有筛选行同时迁移为原生控件，因为这会扩大变更范围并影响包含输入框的复合行。

### 2. 在共享大类映射中将“异界地图”作为 `map` 的合法别名

扩展现有地图类别条目，使“地图”和“异界地图”都归一化到官方 `map`，并保持相同中文展示标签。查询构建仍使用现有类别约束逻辑：名称关闭时删除 `name` 和具体 `type`，但保留映射后的 `category` 以及其他过滤条件。

选择修复共享映射而不是在 UI 中绕过 `canToggleName`，因为缺失的官方大类才是禁用状态的根因；绕过保护会允许无身份约束的宽泛查询。

### 3. `PriceCheckOverlayView` 通过显式 props 支持预览模式

组件新增默认关闭的 `previewMode`、`previewState` 和 `previewOptions` 输入。真实路由未传入 props 时继续走原有生命周期和 Electron API。预览模式初始化时深拷贝输入状态和选项，跳过 `getOverlayState`、`onOverlayState`、`onSettingsChanged` 以及渲染完成通知；查询设置变化只修改组件本地 `reactive` 对象。

所有可能产生副作用的函数仍增加预览守卫，形成第二层保护：关闭、搜索、网页市集、加载更多、价格分布加载、目录重试、身份/词缀解析和复制私聊不会调用 Electron API。设置页样例不提供真实结果或待解析项，同时搜索、网页市集和关闭按钮在模板层禁用并给出提示。这样即使未来样例扩展到其他状态，也不会仅依赖当前 DOM 可达性保证安全。

选择在现有组件内建立显式运行模式，而不是复制一份预览组件，因为复制会使真实浮窗和排障预览逐渐产生布局与交互偏差。也不通过全局 mock Electron API，因为 mock 会隐藏遗漏调用，且可能污染设置页其他业务组件。

### 4. 预览数据由无状态工厂生成，设置页通过实例键完成彻底重置

在查价领域内新增预览样例工厂，返回全新的状态与查询选项对象。固定传奇头盔样例包含名称、官方头盔大类、基础属性、状态事实/筛选和已识别词缀，不包含真实账号、查询结果或外部 URL。设置页持有当前样例和组件实例键；“重置预览”重新调用工厂并更新键，使组件的折叠状态等非输入局部状态也恢复初始值。

选择工厂而不是共享常量加浅拷贝，是为了防止 Vue 对嵌套属性、词缀和状态筛选的修改污染下次重置或其他预览实例。实例键重建比逐个暴露 reset API 更不易漏掉新增的局部状态。

### 5. 设置页提供受约束的内嵌布局模式

在“覆盖层”面板现有制作覆盖层卡片后加入全宽查价预览卡片，容器继续应用 `business-overlay-theme`。组件在预览模式下增加根样式类：取消真实窗口拖拽语义，使用容器高度而不是 `100vh`，并让内容区在固定高度内滚动。设置页负责响应式外框和用途说明，组件负责自身内部滚动。

选择通过模式类覆盖尺寸，而不是让设置页强制穿透 scoped 样式，因为尺寸语义属于组件运行模式；这也减少对 Vue scoped 选择器实现细节的依赖。

### 6. 测试同时覆盖纯逻辑、组件契约和设置页集成

查询测试直接验证名称关闭后的 `name`/`type` 省略、下一模型默认状态和“异界地图”到 `map` 的映射。预览样例工厂测试验证不同调用返回深度独立对象。Vue 源级集成测试验证原生复选框、预览 props/生命周期守卫、禁用操作、设置页位置和重置连接；现有主题测试继续确保内嵌组件继承共享覆盖层变量。最后运行完整测试、构建和差异检查，并仅在开发版进行人工交互验证。

当前项目的 Vue 测试以 Node 源级集成断言为主，因此本次沿用现有测试形态，并用查询与样例工厂的可执行测试覆盖关键状态逻辑。无需为此引入新的浏览器测试依赖。

## Risks / Trade-offs

- [Risk] 预览分支遗漏一个新增 Electron 调用，导致设置页出现副作用 → 生命周期入口与每个副作用函数同时守卫，并用源级回归测试枚举禁用路径。
- [Risk] props 输入被嵌套修改，导致设置页持有的样例也发生变化 → 组件初始化和样例工厂都创建深拷贝，重置时重建整个组件实例。
- [Risk] 原生复选框的 `label` 点击与键盘处理重复触发 → 仅在 `change` 中提交鼠标/Space 的目标值，Enter 单独计算并提交一次，不在 label 上继续绑定通用反转处理。
- [Risk] 固定高度在窄窗口中压缩内容 → 容器设定合理的固定/最大高度和内部滚动，设置页卡片保持全宽并沿用现有响应式布局。
- [Trade-off] 预览不会覆盖真实结果列表与登录/网络错误状态 → 样例专注于本次排查所需的布局、主题和筛选交互，避免给用户造成真实挂单的误解。

## Migration Plan

1. 先落地共享类别别名和回归测试，再修改名称原生交互。
2. 增加无状态预览样例工厂与组件预览模式，验证所有 Electron 入口在预览中不可达。
3. 将预览接入设置页覆盖层面板，并完成主题、尺寸、重置和提示测试。
4. 运行定向测试、完整 `npm test`、`npm run build`、`git diff --check` 和 OpenSpec 严格校验；只在开发版人工检查。
5. 若需回滚，移除设置页预览入口和组件预览 props/样例工厂，并恢复名称模板与类别别名；没有数据迁移、设置迁移或远程资源需要恢复。
