## Context
当前服务和仓库持有账本、祭坛与求解器，设置嵌套策略与校准；已有截图校准修改需保留。
## Goals / Non-Goals
切断移除能力的全部数据流，保留共享识别、安全门禁和两种实战策略；不打包。
## Decisions
拆分策略与校准组件。保留规划入口但只调用实战算法。删除账本与装备输入，复制效果仅说明机制。保留存储 schema 兼容，新增路线版本标记使旧路线失效；旧策略显式重置，旧专属字段不加载、不保存。相较只隐藏页面，完整清理避免隐性旧数据影响推荐。
## Risks / Trade-offs
共享识别误删 → 回归房间奖励、资源和效果。旧快照携带专属字段 → 投影清理并测试迁移。已有修改冲突 → 基于工作区当前内容编辑。
## Migration Plan
读取时迁移，下次正常保存精简结构；提示重新采集旧路线。验证相关与全量测试、Vite 开发转换和 Electron 开发启动。
