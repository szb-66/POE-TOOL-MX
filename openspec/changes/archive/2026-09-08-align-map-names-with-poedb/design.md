## Context
共享目录中 75 个条目有 42 个差异、7 个一致、26 个未出现在页面。历史数据由 createMapRun 规范化，展示使用 mapLabel。

## Goals / Non-Goals
统一当前与历史译名，不修改接口、记录结构或游戏交易数据。

## Decisions
- 从页面 AtlasNode 区域 ID 与中文标签提取静态目录，保留不在页面中的旧映射，消除 AREAS 内地图覆盖项。
- 历史记录优先按区域 ID 取标准名称；仅无可识别 ID 时转换无歧义旧译名，避免 Strand/Atoll 名称碰撞。
- 记录模型统一规范化，筛选与统计前已生效；不批量改写历史文件。

## Risks / Trade-offs
页面仅覆盖当前舆图 → 未收录项保留原值，不宣称已验证。

## Migration Plan
加载时转换，之后正常保存写入新名；无需数据结构迁移。开发版验证，不打包。
