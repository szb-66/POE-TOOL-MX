## Context

应用已通过 `persist:poe-cn-auth` Session 支持国服网页登录和手动 `POESESSID`，但认证对象被组合在混沌配方领域内。物品解析器可以识别详细复制格式，覆盖层和快捷键框架也已存在。腾讯交易搜索使用未公开的站内 `/api/trade/search` 与 `/api/trade/fetch` 接口；物品和词缀 stat ID 不能从国服公开数据接口稳定获取，因此必须使用版本化本地目录。

## Goals / Non-Goals

**Goals:**

- 在游戏内通过一个快捷键查询当前国服物品的官方挂单。
- 共享现有国服认证且不向渲染进程暴露 Cookie。
- 支持固定物品与稀有/魔法装备的可解释筛选。
- 对目录陈旧、接口变化、限流和会话失效安全降级。

**Non-Goals:**

- 自动私聊、购买、上架或模拟游戏输入完成交易。
- 将挂单样本声明为真实成交价或使用 AI/OCR 预测替代官方查询。
- 首版实现批量兑换和历史行情。

## Decisions

1. **共享认证实例而非复制 Cookie。** `PoeCnAuthService` 仍持有唯一 Session，由混沌配方和查价服务注入使用；后续再按目录物理迁移，不改变现有持久分区，避免用户重新登录。
2. **Provider 隔离腾讯接口。** `PoeCnTradeClient` 负责固定 Origin、请求头、超时、响应校验、401/HTML 识别、限流和缓存；领域服务只处理标准化查询与结果。
3. **官方目录优先并保留版本化回退。** 登录 Session 可用时从腾讯官方 `/api/trade/data/stats` 构建完整运行时目录；接口不可用时回退受版本控制的最小目录。生成器仍接受 NDJSON，拒绝重复 ID、无效 matcher 和不唯一映射。
4. **直接采用 Awakened PoE Trade 的查询语义。** 固定上游提交 `18a401efce4683a274978e3f41ce08ac8948732b`，采用其 `pathofexile-trade.ts`、`create-item-filters.ts` 和 `create-stat-filters.ts` 中的在线状态、按需过滤组与宽松默认。项目只做 JavaScript、腾讯端点和简体中文模型适配；普通稀有装备初次查询不自动启用显式词缀、物品等级或普通品质，用户可在浮层手动启用词缀并编辑 80% 下限。
5. **覆盖层由主进程拥有生命周期。** 快捷键读取 Electron clipboard，打开单实例无边框置顶窗口；渲染端通过窄 IPC 请求更新筛选或打开官方页面。主窗口增加查价页用于登录、赛季和快捷键状态诊断。
6. **只展示可验证的挂单统计。** 过滤本人、无价格和无效价格，按卖家去重后展示排序结果与样本中位数，并固定显示“挂单参考，不代表成交价”。

## Risks / Trade-offs

- [腾讯站内接口无公开稳定性承诺] → 集中封装、严格校验响应，并提供打开官方市集和接口不兼容错误。
- [国服交易目录可能落后赛季] → 元数据显示陈旧状态；名称查价可继续，无法可靠映射的词缀禁用而不是猜测。
- [恶意低价和重复卖家扭曲样本] → 排除本人、按卖家去重、同时展示原始挂单，不把中位数命名为公平价。
- [快捷键与现有动作冲突] → 纳入统一快捷键事务注册和回滚。
- [复用认证会让注销影响两个功能] → UI 明确共享账号状态，注销时同步清除两个领域缓存。

## Migration Plan

1. 保留 `persist:poe-cn-auth` 和现有 IPC，先让两个服务共享同一认证实例。
2. 加入目录、Provider、领域服务和测试，再注册新增 IPC。
3. 加入覆盖层路由、主页面、快捷键与帮助文本。
4. 若功能回滚，移除新 IPC/路由/快捷键即可；既有 Session 与混沌配方数据无需迁移。

## Open Questions

无。首版默认快捷键为 `Ctrl+D`，默认使用上游 `available` 状态查询国服可交易的在线挂单，赛季沿用国服账号当前选择并允许在查价页单独切换。
