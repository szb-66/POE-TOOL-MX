## ADDED Requirements

### Requirement: GPU 退出必须按首次挂载状态分流

系统 MUST 在首次渲染器挂载完成后将 GPU 子进程异常退出作为运行期诊断事件，保留原因码、进程类型及退出码，不得因此触发启动恢复、启动失败提示或应用退出。此规则优先于启动 30 秒恢复窗口，适用于安全模式与重复事件。正常退出和应用关闭期间保持现有静默行为。

#### Scenario: 挂载后仍在恢复窗口内
- **WHEN** 首次挂载完成后、启动 30 秒内 GPU 子进程崩溃
- **THEN** 系统记录故障但不重启、不提示启动失败、不退出应用

#### Scenario: 长时间运行或安全模式重复故障
- **WHEN** 首次挂载后超过 30 秒或处于安全模式，GPU 子进程一次或多次异常退出
- **THEN** 每次异常均保留诊断且不触发启动恢复、启动失败提示或应用退出

#### Scenario: 首次挂载前 GPU 故障
- **WHEN** GPU 子进程在首次挂载完成前异常退出
- **THEN** 系统继续执行现有启动诊断策略，符合条件仅恢复一次，不能恢复则提示诊断位置
