## Context

手动制作状态已有普通固有词缀、古灵隐式、孔位/连接和 `corrupted` 标记，但没有瓦尔隐式容器与腐化结果。POEDB 3.28 的瓦尔宝珠页面包含 463 条跨装备/地图/药剂等类别的腐化隐式记录；当前规划器只支持非传奇装备与普通珠宝，不能把全部页面记录无条件放入装备池。

## Goals / Non-Goals

**Goals:**

- 用离线原始快照建立按装备类别、物品等级和权重过滤的瓦尔隐式目录。
- 对当前可表达的非传奇、非珠宝装备实现四类等权瓦尔宝珠结果。
- 保持确定性随机、历史、预见和装备卡展示的一致性。
- 为后续污秽通货提供明确的已腐化状态边界。

**Non-Goals:**

- 不实现传奇物品、专属珠宝变形、地图、药剂、宝石或精华柱腐化。
- 不实现阿兹瓦特双瓦、巨灵触碰/易爆瓦尔宝珠及全部污秽通货。
- 不宣称稀有重铸孔位模型为官方精确概率；未知部分必须版本化并在 UI 披露。

## Decisions

1. **腐化隐式作为独立数据族。** 数据集增加 `corruptedImplicitFamilies`，每条保存效果、需求等级、适用类别、权重、数值范围和标签。它不进入显式词缀三级目录，也不与古灵隐式复用来源字段，避免错误参与显式 Mod Group 和催化剂侧别规则。

2. **四个主结果等权选择。** 普通装备使用 `implicit`、`white-sockets`、`rare-reforge`、`no-change` 四项各 25%。白孔结果先随机变白一个非白孔，再对其余孔逐个以 10% 判定；无孔装备允许产生表面无变化结果。

3. **腐化隐式替换一个既有隐式槽。** 候选按物品等级、类别和 POEDB 权重抽取；存在普通、追忆、古灵或既有瓦尔隐式时，从可替换隐式集合随机替换一条，并记录被替换来源。状态层显式保存瓦尔隐式与被抑制的原隐式标识，避免直接破坏底材定义。

4. **六词缀稀有重铸复用现有词缀池和元工艺。** 结果变稀有并尽量生成 3 前缀+3 后缀；锁定侧按现有元工艺保留。孔位和连接用独立、版本化的腐化经验模型重骰；官方仅公开六孔六连总体概率 1/144，因此不从该单点反推出所有孔位概率。

5. **不支持范围失败关闭。** 珠宝、传奇及非装备类别返回具体禁用原因，而不是退化成“仅腐化”。这样可以防止用户把缺失的专属转换结果误认为模拟准确。

## Risks / Trade-offs

- [POEDB 表格混有规划器不支持类别] → 解析后按显式白名单映射并验证每个可执行类别至少存在候选。
- [中文展示文本与内部 stat 文本可能并存] → 保存规范化展示文本和原始记录标识，无法生成可读文本的记录不进入执行池并由测试审计。
- [腐化重铸孔位完整概率未知] → 版本化、披露且只保证公开不变量，不伪称官方精确概率。
- [旧存档没有瓦尔隐式字段] → schema 规范化时默认空数组/空替换记录，保持旧会话可载入。

## Migration Plan

1. 新增并校验 `Vaal_Orb` 原始来源，再离线生成新 schema 数据集。
2. 旧状态规范化时补齐空腐化隐式状态；不回写用户原文件。
3. 注册动作与 UI 后运行真实快照、确定性生命周期、全量测试和生产构建。
4. 若新数据校验失败，继续使用上一份内置快照，不激活半成品。
