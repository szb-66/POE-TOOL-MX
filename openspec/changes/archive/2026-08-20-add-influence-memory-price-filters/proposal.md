## Why

国服详细复制文本中的六种经典势力尾标尚未完整转换为查价条件，“回忆束丝”数值也被解析器忽略，会使势力装备和带束丝装备的查价结果混入不同底材状态。需要按腾讯官方交易契约补齐这些可查询条件。

## What Changes

- 识别塑界者、裂界者、圣战者、救赎者、狩猎者和督军六种经典势力的当前及兼容尾标。
- 为已识别势力生成官方 `pseudo_has_*_influence` 查价条件，默认启用并允许用户取消；双势力物品同时生成两条。
- 解析 `回忆束丝: N` 并在物品属性过滤中默认启用“至少 N”，写入官方 `misc_filters.memory_level`。
- 对势力条件和束丝数值继续执行主进程白名单清理，防止渲染层伪造物品事实或官方字段。

## Impact

- 影响 Electron 物品剪贴板解析、查价模型/查询构建和查价浮窗现有过滤列表。
- 新增的对外查询字段仅使用腾讯官方已公布的 pseudo stat ID 与 `memory_level`，不增加依赖，不重生成交易目录。
- 保持忆境、焚界者、灭界者现有三态过滤语义不变。
