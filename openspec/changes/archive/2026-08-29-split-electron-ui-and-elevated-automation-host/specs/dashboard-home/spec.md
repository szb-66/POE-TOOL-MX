## MODIFIED Requirements

### Requirement: 简要系统健康状态
系统 SHALL 展示 Python 可用性、全局快捷键配置与注册健康状态和游戏窗口 DPI 状态；健康项不计入业务模块汇总。快捷键配置注册成功且前台监视正常时，系统 MUST 将快捷键视为正常，不得因游戏当前不在前台而要求用户处理。普通权限 MUST 被视为主界面的预期状态；首页 MUST NOT 增加 AutomationHost 专用健康状态机，加载和刷新 MUST NOT 启动 Host 或显示 UAC。

#### Scenario: 系统环境正常
- **WHEN** 主界面为普通权限且三项现有系统健康检查均正常
- **THEN** 系统以收起的简要状态呈现，不把 Host 尚未启动显示为异常

#### Scenario: 前台门禁正常暂停
- **WHEN** 快捷键配置注册成功、前台门禁开启且前台监视正常，但游戏当前不在前台
- **THEN** 快捷键健康项以绿色正常状态显示“快捷键已就绪（切回游戏后生效）”
- **AND** 标题不匹配、进程不匹配或未检测到前台窗口均不计入系统环境问题
- **AND** 系统不生成快捷键异常诊断或提供快捷键问题设置入口

#### Scenario: 游戏前台快捷键生效
- **WHEN** 快捷键配置注册成功、前台门禁开启且游戏位于前台
- **THEN** 快捷键健康项以绿色正常状态显示快捷键已注册并生效

#### Scenario: 快捷键注册失败
- **WHEN** 用户配置的快捷键注册失败
- **THEN** 快捷键健康项显示红色异常状态和注册失败信息

#### Scenario: 前台监视不可用
- **WHEN** 快捷键注册成功但前台监视器不可用，并已回退为全局生效
- **THEN** 快捷键健康项显示黄色需关注状态和回退说明

#### Scenario: 系统环境异常
- **WHEN** 任一现有健康检查失败或需要用户处理
- **THEN** 系统突出显示具体问题并提供既有设置入口

#### Scenario: 手动刷新
- **WHEN** 用户点击刷新
- **THEN** 系统重新查询普通权限可完成的运行时和环境状态
- **AND** 系统不启动 Host、不显示 UAC且不启动持续高频轮询

#### Scenario: Host 启动失败
- **WHEN** 用户启动输入操作时 UAC 取消或薄 Host 无法连接
- **THEN** 对应业务操作显示本次失败原因，首页不新增组件修复、任务版本或摘要健康项
