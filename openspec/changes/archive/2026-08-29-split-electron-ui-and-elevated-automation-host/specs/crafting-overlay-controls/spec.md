## MODIFIED Requirements

### Requirement: 物品制作重新开始使用最新配置
系统 MUST 在用户从完成态浮窗重新开始物品制作时，重新读取点击当下已保存的当前物品预设与全部制作设置，并 SHALL 通过与主界面启动相同的校验、DPI 刷新、`validatedConfig` 生成和固定 `crafting.items` 输入操作链路启动新任务。系统 MUST NOT 重放上一次成功任务的脚本文本、脚本路径、操作请求或预设快照。

#### Scenario: 完成后修改词缀组合
- **WHEN** 用户保持完成态浮窗打开，在主界面删除原命中组合后点击“重新开始”
- **THEN** 新任务不包含已删除组合并只按最新组合判断

#### Scenario: 配置没有修改
- **WHEN** 用户未修改配置并点击“重新开始”
- **THEN** 系统仍从当前持久化配置生成新的请求标识、校验配置并提交固定输入操作

#### Scenario: 最新配置无效
- **WHEN** 最新配置缺少有效组合、全部组合停用、坐标缺失或其他启动校验失败
- **THEN** 系统不得启动 Python 任务或回退旧请求
- **AND** 浮窗保留完成画面并显示具体失败原因

#### Scenario: 防止重复重新开始
- **WHEN** 用户连续点击“重新开始”
- **THEN** 首次请求完成前不得发起第二次启动
