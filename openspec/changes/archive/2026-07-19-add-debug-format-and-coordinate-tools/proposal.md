## Why

当前应用缺少可持久化的控制台调试入口，用户也无法直接确认游戏剪贴板文本是否仍符合解析器支持的格式；同时，设置中的大量屏幕坐标只能手工测量和录入。这些问题会放大游戏版本更新、DPI 缩放和多显示器环境下的排查与配置成本。

## What Changes

- 在设置中增加调试模式开关，持久化控制 Electron 主窗口开发者工具的显示状态，并与快捷键和手工关闭保持同步。
- 在物品和地图页面展示解析器当前支持的中文客户端剪贴板格式摘要与可展开示例。
- 为设置页中的点位坐标增加跨显示器点击取点能力，支持取消、异常清理和即时保存。
- 统一点位坐标为 Windows 物理屏幕像素，允许位于主屏左侧或上方显示器产生的负坐标，并修正脚本中的重复 DPI 换算。
- 为展示的格式示例增加解析回归测试，防止示例与实际解析能力漂移。

## Capabilities

### New Capabilities

- `debug-console-mode`: 设置、持久化和同步应用控制台调试面板的可见状态。
- `supported-item-format-guidance`: 在物品与地图页面展示当前解析器支持的剪贴板文本格式。
- `screen-coordinate-picker`: 通过跨屏取点层选择并保存设置中的物理屏幕坐标。

## Impact

- 影响设置 Pinia store、设置页、应用启动流程，以及物品页和地图页的界面内容。
- 扩展 Electron 主进程窗口管理、IPC、preload 和渲染进程 API 封装。
- 新增无主布局的取点路由/页面，并调整 Python 自动化脚本和坐标校验规则。
- 不新增第三方运行时依赖；测试使用 Node.js 内置测试能力。
