## Context

本变更跨越 Vue 展示、制作数据派生、Electron 导航策略与 Python 背包检测进程。词缀数据已经包含 tier、generation weights、效果行和数值范围，但当前 UI 的归组/过滤会丢失成员并混用快照百分比；模板文件虽然被替换，渲染层和运行中检测器仍可能持有旧 URL 或旧进程配置。

## Goals / Non-Goals

**Goals:**
- 从同一份当前物品合法候选集派生词缀展示、分组和概率。
- 在不破坏已有会话的前提下改进装备、工艺与剧情布局。
- 建立外链统一出口，并让模板保存后立即刷新 UI/检测状态。
- 找出并修复背包子进程异常退出的真实原因，保留明确诊断信息。

**Non-Goals:**
- 不模拟 POE 未公开的生成算法或相互排斥词缀的多步联合概率。
- 不重新设计整个做装页面或背包识别算法。
- 不允许任意协议或任意文件通过外链接口打开。

## Decisions

1. 概率使用 `单项原始权重 / 当前来源与前后缀完整页面池总权重`，family 汇总概率使用 family 全部 tier 权重之和除以同一全局分母。分母必须在搜索过滤之前计算，且不得把 POEDB 的 `spawn_no`（做装状态的禁止生成标签）误当成底材正向标签。百分比按 POEDB 最终页面保留三位小数。这避免使用网页快照百分比，也避免 family 内或搜索结果内重新归一化造成误导。
2. 分组仅决定视觉层级，不再成为成员过滤依据；family 成员由稳定 ID 关联，归组后以原始合法/不可用全集做完整性校验，避免标题存在但某一同 family 词缀被文本去重吞掉。
3. 效果行与右侧 tier 元数据分栏。每个效果各占一行；右侧显示一次 tier/名称，并对多段数值使用“[a-b] 到 [c-d]”。固有词缀保留当前值，同时从结构化 roll range 生成括号范围。
4. 工艺详细开关是纯展示偏好，默认开启并持久化；名称和核心功能始终可见。
5. 渲染层拦截 HTTP(S) 导航并通过受限 IPC 调用 `shell.openExternal`；非 HTTP(S) 不发送，避免开放任意协议。
6. 模板保存结果携带版本戳，预览 URL 增加 cache-busting；若检测启用则安全重载配置/重启检测。子进程启动失败、退出码和 stderr 保留到结构化状态，而非统一覆盖成“异常退出”。
7. 剧情浮窗宽度作为持久化用户设置，通过受限 IPC 调整窗口宽度；高度仍由内容自动上报。同一技能组内技能标签不换列，始终按水平方向排列。
8. 背包 Python 脚本在开发态从模块相对的项目根目录解析，在打包态从 `resources` 解析，避免启动目录变化导致路径落到 `electron/src`。

## Risks / Trade-offs

- [同一词缀池仍受 spawn weight 标签规则影响] → 复用生成候选解析的最终有效权重，不直接相加原始 generation_weights。
- [大量分组计算影响渲染] → 在筛选条件变化时一次性计算总权重并缓存派生结果。
- [检测器热重启带来短暂无状态] → 显示“正在重新加载模板”，重启成功后清空旧识别稳定计数。
- [外链拦截影响内部路由] → 仅处理绝对 HTTP(S)，内部相对链接仍由路由器处理。
