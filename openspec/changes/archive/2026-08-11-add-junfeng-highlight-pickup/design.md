## Context

现有公共检测器只匹配仓库标题与背包标题，控制浮窗也只消费单一 `ready` 状态。现有仓库取件按格中央的单一统计阈值分类，并假定网格行列相同。君锋镇需要独立的奖励标题、12×11 网格和单帧分类，同时必须复用现有前台保护、自动化锁、窗口坐标与 Ctrl+点击时序。

## Goals / Non-Goals

**Goals:**
- 在不操作搜索框的情况下以单帧完成高亮识别。
- 普通仓库与君锋镇拥有独立检测条件和动态按钮。
- 识别核心支持任意行列网格、版本化模型和本机校准。
- 所有模糊或不兼容状态均保守拒绝点击。

**Non-Goals:**
- 不合并普通仓库与君锋镇的界面检测、网格配置和运行状态；二者仅复用分类模型与识别核心。
- 正式发布版不训练或重新导出 ONNX；开发版允许通过训练工作台调用独立 GPU 环境。
- 不执行安装包构建或正式版验证。

## Decisions

### 检测状态向后兼容扩展
公共检测器加载仓库、背包和奖励三类模板，分别输出 `stashReady`、`rewardDetected`、`junfengReady` 和各自分数；原 `ready` 保持等同 `stashReady`，避免现有消费者把奖励界面误认为仓库。控制浮窗在奖励匹配时给予君锋镇按钮显示优先级。

### 君锋镇使用独立运行管理器
新增君锋镇 manager/store/IPC，但共享自动化锁和控制浮窗。这样普通仓库的配置、状态和失败语义无需迁移，奖励标题消失也可以只停止君锋镇流程。

控制浮窗加载期间可能连续收到检测、锁和尺寸状态。加载感知发布器 SHALL 将同一 `WebContents` 的多次待发布状态合并为一个 `did-finish-load` 监听器，只发送最新状态，并在窗口替换、销毁或关闭时清理监听器，避免事件监听器累积。

### 识别核心使用版本化单帧模型契约
Python 识别器将框选区域按配置行列切格、归一化并批量送入 ONNX。模型必须输出三类 logits/probabilities 和 32 维 embedding；模型旁的 manifest 声明版本、输入尺寸、类别顺序和 SHA-256。阈值固定为 0.995，低于门槛只报告不确定。

运行时仅把模型版本、类别契约、输入定义、文件存在性与 SHA-256 完整性作为硬门禁。准确率验证结果作为训练工作台中的质量参考，不阻止当前有效模型执行取件；高置信阈值、低置信停止和转移确认继续约束实际点击。

### 本机校准采用样本近邻覆盖
校准入口展示单帧网格预测，用户只纠正错误格。保存原始 PNG 图块、标签和模型版本特征。推理时，若最近校准 embedding 的余弦相似度不低于 0.97，则采用距离加权的本机标签；否则保留基础模型输出。模型升级时重新嵌入原始图块。

### 候选按连通格归并并验证来源变化
高置信格以四邻域归并，每个连通组选择概率最高格中心点击。截图和分类前鼠标停到网格外；点击后直接预定位到下一候选，并以初始无悬停单帧比较当前来源组，未清空则重试一次，仍失败报告 `transfer-unconfirmed`。最后一件在点击前记录同悬停状态的局部确认基线，点击后鼠标留在原位完成比较，不再移出网格。不再把所有未变化情况归类为背包已满。

### 素材与模型分离
内置模型和 manifest 随源码/资源分发；用户校准保存在 `userData/junfeng-highlight/`。开发采样工具输出按会话组织的截图、网格元数据和标签，训练脚本按会话划分训练/验证集，避免同图格子泄漏。

## Risks / Trade-offs

- [当前模型的验证结果可能未达到建议标准] → 训练工作台明确展示误报、漏报和召回率，并要求训练后先运行检测预览；运行时继续以 0.995 阈值和安全停止降低误点击风险。
- [相邻不同物品可能被连通格合并] → 按初始高置信格生成候选，点击前逐格复检，已随多格物品清空的格直接跳过。
- [本机错误标签污染校准] → 校准入口显示原图和置信度，支持逐条删除与全部重置，并只对高相似素材覆盖。
- [模板检测扩展破坏现有 ready 语义] → 保留 `ready = stashReady`，新增字段由君锋镇独立消费。

## Migration Plan

新增配置采用缺省关闭且允许旧设置无损归一化。没有君锋镇配置或模型时，普通仓库、自动入库和混沌配方继续按原逻辑工作。回滚时删除君锋镇消费者与资源即可，旧配置字段会被旧版本忽略。

### 开发版通用网格训练工作台
工作台作为侧栏中的独立页面，不再嵌入背包配置页。页面内置君锋镇 12×11、小仓库 12×12 和大仓库 24×24 三种来源配置，各自保存框选区域与显示器/DPI 元数据。识别与切格实现不依赖正方形网格；每次截图记录来源域、行列数和稳定的 `previewId`。

用户纠正错误格后，可明确确认“整张已核对”，应用再将全部图块与最终标签写入独立训练仓库；未确认的模型预测不得自动成为训练真值。训练仓库与运行时近邻校准仓库分离，避免大量普通仓库样本改变君锋镇即时近邻覆盖行为。普通仓库素材可参与基础特征训练，独立质量评估只使用从未参与训练的君锋镇会话。

主进程仅在开发版查找 `.runtime/junfeng-training` GPU 环境，依次执行校准/会话导出、基础数据集合并、当前模型训练和独立验证。训练与正式取件互斥；候选 ONNX、manifest 与数据划分验证完成后才以带备份回滚的事务发布为当前取件模型，失败时保留原模型。零误报、召回率不低于 99% 且零高亮场景零点击仍作为建议质量标准和可选最终测试结果，但不再是运行时批准门禁。

### 可审计真值与三分数据集
工作台会话保存完整原图、每格原始图块、人工标签、来源域、用途、审计状态和修订号。历史会话可在软件内重新打开并以原图覆盖网格复核，修改后增加修订号；错误会话可整张删除。旧版未保存完整原图的会话使用原始图块重建网格，并明确提示信息降级。

数据用途分为训练集、调参验证集和最终测试集。验证与测试采集隐藏模型初判，避免确认偏差；用户可先批量标注全亮、全灰或空格，再逐格修正。验证集与最终测试集均不参与梯度训练，最终测试集至少包含三个已审计独立会话，并覆盖高亮、非高亮和零高亮场景。发布报告保存误报与漏报的会话、坐标、人工答案和概率，可从界面跳回原图复核。
