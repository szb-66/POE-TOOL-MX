## ADDED Requirements

### Requirement: 批量导入遵守运行时事务
系统 MUST 让配置导入复用持续功能的候选规范化、运行时先同步、串行提交和失败回滚语义；导入开始前已停止的输入功能 MUST NOT 因候选或回滚配置而重新启用。

#### Scenario: 批量候选同步成功
- **WHEN** 已选配置区块全部通过校验且运行时接受候选配置
- **THEN** 系统按一个导入事务持久化所有已选区块
- **AND** 相关持续输入功能保持关闭

#### Scenario: 批量候选同步失败
- **WHEN** 任一运行时拒绝批量导入中的候选配置
- **THEN** 系统恢复全部已选区块的上一份有效配置
- **AND** 不让较早成功的区块形成部分导入结果

#### Scenario: 快捷键候选注册失败
- **WHEN** 导入的快捷键集合无法完整注册
- **THEN** 系统保留原快捷键集合、持久值和主进程运行时状态
