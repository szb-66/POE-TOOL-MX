## ADDED Requirements

### Requirement: 剧情与技能预设可安全传输
系统 SHALL 允许逐个导出和导入剧情预设与技能预设。导入 MUST 深拷贝完整内容及进度、为预设和所有章节、步骤、技能组及技能实体生成新 ID，并 MUST 保持本地当前剧情与技能预设不变。

#### Scenario: 导入剧情预设
- **WHEN** 用户导入包含章节、步骤和当前进度的剧情预设
- **THEN** 系统创建结构独立且名称不冲突的新剧情预设
- **AND** 所有章节和步骤使用新 ID

#### Scenario: 导入技能预设
- **WHEN** 用户导入包含多个章节槽位的技能预设
- **THEN** 系统保留全部章节槽位和目录元数据
- **AND** 所有技能组及技能实体使用新 ID
