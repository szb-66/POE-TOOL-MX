## Context

公共解析器仅在名称和佣兵凭证判定中清除末尾价格标签，底材行未清理；查价直接使用 baseName。该解析器有多个调用方，需要统一身份语义。

## Goals / Non-Goals

**Goals:** 所有公共解析器身份赋值使用统一的方括号清理规则。

**Non-Goals:** 不增加接口字段，不清理整份文本，不改变词缀规则。

## Decisions

- 替换 stripInjectedPriceTag 为名称标记清理函数，以全局方括号匹配删除成对内容，保留不成对括号，再 trim。替代方案为查价端兜底，但会让其他调用方继续得到错误底材，故不采用。
- 名称、底材、海图身份及佣兵凭证身份判断复用规则；仅在身份处理处使用，避免词缀数值被误删。
- 真实样例恢复游戏格式的物品等级行，保留用户提供的词缀文本。比较带标记和无标记解析结果，并明确断言交易底材、数量、数值和等阶。

## Risks / Trade-offs

- 正常名称若含成对 ASCII 方括号也会被删除 → 遵循用户明确要求的宽松补丁规则，范围限定身份字段。
- 未闭合标记无法清理 → 保留原样，不猜测名称边界。

## Migration Plan

无数据迁移；开发版重新复制物品即可使用新解析结果。回滚本次解析改动即可恢复旧行为。
