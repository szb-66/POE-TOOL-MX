## Context

训练预览由截图图片和绝对覆盖的 CSS Grid 组成，每个格子是透明按钮，标签状态通过 `is-*` 类映射到边框颜色。格子还承担点击切换、悬停提示和复核焦点反馈，因此显示开关只能控制标签颜色层，不能禁用或隐藏按钮本身。

## Goals / Non-Goals

**Goals:**

- 在同一个格子元素上渲染边框与中心圆点，保证两者始终与网格尺寸和标签状态同步。
- 让两个显示维度相互独立，并保留交互反馈。
- 用共享颜色变量保证边框、圆点和图例语义一致。

**Non-Goals:**

- 不持久化显示偏好；开关只影响当前页面实例。
- 不改变标签循环、训练数据、模型识别或 IPC。
- 不修改普通背包页中的同名预览样式。

## Decisions

1. **在网格覆盖层设置显示模式类。** 两个 Vue `ref` 默认均为 `true`，通过覆盖层 class 分别关闭标签边框和伪元素圆点。相比逐格生成动态 style，这种方式只改变父级 class，模板和响应式开销更小。
2. **用格子 `::after` 绘制中心圆点。** 圆点无需新增可访问性节点，也不会改变按钮的点击区域或网格布局。格子通过状态类设置统一的 `--training-label-color`，边框和圆点共同引用它。
3. **显示开关不控制焦点与悬停样式。** 隐藏标签边框时只覆盖 `border-color`，保留 `box-shadow`，保证复核定位和鼠标反馈仍可用。
4. **保留未知状态的橙色反馈。** 用户定义的三色规则应用于三种可提交标签；尚未标注的 `unknown` 继续使用橙色，以免它与任一有效标签混淆。

## Risks / Trade-offs

- [白色圆点在浅色截图区域可能对比不足] → 为圆点增加细微深色描边，但不改变其标签主色。
- [关闭网格颜色后透明边框仍占 2px] → 保留边框尺寸避免网格单元布局抖动，只将颜色设为透明。

## Migration Plan

这是仅开发版页面的无状态 UI 变更，无数据迁移。回滚时恢复原模板和样式即可，不影响已有训练会话。
