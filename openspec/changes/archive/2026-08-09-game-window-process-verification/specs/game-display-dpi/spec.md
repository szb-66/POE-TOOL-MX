## MODIFIED Requirements

### Requirement: 自动检测游戏窗口 DPI
系统 MUST 在 Windows 上使用用户配置的游戏窗口名称列表和游戏客户端进程名列表识别顶层窗口，并读取所选游戏窗口的实际 DPI 倍率；仅标题与进程名同时匹配的窗口可作为候选。跨名称候选 MUST 先按配置顺序选择。同一名称内优先选择非最小化窗口，再按前台状态和可见面积选择；仅有最小化候选时仍 MUST 使用该窗口读取 DPI。

#### Scenario: 仅存在最小化候选
- **WHEN** 配置名称与进程名匹配的游戏窗口已最小化，且没有其他同名候选
- **THEN** 系统仍必须使用该窗口读取 DPI，不得报告未找到游戏窗口

#### Scenario: 浏览器候选被过滤
- **WHEN** 顶层窗口标题匹配配置名称但进程是浏览器，且没有其他游戏窗口
- **THEN** 系统报告未找到游戏窗口，不得使用浏览器窗口读取 DPI
