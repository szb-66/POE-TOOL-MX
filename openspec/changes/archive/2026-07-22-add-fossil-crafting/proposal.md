## Why

手动做装模拟器已经支持基础通货、精华和工艺台，但化石仍只能作为词缀来源被浏览，无法通过共振器实际重铸装备。化石是验证真实标签权重、禁止词缀和多材料组合是否准确的关键机制，也是继续扩展花园与特殊制作前必须补齐的基础能力。

## What Changes

- 增加当前版本 25 种化石及 1–4 孔混乱共振器的结构化规则目录，显示每种化石的作用、标签乘数、禁止项、特殊后果和支持状态。
- 允许用户选择共振器孔数并装入互不重复的化石，只有装满后才能对稀有装备执行重铸。
- 按词缀真实标签应用“更多”“更少”“无”权重规则；禁止规则优先，多个化石乘数相乘，并允许化石限定的地心词缀进入候选池。
- 支持圣洁化石的高等级权重与幸运数值，支持普通确定性标签化石；复杂特殊化石在未能完整建模时必须显示精确效果和明确禁用原因，不执行近似结果。
- 将化石操作接入固定随机种子、装备状态、历史、撤销、重做、重置、服务 API 和帮助说明。
- 价格数据继续停用，消耗历史只记录共振器和所装化石的数量与名称。

## Capabilities

### New Capabilities

- `fossil-crafting`: 共振器组装、化石标签权重、化石限定词缀、圣洁化石和特殊化石支持边界的手动制作行为。

### Modified Capabilities

无。

## Impact

- 扩展做装数据模型、POEDB 解析/更新器、手动制作状态机和随机词缀池变换接口。
- 扩展 Electron service、IPC、preload、渲染 API、Pinia store 与做装页面。
- 增加化石规则、组合、真实快照审计、历史和 UI 契约测试。
