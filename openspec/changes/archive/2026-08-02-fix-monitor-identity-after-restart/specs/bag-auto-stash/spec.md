## MODIFIED Requirements

### Requirement: 采集环境兼容性校验
系统 MUST 在启动背包检测前校验带元数据模板能否唯一对应到当前显示器，并校验其 DPI、物理分辨率和采集区域兼容性；运行时显示器 id 仅作为优先匹配提示，不得作为跨系统重启的唯一身份依据。

#### Scenario: 采集环境保持兼容
- **WHEN** 仓库和背包模板元数据能通过当前 id，或通过 scale factor、物理尺寸及采集区域所在屏幕唯一对应到兼容显示器
- **THEN** 系统允许启动检测

#### Scenario: 重启后显示器 id 变化
- **WHEN** 系统重启导致采集记录中的显示器 id 不再存在或指向其他显示器，但原显示器的 scale factor、物理尺寸和采集区域仍与当前唯一显示器兼容
- **THEN** 系统允许启动检测且不要求用户重新框选

#### Scenario: 无法唯一定位兼容显示器
- **WHEN** 当前环境不存在兼容显示器，或存在多个无法由采集区域唯一确定的兼容显示器
- **THEN** 系统拒绝启动检测并指出需要重新框选的标题

#### Scenario: 显示环境发生变化
- **WHEN** 能定位到采集显示器但其 scale factor 或物理尺寸与采集记录不一致
- **THEN** 系统拒绝启动检测并指出需要重新框选的标题

#### Scenario: 旧模板没有元数据
- **WHEN** 模板路径和区域有效但没有采集元数据
- **THEN** 系统允许按兼容模式启动并返回可展示的旧配置提示
