## Context

参见 proposal.md。主进程模型总开关与入库均已默认 false；浮窗默认值、归一化、显示策略和设置抽屉仍将缺失值当作开启。

## Goals / Non-Goals

Goals：统一主进程和渲染层缺失开关的行为。
Non-Goals：不迁移覆盖已有用户设置，不改变采集和前台安全条件。

## Decisions

浮窗默认值改为 false，各层采用显式 true 判断，与追踪总开关一致。仅修改默认常量无法覆盖缺失配置和渲染初始态，因此同步修改相关判断。

## Risks / Trade-offs

已有显式 true 无法区分历史默认值与手动选择 → 保留已保存值，避免覆盖用户偏好。
