## Purpose

定义流放助手以整体管理员权限运行的 Tauri v2 Windows 桌面运行时、WebView2 安全边界、多窗口功能对等和正式切换门槛。

## ADDED Requirements

### Requirement: 管理员 Tauri 主程序
Windows 开发版和正式版 Tauri 主程序 MUST 通过应用清单请求管理员权限，且开发启动流程 MUST NOT 因此将 Vite、调用终端或其他构建工具整体提权。

#### Scenario: 启动开发版
- **WHEN** 开发者启动 Tauri 开发版
- **THEN** Vite 以当前用户权限运行，Tauri 主程序单独触发 UAC，并在启动健康状态中报告高完整性

#### Scenario: 用户拒绝 UAC
- **WHEN** 用户拒绝 Tauri 主程序的提权请求
- **THEN** 启动受控结束且显示可操作原因，不残留受管 Python 或桌面子进程

### Requirement: 保留 WebView2 安全机制
系统 MUST 保留 WebView2 的渲染隔离、安全沙盒和标准用户数据目录权限，MUST NOT 以关闭沙盒或传递不安全浏览器参数作为管理员启动失败的修复。

#### Scenario: WebView2 创建失败
- **WHEN** 管理员 Tauri 主程序无法创建 WebView2 或访问其用户数据目录
- **THEN** 系统记录脱敏的结构化启动原因并受控退出，不使用 `--no-sandbox` 或等效绕过重试

### Requirement: 桌面功能完整对等
Tauri 运行时 SHALL 在替换 Electron 正式入口前提供主窗口、全部业务浮窗、屏幕选区、多显示器/DPI、全局快捷键、自动化、制作、账号、查价、反馈、诊断、训练和更新能力，且 SHALL 保持现有可见行为和错误语义。

#### Scenario: 功能尚未全部迁移
- **WHEN** 任一现有桌面能力或对应回归场景尚未通过
- **THEN** Electron 仍作为正式入口，Tauri 不得被标记为可切换版本

#### Scenario: 功能迁移完成
- **WHEN** 全部桌面能力及对应开发版回归场景通过
- **THEN** Tauri 可以进入需另行授权的正式打包和切换验收

### Requirement: 原生多窗口行为
系统 SHALL 为主窗口和每类业务浮窗提供独立原生窗口，并 MUST 保持既有透明、置顶、无边框、鼠标穿透、拖动、尺寸、焦点和路由隔离行为。

#### Scenario: 多显示器不同缩放
- **WHEN** 用户在具有不同缩放比例的多个显示器之间使用主窗口、浮窗或屏幕选区
- **THEN** 系统使用一致的物理坐标和 DPI 换算显示、移动和选择窗口区域

#### Scenario: 交互式透明浮窗
- **WHEN** 浮窗同时包含可交互区域和鼠标穿透区域
- **THEN** 可交互区域接收预期输入，其他区域将输入传递给游戏且不抢占不必要的焦点

#### Scenario: 高频检测与尺寸同步
- **WHEN** 共享检测连续发布相同状态，或浮窗内容尺寸在原生调整后保持不变
- **THEN** 系统合并待执行的原生窗口操作、跳过相同状态和相同尺寸，且不得由尺寸回报与窗口状态事件形成反馈循环

### Requirement: 保持共享界面检测语义
Tauri 运行时 MUST 保持 Electron 的公共界面检测协调语义，由自动入库、仓库自动取件、混沌配方和君锋镇共同注册到唯一检测进程，并向全部消费者广播同一检测状态；仅消费者集合变化且检测配置未变化时 MUST NOT 重启检测进程。

#### Scenario: 多个存取功能同时启用
- **WHEN** 自动入库、仓库自动取件、混沌配方或君锋镇中的多个功能同时启用且使用相同检测配置
- **THEN** 系统保留同一个检测进程并将同一仓库、背包、奖励区、前台和游戏客户区状态广播给全部消费者

#### Scenario: 共享检测配置变化
- **WHEN** 任一消费者提交的模板、区域或匹配阈值改变了公共检测配置
- **THEN** 系统只重配唯一检测进程且全部已注册消费者继续接收新状态

### Requirement: 替换后的产品运行时
完成正式切换后，产品运行路径 MUST NOT 依赖 Electron、Electron preload、electron-builder、Node 主进程或 Node sidecar；迁移期间旧 Electron 实现 SHALL 保持冻结并只用于行为对照和回退。

#### Scenario: 检查正式运行依赖
- **WHEN** Tauri 版本满足切换条件
- **THEN** 产品运行和自动化不加载 Electron 或 Node 桌面后端，且旧实现可以从产品入口安全移除

### Requirement: 正式切换性能门槛
在用户明确授权打包后，Tauri 正式包 MUST 在同机、同数据和同测量方法下相对 Electron 基线将安装体积降低至少 35%、空闲稳定内存降低至少 20%，且冷启动时间不得变慢。

#### Scenario: 任一性能门槛未满足
- **WHEN** 正式包对比结果未达到任一规定门槛
- **THEN** Tauri 不得替换 Electron 正式入口，系统保留测量记录供优化和复测
