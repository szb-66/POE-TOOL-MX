## ADDED Requirements

### Requirement: Rust 系统层监督 Python 生命周期
Tauri 运行时 SHALL 由管理员权限 Rust 系统层按固定语义操作启动、监督和停止 Python 进程，并 MUST 保留现有游戏前台、完整性、DPI、坐标、模板、互斥和停止预检。驻留监控操作 MAY 在游戏不位于前台时启动并等待，但 MUST 在每次检测或发送输入前重新确认游戏位于前台。

#### Scenario: 自动化预检通过
- **WHEN** 用户启动受支持自动化且全部运行环境预检通过
- **THEN** Rust 使用受支持解释器和受限参数启动对应 Python 脚本，并发布与现有客户端一致的状态事件

#### Scenario: 自动化预检失败
- **WHEN** 游戏前台、完整性、DPI、坐标、模板或互斥条件任一不满足
- **THEN** Rust 不启动会产生键鼠输入的 Python 进程，并返回稳定的结构化错误

#### Scenario: 驻留战斗辅助在游戏后台时启用
- **WHEN** 用户在游戏窗口不位于前台时启动被动喝药或主动循环驻留监控
- **THEN** Rust 启动监控并报告等待游戏窗口，脚本在游戏恢复前台前不检测像素且不发送任何输入

#### Scenario: 应用停止或退出
- **WHEN** 用户触发全局停止、关闭应用或启动更新
- **THEN** Rust 在既有超时内停止全部受管 Python 进程并确认无残留后继续退出流程

### Requirement: 禁止通用脚本执行接口
产品 WebView MUST NOT 获得任意 Python 路径、任意脚本正文或任意命令参数执行能力；Rust SHALL 只接受固定操作标识及按操作校验的配置。

#### Scenario: 未知操作或越界参数
- **WHEN** WebView 请求未知自动化操作、任意脚本路径或超出允许范围的参数
- **THEN** Rust 拒绝请求且不创建子进程，并记录不含秘密载荷的结构化原因
