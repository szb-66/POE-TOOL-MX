## Why

从应用界面点击“地图洗练”启动时，应用窗口仍占据前台，脚本随后向错误窗口发送 `Ctrl+Alt+C`，无法复制游戏内地图信息并把有效地图误判为空格。全局快捷键从游戏内启动时没有该问题，说明两种入口缺少一致的游戏前台保障。

## What Changes

- 地图洗练脚本在第一次鼠标和键盘操作前确认并恢复《流放之路》游戏窗口到前台。
- 如果无法找到或激活游戏窗口，脚本明确停止并输出原因，不进入连续空格判定。
- 保留游戏内 `Alt+2` 启动行为，并为应用内启动场景增加回归测试。

## Capabilities

### New Capabilities

- `map-rolling-foreground-start`: 规定地图洗练从任意入口启动时的游戏窗口激活与失败行为。

### Modified Capabilities

无。

## Impact

- 影响地图洗练 Python 模板及其生成脚本。
- 增加地图洗练启动前台保障的自动化回归测试。
- 不改变快捷键配置、地图匹配规则、剪贴板文件协议或用户配置格式。
