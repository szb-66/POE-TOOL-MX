## Context

君锋镇 manager 当前直接按保存的 Electron 显示器 ID 查询显示器，而标题模板校验已经实现了按显示参数和区域归属恢复匹配。奖励网格保留了显示器物理边界和物理坐标，可以使用相同判定模型。

## Goals / Non-Goals

**Goals:**

- 消除仅由显示器 ID 重枚举产生的误报。
- 保持真实显示环境变化和多屏歧义时的安全阻断。
- 让奖励网格环境判断通过纯函数进行行为测试。

**Non-Goals:**

- 不识别显示器硬件序列号，不迁移或重写已保存配置。
- 不改变取件脚本、界面检测或键鼠安全门禁。

## Decisions

1. 导出现有显示器解析函数，并增加可选 DPI 容差。默认值保持标题模板现有的严格比较；君锋镇传入既有的 `0.01` 容差，避免无关行为变化。
2. 在君锋镇配置工具中增加纯函数校验。函数把奖励网格保存的物理边界转换为共享解析器需要的物理尺寸，并以网格区域作为归属判据；manager 只传入当前显示器快照并转译错误结果。
3. 匹配优先选择参数兼容、区域仍归属其中的原 ID 显示器；原 ID 失效或交换时，仅接受唯一包含原区域的兼容显示器。没有唯一结果时继续阻断，不做无条件回退。
4. 每次启动动态解析，不回写新 ID。这样无需新增 IPC 或持久化迁移，并能持续承受后续重枚举。

## Risks / Trade-offs

- [两台完全同规格显示器且缺少可用物理边界时无法区分] → 保持拒绝启动并要求重新框选。
- [显示器布局变化后旧坐标恰好落入另一台兼容屏幕] → 标题模板、前台窗口及奖励界面门禁仍会在键鼠输入前校验；区域归属规则与现有模板校验保持一致。
