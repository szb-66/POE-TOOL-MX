## Why

君锋镇奖励网格把 Electron 显示器 ID 当成稳定硬件标识；Windows 重启、休眠或显卡驱动重枚举后 ID 可能变化，即使物理屏幕、DPI 和布局未变也会误判并强制重新框选。项目中的标题模板已经能够安全恢复这种显示器匹配，奖励网格需要采用一致规则。

## What Changes

- 显示器 ID 失效或交换时，根据 DPI、物理尺寸和原网格坐标唯一恢复兼容显示器。
- 保留 DPI、分辨率、位置真实变化以及多屏歧义时的阻断行为。
- 将显示环境判断提取为可直接测试的纯函数，并复用现有标题模板匹配逻辑。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `junfeng-highlight-pickup`: 明确临时显示器 ID 变化不等于显示环境变化，兼容环境下应继续使用原框选。

## Impact

影响共享显示器匹配工具、君锋镇奖励网格启动前校验及对应 Node 测试；不改变持久化格式、Python 取件脚本、自动点击门禁或第三方依赖。
