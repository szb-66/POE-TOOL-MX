## Context

现有批量制作以国服角色接口快照提供稳定 ID、坐标和尺寸，再由制作脚本逐件复制预检。项目同时已有背包自动入库的 12×5 复制遍历、尺寸目录、前台门禁、自动化互斥和输入释放能力。本变更在当前未提交实现上替换候选来源，见 proposal.md 与 delta specs。

## Goals / Non-Goals

**Goals:**

- 在不依赖网络账号的情况下生成可视化、可冻结的本地背包候选。
- 复用现有安全门禁并保证所有候选身份预检早于通货页选择和通货输入。
- 对复制文本无法证明占位关系的情况失败关闭，而不是重复制作。

**Non-Goals:**

- 不扫描扩展背包列，不自动打开背包或仓库，不改变单件制作。
- 不跨异常恢复旧批次，不持久化扫描快照或完整复制文本。
- 不移除账号模块本身，不打包或发布。

## Decisions

### 1. 扫描由独立本地自动化操作完成

主进程提供批量扫描 IPC，注入原生网格、全局时序、游戏窗口和尺寸目录，使用独立 Python 脚本遍历并通过结构化事件发布进度。它与制作共享自动化锁和全局停止，但不创建制作浮层。相比把扫描塞入正式制作脚本，独立操作允许页面在选择类别前得到完整预览。

### 2. 扫描不负责打开游戏页面

Renderer 在调用前展示准备确认；脚本只聚焦游戏、移动鼠标和复制，不发送背包键、不点击仓库页。正式制作仍按现有全局自动选页设置决定是否选择通货页；关闭时直接在当前页面执行通货预检。

扫描开始前复用屏幕取点的窗口准备流程，由应用主动最小化主窗口后再让脚本聚焦游戏。扫描进程返回结构化快照且主进程完成临时配置和自动化锁清理后，无论成功、失败或停止，都在主进程结束处直接等待应用既有的主窗口恢复流程，恢复完成后才向 Renderer 返回结果。不得依赖 Renderer 发起第二次 IPC 才恢复窗口。

### 3. 尺寸目录优先，未知尺寸失败关闭歧义

已知尺寸从左上格扩展占位矩形并跳过剩余格。未知尺寸继续逐格复制，以规范化完整文本指纹识别相邻重复；孤立结果可作为 1×1，任一相邻重复连通区都标记为不可制作歧义。这样不会把相邻相同单格物品错误合并，也不会把多格物品重复加入。

### 4. 扫描原文只存在于临时进程边界

Python 以临时结果文件交付每格复制原文，主进程用现有解析器生成类别、底材和展示字段后立即删除原文；Renderer、Store、日志与诊断只接收白名单结构和不可逆指纹。

### 5. 批次使用扫描内身份且不再续作

冻结配置用 `scanId + 左上格` 作为会话内 ID，并保存类别、底材和尺寸。正式预检只访问所选候选左上格。由于复制文本没有官网稳定 ID，异常后清除恢复检查点并要求新扫描，避免按位置或相似底材猜测身份。

制作启动中的配置引导校验和最终公共校验必须接收同一个批量 Store 的 `snapshot` 与 `candidates.length`。动态扫描状态不能只传给前置引导而在最终校验中省略。

### 6. 网格使用绝对占位层表达整体物品

视图以 12×5 基础格提供空格边界，物品层按 `x/y/width/height` 跨格定位。类别颜色由单一映射提供；选择状态提升不透明度、边框和阴影，歧义区域使用警示纹理。Tooltip 只展示结构化元数据。

## Risks / Trade-offs

- [未知多格物品与相邻相同单格物品无法区分] → 标记歧义并禁止制作，提示用户移开后重扫。
- [用户未打开正确页面] → 扫描前明确提示，复制失败或通货预检失败时给出阶段化原因且不输入通货。
- [扫描后背包发生变化] → 正式制作前逐件预检所有所选候选。
- [扫描 60 格耗时] → 已知占位跳格并持续发布进度，不使用提前空格阈值漏扫后部物品。

## Migration Plan

1. 增加本地扫描 IPC、脚本和测试，再将批量 Store/页面切换到新契约。
2. 删除批量启动与浮层对账号快照和稳定 ID 续作的依赖，保留账号模块供其他功能使用。
3. 完成开发版自动化测试、构建和受控只读实机扫描；不执行打包。
4. 回滚时恢复账号快照批量分支；预设结构未变化，无用户数据迁移。
