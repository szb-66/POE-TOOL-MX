## ADDED Requirements

### Requirement: 解析格式回归覆盖
系统 MUST 维护可由当前解析器成功处理的代表性格式样例，并通过表驱动自动化测试验证每一种代表性结构的关键解析结果；这些测试样例无需展示在最终用户界面中。

#### Scenario: 运行格式回归测试
- **WHEN** 开发者运行项目测试
- **THEN** 每个受支持的代表性剪贴板样例都被提交给真实物品解析器
- **AND** 测试验证类别、稀有度、状态、阶级、六项地图基底、插槽、势力或词缀等适用字段

## REMOVED Requirements

### Requirement: 格式示例与解析器一致
**Reason**: 原要求同时耦合了解析回归与用户界面展示；移除说明面板后不再需要浏览器展示场景。

**Migration**: 解析回归契约由新增的“解析格式回归覆盖”要求承接，代表性样例及关键字段验证继续保留。

### Requirement: 物品剪贴板格式说明
**Reason**: 制作页面顶部说明面板对日常用户冗余并占用核心操作区的首屏空间。

**Migration**: 用户直接通过制作页面的现有配置和词缀参考入口完成操作；解析能力和格式回归样例继续保留。

### Requirement: 地图剪贴板格式说明
**Reason**: 异界地图页面顶部说明面板对日常用户冗余并延后洗图配置区的展示。

**Migration**: 用户直接使用现有地图基底、词缀和预设配置；地图解析字段及其回归验证保持不变。

### Requirement: 航海海图剪贴板格式说明
**Reason**: 航海海图 Tab 顶部说明面板对日常用户冗余并占用操作空间。

**Migration**: 用户直接使用航海海图奖励和词缀配置；海图解析字段及已鉴定、未鉴定、已腐化样例的回归验证保持不变。
