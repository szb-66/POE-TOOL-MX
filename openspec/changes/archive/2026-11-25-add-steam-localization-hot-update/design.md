# Design

## Context

沿用现有国际服独立用户目录、Electron IPC门禁与阿里云反馈后台管理员认证。两个仓库均有已存在的未提交工作。动机见 proposal.md。

## Goals / Non-Goals

支持当前 Windows x64 Steam，以本地官方繁体为底、官方简体按条目覆盖。首期通过现有 SSH 隧道验收，不打包助手安装程序，不自动抓取游戏或联网更新，不迁移市场及开放未验证自动化。

## Decisions

- 原生 helper 固定 LibBundle3 2.7.5 commit 50c2d279b3806366f79e831acc1c03bc35bb6442，.NET 8自包含；JSONL protocolVersion=1。资源仅包含数据，解析引擎不热更。
- 表格按 table/id/field，词缀按 stat序列和变体匹配，源英文SHA256及结构不一致则回退。只替换可验证文本，不用行号进行跨服配对。
- 玩家展示字段采用明确的逐表白名单，覆盖装备／技能名称、天赋、NPC、区域和界面等，不能仅依赖上游localized标记；资源路径和机制字段不开放。旧国服可用固定3.29.3来源结构读取，目标写入始终用当前国际服结构，译文仍须同稳定标识、同英文原文及占位符校验。
- 服务端协议为 entries 数组、按表隔离且每表16个稳定key哈希桶、gzip对象、SHA256内容寻址、Ed25519 canonical JSON签名。客户端只读取完整验签激活版本，整张名称表补齐不会导致未变化词缀表重新下载。
- 主进程提供“切简体”和“切繁体”：简体将版本检测、资源检查、按需下载和应用组织成一个任务；繁体只从本地同版本应用前备份重建，不检查或下载服务器词库。全程保持忙碌并支持退出等待，不提供预览或手动完整性核对入口。独立helper负责读取、暂存、结构校验、自动建立应用前备份、事务提交和同版恢复，不再依赖Steam手动校验日志或baselineConfirmed。
- 简繁模式记录在原生Active事务状态中，旧记录缺省为simplified；同release只有mode也相同时才可直接复用。繁体忽略简体entries，同版本本地验签缓存可提供资源版本以保持映射；无同版缓存时使用native-tw并仍允许离线切换。
- 将语言偏好与当前 Build 已应用状态分开保存；游戏更新只使已应用状态和查价映射失效，不能清除语言选择。设置页分别展示所选语言、当前是否已生效及词库来源版本；缺省apply请求先取保存的preferredMode，无偏好才取simplified；成功恢复原版后清除语言偏好。
- 点击简体仍先检查频道并按需下载。仅连接失败、超时或暂时性服务错误允许回退到本地完整缓存，回退前重新验证固定公钥签名和全部对象；损坏本地候选被排除，但可选择另一完整有效缓存。收到新资源后的签名、协议、对象校验错误及权限错误不得静默回退。跨gameVersion的缓存作为翻译候选，实际写入仍逐条检查当前稳定标识、英文原文SHA256、占位符和词缀结构，缺失内容保留当前繁体/英文；提示正在使用缓存及其来源版本。
- 跨Build旧补丁处理始终以当前索引为输入；仅当原应用记录、旧应用前备份和文件重定向对应关系均可验证时，逐文件撤销仍指向受管补丁的引用，保留当前其它资源及Steam更新。为撤销后的当前Build保存备份，再按当前资源生成目标语言；恢复入口也可先迁移为当前Build基线再恢复。不得将旧版完整索引恢复到新版，也不得采纳未知第三方重定向；无法确认时停止并提示Steam校验。
- 新事务记录受管资源原文SHA256并保存已应用索引副本，用于后续部分Steam索引更新后的引用核验。无sourceHash的旧事务只在当前索引精确匹配旧outputHash时尝试：逐文件验证当前源DAT保留的原始字符串池和非展示字节、languages重新生成的完整结果，以及CSD除繁体显示文本外的全部结构和内容，任何不一致均拒绝迁移。
- 后台存储在独立持久资源目录，PostgreSQL存发布元数据，Nginx直接缓存分发对象。服务器先落齐对象再切频道；资源回退不覆盖不可变对象。
- 混合语言查价在国际服输入边界还原英文和国际交易标识，保留精确原文和未知诊断，不更改共享国服解析规则。

## Risks / Trade-offs

- 当前 DATc64和压缩依赖尚未实测：先完成真实资源解析/往返闸门，失败不得产生游戏写入或声称已验收。
- 官方译文滞后、结构变化：保留繁体/英文并展示覆盖统计，原生格式变化仍可能需要升级助手。
- 其他补丁污染、Steam更新竞争：自动结构校验和应用前备份不证明首次接触文件为官方原版；拒绝已知同版外部变化和无法核实的旧补丁。可核实受管旧引用只在当前索引上撤销，写前重新检查版本/指纹，保留事务日志和同版本还原；新格式或缺失旧备份仍需Steam校验，不能保证任意旧补丁均可自动修复。
- 资源路径遍历和解压膨胀：固定哈希路径、数据结构白名单、长度/计数/解压上限。

## Migration Plan

先开发版和受影响测试，再全量回归、内部服务部署及本机 Steam 实测。无公网入口改动。恢复服务端频道不影响软件版本；游戏恢复只用同版本原索引。公开依赖来源与许可说明，临时测试移回收站。
