## Context

现有联想目录丢失互斥组和部分内部属性，自动洗图按中文显式描述的字符串包含判断黑名单。契约蓝图要求命中非空白名单，地图和海图白名单不构成必须命中条件。

## Goals / Non-Goals

提供联合可达性及原因；不计算概率、不读取物品、不修改执行或预设。

## Decisions

- 从 POEDB ModsView 生成独立离线快照，保留来源 URL、日期、原始身份、分组、等级、描述数值范围与属性贡献。按来源底子隔离词缀池。
- 确定性深度优先组合搜索，最多三前缀三后缀、按合法词缀数验收；用剩余贡献上界剪枝。对数值文字展开范围，未能穷尽的范围和未核实的修正不得产生无解证明。
- 使用实际运行匹配语义，必选与挑选同项取更高阈值并从挑选移除；黑名单优先。
- 两次搜索区分黑名单导致与原本无解，结果包括状态、原因、条件、黑名单和数据版本。任何来源未知都阻止全局无解结论，但已发现的合法解可提前返回。
- Web Worker 隔离计算，编辑防抖、终止旧 worker 并核对请求序号；组件卸载时释放。默认节点预算限制运行成本，耗尽返回无法判定。页面仅渲染黑名单导致无解或条件本身无解的错误提示；计算中、可达、无法判定均不显示提示且不占位。
- 品质加成完全排除，不枚举贤主钉或其他品质方案。附魔和特殊底子必须有覆盖证据；无法确认时保留明确覆盖缺口，不臆造倍率。瓦尔前可达性不借用瓦尔后结果。

## Risks / Trade-offs

- 来源页面变化 → 生成器验证字段和来源域，失败不覆盖快照。
- 特殊修正规则不完整 → 返回无法判定而非错误的无解；在研究记录明确未核实项目。
- 组合爆炸 → 有界搜索和后台线程；超限不会误报。

## Migration Plan

新增只读分析模块和页面组件，无预设迁移；移除组件即可回退功能。
