## Why

黑名单可能排除满足数值条件所必需的词缀，导致用户反复洗练仍无法达标。页面需要基于合法组合的保守提示，而非概率或独立属性最大值相加。

## What Changes

- 三类洗图页签在不包含任何品质加成的前提下，自动检查当前类别所有底子的理论可达性。
- 比较有无黑名单的结果，区分黑名单冲突、条件本身无解和资料不足；页面仅在确认不可达时显示错误提示。
- 补齐可追溯离线目录，以异步确定性搜索执行，不增加启动预检或改变自动化。

## Capabilities

### New Capabilities
- `map-blacklist-feasibility`: 地图制作黑名单与联合数值条件可达性提示。

### Modified Capabilities
无。

## Impact

地图条件页面、新增离线数据生成器、独立判定模块及 Web Worker。保持预设、启动接口与 Python 自动化不变。
