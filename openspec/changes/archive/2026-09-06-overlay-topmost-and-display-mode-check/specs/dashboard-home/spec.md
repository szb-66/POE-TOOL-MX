# dashboard-home Delta

## ADDED Requirements

### Requirement: 游戏显示模式健康项

系统 SHALL 在首页系统环境面板展示"游戏显示模式"健康项，依据游戏显示模式检测结果呈现：仅受支持的显示模式（窗口模式、全屏、无边框窗口）显示为绿色正常状态；独占全屏显示为黄色需关注状态并提示浮窗可能被游戏遮挡、建议切换为无边框全屏或窗口模式；游戏窗口最小化或未检测到游戏窗口时显示为黄色需关注状态并说明无法判断的原因。该项 MUST 遵循系统环境面板既有的状态渲染与诊断记录机制，且 MUST NOT 要求用户进行与显示模式无关的处理。

#### Scenario: 受支持的显示模式显示绿色

- **WHEN** 游戏显示模式检测返回窗口模式、全屏或无边框窗口且标记为受支持
- **THEN** 该健康项显示绿色正常状态并展示检测到的显示模式名称

#### Scenario: 随游戏状态变化自动更新

- **WHEN** 游戏窗口前台状态或窗口几何变化（含游戏内切换显示模式）触发游戏窗口状态推送，无论 DPI 处于自动还是手动模式
- **THEN** 系统自动重新检测显示模式并更新该健康项，无需重新进入首页或手动刷新
- **AND** 更新机制与游戏前台快捷键状态推送一致

#### Scenario: 独占全屏显示黄色并给出建议

- **WHEN** 游戏显示模式检测返回独占全屏且标记为不受支持
- **THEN** 该健康项显示黄色需关注状态
- **AND** 提示浮窗可能被游戏遮挡，建议在游戏中切换为无边框全屏或窗口模式

#### Scenario: 游戏窗口最小化时提示无法判断

- **WHEN** 游戏窗口存在但已最小化，显示模式无法判断
- **THEN** 该健康项显示黄色需关注状态并说明需还原游戏窗口后重新检测

#### Scenario: 未检测到游戏窗口时提示

- **WHEN** 没有匹配的游戏窗口，无法进行显示模式检测
- **THEN** 该健康项显示黄色需关注状态并说明未检测到游戏窗口
- **AND** 不影响其他系统环境健康项的展示
