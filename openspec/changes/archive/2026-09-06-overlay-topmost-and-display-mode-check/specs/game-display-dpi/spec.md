# game-display-dpi Delta

## ADDED Requirements

### Requirement: 检测游戏窗口显示模式

系统 MUST 在游戏窗口检测过程中同时采集所选游戏窗口的显示模式信息，包括窗口样式是否含标题栏、窗口矩形与其所在显示器矩形，以及系统级全屏通知状态；并基于这些信息将游戏显示模式分类为：窗口模式、全屏（无边框）、无边框窗口（三者均受支持）和独占全屏（不受支持，浮窗可能被游戏遮挡）。检测结果 MUST 附带显示模式分类与是否受支持的判定；窗口最小化时 MUST 报告无法判断；游戏不在前台时系统 MUST NOT 仅凭铺满显示器判定为独占全屏（全屏通知状态信号仅在前台可靠，此时按无边框全屏处理，不得误报）。未找到游戏窗口时 MUST 返回未检测到显示模式的结构化结果而不阻断应用启动。已有 DPI 检测行为 MUST 保持不变。

#### Scenario: 窗口模式判定为支持

- **WHEN** 所选游戏窗口样式包含标题栏
- **THEN** 系统返回窗口模式分类且标记为受支持

#### Scenario: 铺满显示器的无边框窗口判定为支持

- **WHEN** 所选游戏窗口无标题栏且窗口矩形覆盖所在显示器矩形面积达到覆盖判定阈值，系统未收到独占全屏信号
- **THEN** 系统返回全屏（无边框）分类且标记为受支持

#### Scenario: 前台独占全屏判定为不支持

- **WHEN** 游戏窗口位于前台、无标题栏、铺满所在显示器，且系统全屏通知状态报告正在运行 D3D 独占全屏
- **THEN** 系统返回独占全屏分类且标记为不受支持

#### Scenario: 未铺满显示器的无边框窗口判定为支持

- **WHEN** 所选游戏窗口无标题栏且窗口矩形未铺满所在显示器
- **THEN** 系统返回无边框窗口分类且标记为受支持

#### Scenario: 游戏窗口最小化时无法判断

- **WHEN** 所选游戏窗口已最小化
- **THEN** 系统报告无法判断显示模式且不标记为受支持

#### Scenario: 游戏不在前台时不误报独占全屏

- **WHEN** 游戏窗口无标题栏且铺满显示器但不在前台，系统未收到独占全屏信号
- **THEN** 系统按全屏（无边框）分类处理且标记为受支持

#### Scenario: 未找到游戏窗口

- **WHEN** 没有匹配的游戏窗口
- **THEN** 系统返回未检测到显示模式的结果且不影响其他系统环境检查
