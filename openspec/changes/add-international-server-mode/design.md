## Context

见 proposal.md。账号实际实现位于 chaosRecipe/auth.js；交易目录已有国际服官方目录生成基础。窗口标题和日志已有部分英文支持，物品与业务匹配仍大量依赖中文。

## Goals / Non-Goals

Goals: 单进程只运行一个服务器上下文，中文界面，英文国际服；共享计算与组件，隔离环境数据。
Non-Goals: PoE2、主机、英文助手界面、双进程同时运行、首期 OAuth 系统。

## Decisions

- 服务器描述放 shared，主进程启动读取唯一设置文件；通过 preload 向所有渲染窗口发布只读上下文，禁止渲染端任意指定请求域名。
- 国服沿用当前存储键及数据目录；国际服增加命名空间。共享主题、外观、延迟、快捷键，其余业务状态按服隔离。优先明确存储键映射，避免复制 store。
- 切换采用严格清理后持久化与开发版受管重启；清理失败不写模式。不在运行中替换客户端，避免异步回调串服。
- 配置包升级为 v2 并强制服务器标识，同时接收归属国服的 v1 包；旧助手会拒绝 v2，避免忽略服务器字段而误导入国际服预设。
- 客户端注入固定服务器描述；共用网站会话实现，支持逐接口验证，401/403/429 分别报告，不把网页 HTML 当成功 JSON。
- 英文输入归一化到现有业务字段和值，官方交易英文词缀保留原文以匹配对应目录；不逐字猜译词缀。
- 国际服能力默认未验证，统一主进程 IPC 门禁阻断未适配的业务与游戏输入；UI展示原因。可在开发版验证的离线能力逐项开放。
- 无客户端也能验证的只读能力单独开放：手动查价共用 PriceCheckService，国际服禁止该服务的游戏捕获入口；仓库只开放读取和计算 IPC，不开放控制浮窗和自动取件；英文商店条件仅替换稳定 ID 对应的语言表达式。
- 国际服交易目录通过应用独立 Session 获取并按用户目录缓存；API 未提供补丁号时标记 live，仅供在线查询，不沿用国服补丁号或推断 PoB 版本。英文 PoB 输入只跳过已有英文的重复翻译，保留共用预处理、身份消歧与完整性检查，调用后恢复翻译器状态。
- 数据生成参数化并记录版本、语言、来源和哈希，输出候选通过校验后原子替换；两服不共用活动目录。

## Risks / Trade-offs

- 助手独立国际服会话与真实英文截图尚未完成联调 → 浏览器会话只作为接口结构证据；仓库、角色转换及识别能力保留待实测状态，不以模拟测试代替真实验收。
- 已有业务状态分散 → 审计 localStorage、文件存储与 Python 生成路径，保持国服路径兼容。
- 现有停止流程部分是尽力清理 → 切换使用严格成功检查；不直接用忽略异常的退出回调作为停止成功证据。

## Migration Plan

默认 cn，保留当前会话分区及存储。国际服独立目录与会话。回退国服不合并或删除国际服数据。旧配置包归属国服，跨服导入只允许明确共享区块。

## 3.30.0 六项功能补全

- 英文制作、地图词库和技能目录使用独立当前快照，记录来源哈希；制作候选与对应英文词缀共用现有计算和匹配流程。Atlas Drops、Threads 单独建字段，保留旧国服属性；普通地图补词仍六词，腐化结果允许九词。英文地图理论可行性覆盖不足时报告未知，不使用国服上限。
- 自动化能力可配置，但默认 `gameInputAvailable=false`、状态为 `pending-client`。仅未打包主进程读取 `--verify-international-features=`，逐项切为 `verification`；页面、快捷键、浮窗及直接 IPC 共用同一状态。该参数不保存为实测通过记录。
- 背包自动入库、仓库取件和君锋镇拆成子能力；国际服启动只监听状态，不恢复保存的启用配置。标题、网格和 DPI 重新校准。严格已知占位表记录真实旧尺寸来源并与本服目录取交集，本服 API 实测尺寸优先，未知不可选、不猜单格。
- 仓库取件、君锋镇和批量扫描的模型消费者按服选择同一模型；国际服训练、测试与发布目录隔离，测试未通过不得发布，不能改写国服内置模型的报告。
- 主进程使用固定内置战斗模板和共用纯制作生成器，忽略渲染端原始脚本与脚本路径；制作只允许主窗口、固定任务类型及内部通信路径。错误请求在停止现有任务前拒绝。
- 不扩展 PoB、完整做装模拟、圣所或浮士德；未完成的真实游戏及模型样本验收继续留待用户操作。
