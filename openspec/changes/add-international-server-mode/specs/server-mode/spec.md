## Purpose

定义同一流放助手应用中国服和国际服模式的选择、隔离、接口适配与验证边界，保证共享业务规则的同时不会误用另一服务器的账号、数据、校准或自动化状态。

## ADDED Requirements

### Requirement: 默认国服并在严格停止后重启切换
系统 SHALL 默认使用 cn，并允许选择 international；模式 MUST 仅在任务成功停止后持久化并重启生效。

#### Scenario: 停止失败
- **WHEN** 切换时停止任务失败
- **THEN** 当前模式及持久化模式保持不变，并返回错误

#### Scenario: 成功切换
- **WHEN** 停止任务、取消请求和关闭业务浮窗成功
- **THEN** 系统保存目标模式并重启，仅初始化目标服务器，且不恢复自动化任务

### Requirement: 会话和环境数据按服隔离
系统 MUST 保留当前国服存储和登录会话，国际服独立保存账号、赛季、路径、校准、文字预设与历史；通用主题、外观、延迟和快捷键 SHALL 共享。配置包 MUST 标明服务器且不得包含凭据，旧包按国服处理。

#### Scenario: 国际服首次启动
- **WHEN** 国际服没有自己的环境配置
- **THEN** 使用未校准的默认值，不使用国服账号、赛季或坐标

### Requirement: 未验证能力统一阻断
系统 MUST 通过同一能力状态限制页面、IPC、快捷键和浮窗；未适配功能不得产生游戏输入。国际服网站登录、仓库、角色与交易 SHALL 分别验证，认证成功不代表其他能力可用。

#### Scenario: 未适配入口被直接调用
- **WHEN** 用户或浮窗绕过页面调用未开放的国际服功能
- **THEN** 主进程返回明确的不可用原因，且不执行操作

### Requirement: 无客户端时提供已验证的只读功能
系统 SHALL 在国际服模式提供已通过应用 Session 验证的手动文本查价、仓库读取与配方计算、角色导出和英文商店基础条件正则。这些功能 MUST NOT 要求安装或启动游戏客户端，并 MUST NOT 因页面已开放而开放游戏内捕获、自动取件或其他输入通道。

#### Scenario: 手动文本查价
- **WHEN** 已登录的用户选择赛季并粘贴英文物品文本进行查询
- **THEN** 系统共用物品解析、查询和挂单处理流程，展示当前服结果且仅在用户操作时复制私聊文本或打开官网
- **AND** 更换账号、赛季或输入文本时清除旧结果并丢弃迟到响应

#### Scenario: 配方计算与自动取件分开
- **WHEN** 国际服用户刷新选中的普通或大型仓库页
- **THEN** 系统读取仓库并计算共用配方，游戏内控制和自动取件入口保持关闭

#### Scenario: 英文角色数据导出
- **WHEN** 国际服官网返回英文装备、技能和天赋数据
- **THEN** 系统保留英文原文并共用预处理和完整性检查，不产生中文翻译器误报，也不影响后续国服转换

### Requirement: 英文输入共用业务结构
系统 SHALL 将英文客户端物品头部、属性和状态解析到统一业务结构，并保留原始词缀供对应服的交易目录匹配；歧义文本 MUST NOT 猜测身份。

#### Scenario: 英文物品
- **WHEN** 输入受支持的英文物品文本
- **THEN** 稀有度、等级、品质等字段与等价中文样本含义一致，词缀原文得以保留

### Requirement: 网站接口错误明确降级
系统 SHALL 使用独立网站会话访问当前服务器，区分失效、访问拒绝、限流和结构变化；不得向另一服务器回退请求或复用结果。

#### Scenario: 网站请求被限制
- **WHEN** 国际服接口返回拒绝、HTML 或限流
- **THEN** 系统返回结构化错误并遵守恢复时间，不把响应当作成功数据

### Requirement: 六项英文功能与开发版验收隔离
系统 SHALL 适配英文物品制作、地图制作、背包存取与君锋镇、战斗、剧情及商店／地图／野兽正则。未实测自动化 SHALL 可配置且明确标记待实测，游戏输入默认关闭；仅未打包主进程 SHALL 接受显式逐功能验收参数，验收入口 MUST NOT 等同于实测通过。

#### Scenario: 只开启地图验收
- **WHEN** 开发版只指定地图验收参数
- **THEN** 地图按钮、快捷键与对应 IPC 使用同一权限，其他未开放自动化继续拒绝
- **AND** 原始 Python 执行、范围外模块和制作任务不得借共享入口执行

#### Scenario: 原始脚本正文被伪造
- **WHEN** 渲染端在采样或制作请求中提交任意脚本正文或脚本路径
- **THEN** 主进程只从固定内置模板和可信生成器生成脚本，使用内部输出路径
- **AND** 非主窗口或无效制作任务在停止现有任务前被拒绝

#### Scenario: 国际服启动及安全关闭
- **WHEN** 国际服重启且磁盘保存了已启用的存取功能
- **THEN** 仅初始化关闭的运行态，不改写原配置且不自动执行取件或入库
- **AND** 严格 disabled 请求与停止在未验收或切服期间仍可执行

### Requirement: 英文取件数据与模型不串服
系统 MUST 使用本服标题与网格校准；本服 API 实际占位尺寸 SHALL 优先于已知兼容尺寸，未知尺寸不得猜为单格。国际服训练、评估和候选发布 SHALL 隔离，未通过独立保留集门槛不得替换活动模型。

#### Scenario: 新物品尺寸未知
- **WHEN** 英文背包出现没有可靠尺寸的物品
- **THEN** 扫描可展示未知原因，但该物品不可选且不产生取件操作

#### Scenario: 英文模型覆盖不足
- **WHEN** 测试缺少无高亮场景或产生误取
- **THEN** 保留候选与报告，不标记通过且不覆盖国服或本服活动模型
