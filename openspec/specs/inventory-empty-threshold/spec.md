# inventory-empty-threshold Specification

## Purpose

定义地图制作和背包自动入库共同使用的连续空格阈值，包括合法范围、旧配置迁移、异常值规范化、重置默认值，以及检测与自动化运行期间的配置快照和下一轮生效行为。

## Requirements

### Requirement: 共享连续空格阈值设置
系统 SHALL 在全局背包设置中保存唯一的 `inventory.emptySlotThreshold`，并让地图制作和背包自动入库共同使用该值。

#### Scenario: 修改共享阈值
- **WHEN** 用户在设置页输入 1–60 范围内的连续空格数量
- **THEN** 系统持久化该整数，后续地图制作和自动入库轮次均使用该值

#### Scenario: 加载旧设置
- **WHEN** 持久化设置缺少 `inventory.emptySlotThreshold`
- **THEN** 系统使用默认值 3 且保留其他背包设置

#### Scenario: 加载非法设置
- **WHEN** 持久化值不是有效数值、包含小数或超出 1–60
- **THEN** 系统使用默认值处理非数值，并将数值取整后钳制到 1–60

#### Scenario: 重置设置
- **WHEN** 用户执行重置所有设置
- **THEN** 连续空格阈值恢复为 3

### Requirement: 地图制作按共享阈值提前结束
地图制作脚本 SHALL 按列优先扫描背包，并仅在连续明确空格达到共享阈值时正常提前结束。

#### Scenario: 达到配置阈值
- **WHEN** 地图扫描连续遇到的明确空格数量达到 `inventory.emptySlotThreshold`
- **THEN** 脚本正常结束且不再扫描后续格子

#### Scenario: 零散空格
- **WHEN** 未达到阈值的空格后成功复制到新内容
- **THEN** 脚本将连续空格计数清零并继续处理当前格

#### Scenario: 复制到非地图或无法解析内容
- **WHEN** 当前格成功复制到新内容但解析失败或物品类别不是地图
- **THEN** 当前格不作为空格且连续空格计数保持为零

#### Scenario: 剪贴板序列号读取异常
- **WHEN** Windows 剪贴板序列号接口存在但无法取得复制前或复制后的序列号
- **THEN** 脚本按安全策略停止且不得把该结果作为空格

### Requirement: 运行期间更新下一轮自动入库阈值
系统 MUST 在背包检测器运行期间同步最新阈值，且每轮自动入库 MUST 使用启动时冻结的配置快照。

#### Scenario: 检测期间修改
- **WHEN** 检测器正在运行但尚未启动新的入库轮次时用户修改阈值
- **THEN** 系统不重启检测器且下一轮入库使用新值

#### Scenario: 入库期间修改
- **WHEN** 一轮入库已经启动后用户修改阈值
- **THEN** 当前轮次继续使用旧快照，后续轮次使用新值
