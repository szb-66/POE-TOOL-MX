# map-rolling-foreground-start Specification

## Purpose

确保地图洗练无论从应用界面还是游戏内快捷键启动，都先可靠激活并确认《流放之路》窗口位于前台，并在激活失败时于任何输入发生前安全停止。

## Requirements

### Requirement: 地图洗练启动时保障游戏前台
地图洗练 MUST 遵循 [统一前台策略](../game-foreground-runtime-policy/spec.md)的窗口选择、主进程激活及脚本前台校验规则，并在首次鼠标、键盘或剪贴板操作前完成前台确认。

#### Scenario: 从应用界面启动
- **WHEN** 用户点击应用内地图洗练启动操作且应用窗口当前位于前台
- **THEN** 主进程通过统一机制激活可信游戏窗口，脚本校验前台后再移动鼠标和复制地图信息

#### Scenario: 从游戏内快捷键启动
- **WHEN** 用户在匹配当前名称列表和进程名列表的游戏窗口位于前台时按地图洗练快捷键
- **THEN** 脚本确认当前游戏窗口并直接进入地图扫描，不引入额外的焦点切换

#### Scenario: 未找到游戏窗口
- **WHEN** 启动时没有找到同时匹配标题和进程名列表的窗口
- **THEN** 系统报告无法激活游戏窗口的停止原因，且不得移动鼠标、发送复制键或增加连续空格计数

### Requirement: 游戏激活失败时安全停止
地图洗练 MUST 将主进程报告的游戏窗口激活失败与背包空格区分，并在失败时停止流程。

#### Scenario: 系统拒绝前台切换
- **WHEN** 找到游戏窗口但在限定时间内无法确认其位于前台
- **THEN** 系统安全停止，且不得进入剪贴板判空流程
