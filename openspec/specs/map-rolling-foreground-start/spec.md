# map-rolling-foreground-start Specification

## Purpose

确保地图洗练无论从应用界面还是游戏内快捷键启动，都先可靠激活并确认《流放之路》窗口位于前台，并在激活失败时于任何输入发生前安全停止。

## Requirements

### Requirement: 地图洗练启动时保障游戏前台
地图洗练脚本 MUST 在首次鼠标、键盘或剪贴板操作前确认中文或英文《流放之路》游戏窗口位于前台；如果游戏不在前台，系统 SHALL 尝试查找、恢复并激活该窗口。

#### Scenario: 从应用界面启动
- **WHEN** 用户点击应用内地图洗练启动操作且应用窗口当前位于前台
- **THEN** 脚本先激活可见的游戏窗口，确认游戏位于前台后再移动鼠标和复制地图信息

#### Scenario: 从游戏内快捷键启动
- **WHEN** 用户在游戏窗口位于前台时按地图洗练快捷键
- **THEN** 脚本确认当前游戏窗口并直接进入地图扫描，不引入额外的焦点切换

#### Scenario: 游戏窗口已最小化
- **WHEN** 脚本找到匹配的游戏窗口但该窗口处于最小化状态
- **THEN** 系统恢复该窗口并在确认其位于前台后开始地图扫描

### Requirement: 游戏激活失败时安全停止
地图洗练脚本 MUST 将游戏窗口激活失败与背包空格区分，并在失败时停止流程。

#### Scenario: 未找到游戏窗口
- **WHEN** 启动时没有找到可见的中文或英文《流放之路》窗口
- **THEN** 脚本输出无法激活游戏窗口的停止原因，且不得移动鼠标、发送复制键或增加连续空格计数

#### Scenario: 系统拒绝前台切换
- **WHEN** 找到游戏窗口但在限定时间内无法确认其位于前台
- **THEN** 脚本安全停止，且不得进入剪贴板判空流程
