# map-rolling-foreground-start Specification

## Purpose

确保地图洗练无论从应用界面还是游戏内快捷键启动，都先可靠激活并确认《流放之路》窗口位于前台，并在激活失败时于任何输入发生前安全停止。

## Requirements

### Requirement: 地图洗练启动时保障游戏前台
地图洗练脚本 MUST 在首次鼠标、键盘或剪贴板操作前确认前台窗口标题匹配当前游戏窗口名称列表且进程名匹配游戏客户端进程名列表；如果游戏不在前台，系统 SHALL 按名称配置顺序查找、恢复并激活同时满足标题与进程名匹配的窗口。

#### Scenario: 从应用界面启动
- **WHEN** 用户点击应用内地图洗练启动操作且应用窗口当前位于前台
- **THEN** 脚本按配置优先级激活匹配的游戏窗口，确认游戏位于前台后再移动鼠标和复制地图信息

#### Scenario: 从游戏内快捷键启动
- **WHEN** 用户在匹配当前名称列表和进程名列表的游戏窗口位于前台时按地图洗练快捷键
- **THEN** 脚本确认当前游戏窗口并直接进入地图扫描，不引入额外的焦点切换

#### Scenario: 浏览器页面误判
- **WHEN** 前台窗口标题匹配名称列表但进程是浏览器
- **THEN** 脚本不执行鼠标、键盘或剪贴板操作，并进入查找游戏窗口流程

#### Scenario: 多名称候选
- **WHEN** 同时存在分别匹配多个配置名称的游戏窗口
- **THEN** 脚本选择匹配最靠前配置名称的窗口

#### Scenario: 游戏窗口已最小化
- **WHEN** 脚本找到最高优先级匹配窗口但该窗口处于最小化状态
- **THEN** 系统恢复该窗口并在确认其位于前台后开始地图扫描

### Requirement: 游戏激活失败时安全停止
地图洗练脚本 MUST 将游戏窗口激活失败与背包空格区分，并在失败时停止流程。

#### Scenario: 未找到游戏窗口
- **WHEN** 启动时没有找到同时匹配标题和进程名列表的窗口
- **THEN** 脚本输出无法激活游戏窗口的停止原因，且不得移动鼠标、发送复制键或增加连续空格计数

#### Scenario: 系统拒绝前台切换
- **WHEN** 找到游戏窗口但在限定时间内无法确认其位于前台
- **THEN** 脚本安全停止，且不得进入剪贴板判空流程

### Requirement: 地图洗练运行中保持输入前台门禁
地图洗练脚本 MUST 在每次鼠标、键盘或剪贴板输入前验证游戏仍位于前台，运行中失焦时 SHALL 立即安全停止且不得尝试重新激活游戏。

#### Scenario: 地图洗练运行中失焦
- **WHEN** 地图洗练启动成功后前台切换为其他窗口
- **THEN** 脚本在下一次输入前释放输入状态、报告游戏不在前台并结束本轮
