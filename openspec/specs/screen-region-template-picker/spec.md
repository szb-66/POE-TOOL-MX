# screen-region-template-picker Specification

## Purpose

定义跨显示器矩形区域选取、干净截图精确裁剪、混合 DPI 物理坐标转换、互斥选取会话生命周期、受限模板原子保存，以及模板替换后预览和识别缓存失效的完整行为。

## Requirements

### Requirement: 矩形区域拖动选取
系统 SHALL 提供跨显示器的矩形选取模式，并在单个显示器内将任意拖动方向规范化为有效矩形。

#### Scenario: 成功拖选区域
- **WHEN** 用户在任一显示器按下鼠标、拖动并松开，且选区达到最小尺寸
- **THEN** 系统实时显示选区及尺寸，并允许用户确认提交

#### Scenario: 反向拖动
- **WHEN** 用户从右下向左上或其他反向方向拖动
- **THEN** 系统将起止点规范化为 left、top、right、bottom

#### Scenario: 选区过小
- **WHEN** 物理选区小于 20×10 像素
- **THEN** 系统拒绝确认并提示重新拖选

#### Scenario: 跨显示器拖动
- **WHEN** 用户尝试将选区拖出起始显示器
- **THEN** 系统将选区限制在起始显示器边界内

### Requirement: 干净屏幕截图与精确裁剪
系统 MUST 在显示选区层之前捕获目标显示器的干净画面，并从该画面生成模板 PNG。

#### Scenario: 裁剪模板
- **WHEN** 用户确认有效选区
- **THEN** 模板图片不包含选区蒙层、提示框或边框，且像素尺寸严格等于物理选区尺寸

#### Scenario: 截图缩放换算
- **WHEN** 截图 thumbnail 尺寸与显示器物理尺寸不同
- **THEN** 系统按实际宽高比例换算裁剪坐标并输出选区目标尺寸的图片

#### Scenario: 截图不可用
- **WHEN** 截图为空、尺寸无效或像素内容无法作为模板
- **THEN** 系统返回明确错误且 MUST NOT 生成或覆盖模板文件

### Requirement: 多显示器物理坐标
系统 MUST 将矩形选区转换为 Windows 虚拟桌面物理像素坐标，并支持副显示器、混合 DPI 和负坐标布局。

#### Scenario: 副显示器选区
- **WHEN** 用户在副显示器完成拖选
- **THEN** 返回矩形使用该显示器对应的全局物理坐标和 display id

#### Scenario: 负坐标显示器
- **WHEN** 显示器位于主屏左侧或上方
- **THEN** 返回矩形允许 left、top、right 或 bottom 包含负坐标

#### Scenario: 混合 DPI 显示器
- **WHEN** 选区所在显示器使用非 100% DPI 或与其他显示器缩放不同
- **THEN** 系统仅按该显示器完成 DIP 到物理像素及截图局部坐标转换

### Requirement: 选取会话确认取消与清理
系统 MUST 保证 point 与 region 选取共享单一互斥会话，每个请求只结算一次并清理全部窗口和监听器。

#### Scenario: 确认选区
- **WHEN** 用户按 Enter 或点击确认提交有效选区
- **THEN** 系统返回一次选区结果并关闭所有显示器的选取窗口

#### Scenario: 取消选区
- **WHEN** 用户按 Esc、主动取消或选取窗口异常关闭
- **THEN** 系统返回 canceled 且关闭全部选取窗口，不修改调用方配置

#### Scenario: 重复选取请求
- **WHEN** 已存在 point 或 region 选取会话时再次发起请求
- **THEN** 系统不创建第二组窗口，并返回现有请求或明确忙碌错误

### Requirement: 受限模板保存
系统 SHALL 仅为调用方允许的模板目标保存裁剪结果，并以原子方式替换目标 PNG。

#### Scenario: 成功保存模板
- **WHEN** 调用方提供允许的模板目标且截图裁剪成功
- **THEN** 系统先写同目录临时文件再替换目标文件，并返回路径、物理选区及采集元数据

#### Scenario: 非法模板目标
- **WHEN** 调用方提交未列入白名单的目标标识
- **THEN** 系统拒绝请求且 MUST NOT 写入任意文件

#### Scenario: 保存失败
- **WHEN** 临时写入或替换目标文件失败
- **THEN** 系统清理临时文件、保留旧目标文件并返回错误

### Requirement: 模板保存结果使消费者缓存失效
系统 SHALL 在模板成功替换后返回变化版本，并使渲染层预览与运行态识别器立即放弃旧模板缓存。

#### Scenario: 同路径覆盖模板
- **WHEN** 用户将新截图保存到已有模板路径
- **THEN** 预览 URL 使用新版本加载且识别器重新读取该文件
