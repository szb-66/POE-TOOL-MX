# tab-selection-persistence Specification

## Purpose

统一应用内所有可交互 Tab 的选中状态记忆、恢复和回退行为，使用户在页面往返或重新启动应用后都能回到各个 Tab 组最后一次有效选择，同时避免不同页面和动态分组之间相互覆盖。

## Requirements

### Requirement: Tab 选择跨应用运行持久化
系统 SHALL 为每个由用户主动切换且具有稳定选项标识的 Tab 组保存最后一次合法选择，并 SHALL 在用户再次进入对应界面或重新启动应用后恢复该选择。

#### Scenario: 返回页面
- **WHEN** 用户切换一个 Tab 后离开并再次进入对应页面
- **THEN** 系统恢复该 Tab 组最后一次合法选择

#### Scenario: 重新启动应用
- **WHEN** 用户切换一个 Tab、关闭应用并再次启动后进入对应页面
- **THEN** 系统恢复该 Tab 组最后一次合法选择

### Requirement: Tab 组状态相互隔离
系统 MUST 为不同 Tab 组使用相互独立的持久化状态；同一页面中按稳定业务标识重复出现的动态 Tab 组 MUST 分别记忆选择，不得由一个分组的切换覆盖另一个分组。

#### Scenario: 切换不同页面的 Tab
- **WHEN** 用户分别在两个页面的 Tab 组中选择非默认项
- **THEN** 用户再次进入任一页面时恢复该页面自己的选择

#### Scenario: 切换动态重复 Tab
- **WHEN** 同一页面按不同业务分组展示多个结构相同的 Tab 组，且用户在其中一个分组切换选项
- **THEN** 系统仅更新该业务分组的持久化选择
- **AND** 其他分组已保存的选择保持不变

### Requirement: Tab 恢复值必须合法
系统 MUST 仅恢复当前 Tab 组仍存在的选项；没有持久化记录、存储不可用、记录损坏或选项已移除时，系统 SHALL 使用该 Tab 组定义的默认项，并 SHALL NOT 阻断页面渲染或其他业务功能。

#### Scenario: 首次使用 Tab 组
- **WHEN** 当前 Tab 组没有持久化记录
- **THEN** 系统显示该 Tab 组定义的默认项

#### Scenario: 持久化值无效
- **WHEN** 当前 Tab 组的持久化记录不是现有合法选项
- **THEN** 系统回退到默认项
- **AND** 页面其余功能继续可用

#### Scenario: 本机存储不可用
- **WHEN** 读取或写入 Tab 状态时本机持久化存储抛出错误
- **THEN** 系统继续使用当前合法选择或默认项
- **AND** 不向用户暴露阻断性错误
