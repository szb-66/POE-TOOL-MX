# sanitized-diagnostics Specification

## Purpose

为公开发布后的远程排错提供稳定、可保存的环境信息，同时在诊断生成阶段排除登录凭据、账号内容和可识别用户身份的本地路径。

## Requirements

### Requirement: 生成稳定诊断快照
系统 SHALL 生成 schema v3 JSON 快照，包含随机诊断标识、生成时间、应用版本与运行环境、安全设备兼容性信息、显示器布局、DPI、游戏窗口、运行时、白名单健康状态、诊断上下文、确定性结论以及最近结构化故障事件，不得生成持久设备标识。

#### Scenario: 生成成功
- **WHEN** 用户请求生成诊断信息
- **THEN** 系统返回带有 schema 版本、随机诊断标识与生成时间的结构化快照

#### Scenario: 部分探测失败
- **WHEN** 某项系统、游戏或事件存储探测不可用
- **THEN** 快照保留其他项目，并以安全状态或原因码表示失败而不是整体失败

#### Scenario: 渲染进程提供状态
- **WHEN** 应用提供当前模块和渲染进程健康状态用于本地导出或反馈诊断
- **THEN** 主进程只接受允许的标识、状态和原因码且丢弃所有自由文本与额外字段

### Requirement: 安全设备兼容性信息
系统 SHALL 仅记录 Windows 版本与构建号、CPU 型号与逻辑核心数、内存总量、GPU 型号与驱动版本；探测失败时对应字段安全降级且不得阻止导出。

#### Scenario: 设备探测成功
- **WHEN** 用户生成诊断且系统能够读取兼容性信息
- **THEN** 快照包含白名单设备字段以及各探测项的可用状态

#### Scenario: 禁止持久设备身份
- **WHEN** 系统生成任意诊断快照
- **THEN** 快照不包含主机名、用户名、硬件序列号、MAC 地址、磁盘标识或设备 GUID

### Requirement: 诊断会话与确定性结论
系统 SHALL 在问题反馈页支持最长 15 分钟的结构化诊断会话，要求选择模块和现象枚举，并按当前会话、未恢复状态和直接证据生成排序结论。

#### Scenario: 会话内复现问题
- **WHEN** 用户开始诊断、复现问题并结束会话
- **THEN** 会话期间事件携带随机会话标识且导出结论只聚合该诊断会话的事件

#### Scenario: 会话随反馈自动结束
- **WHEN** 用户在活动诊断会话中提交反馈
- **THEN** 系统在生成诊断附件前结束会话
- **AND** 反馈失败时保留已结束会话供本地导出或重试提交

#### Scenario: 会话异常中断
- **WHEN** 应用在活动诊断会话中退出或超过时限
- **THEN** 下次打开问题反馈页时分别将会话标记为中断或超时并允许用户使用已有证据

#### Scenario: 证据不足
- **WHEN** 当前会话没有可支持具体根因的结构化失败
- **THEN** 结论明确使用未知原因与继续采集建议，不得根据自由文本猜测根因

### Requirement: 诊断数据脱敏
系统 MUST 在主进程生成诊断内容时排除 Cookie、POESESSID、Authorization、Bearer 或会话令牌、账号标识、邮件、IP 地址、仓库内容、预设内容、剪贴板文本、完整本地路径和 UNC 路径，并在最终序列化前对所有字符串再次执行防御性脱敏。

#### Scenario: 本地路径包含用户名
- **WHEN** 任意诊断文本包含大小写不同的用户目录、正反斜杠绝对路径或 UNC 路径
- **THEN** 诊断不包含用户名或完整绝对路径

#### Scenario: 账号已登录
- **WHEN** 用户已经登录国服账号并生成诊断
- **THEN** 诊断中不存在 Cookie、会话值、账号 ID、邮件、IP 地址或仓库数据

#### Scenario: 凭据采用常见文本格式
- **WHEN** 错误文本包含带引号、空格、URL 参数或 Bearer 前缀的凭据
- **THEN** 最终诊断不包含凭据原值

### Requirement: 用户主动导出
系统 SHALL 只在用户于问题反馈页主动导出、明确勾选附带诊断或主动开始诊断会话时生成脱敏诊断；系统 SHALL NOT 在后台自动上传诊断。导出取消、写入失败和反馈上传失败均不得泄露目标路径或诊断中的敏感原值。

#### Scenario: 保存诊断
- **WHEN** 用户在问题反馈页选择导出当前诊断并确认目标文件
- **THEN** 系统将当前脱敏快照保存到该文件并仅反馈文件名
- **AND** 本地导出不上传诊断也不清除已有诊断会话

#### Scenario: 保存诊断会话
- **WHEN** 用户结束并导出诊断会话或导出已有会话
- **THEN** 系统将对应会话的脱敏快照保存到本地
- **AND** 保留会话供后续反馈提交，直到用户取消或反馈提交成功

#### Scenario: 取消保存
- **WHEN** 用户取消保存对话框
- **THEN** 系统不创建文件、不显示失败消息且不改变诊断会话状态

#### Scenario: 写入失败
- **WHEN** 目标文件不可写
- **THEN** 系统返回稳定错误码和安全中文提示且不包含完整目标路径

#### Scenario: 明确附带到反馈
- **WHEN** 用户在反馈表单中明确勾选附带脱敏诊断或开始诊断会话并提交
- **THEN** 系统生成当前快照或对应会话快照并仅用于本次反馈上传
- **AND** 页面在提交前说明诊断包含的类别且普通诊断默认保持未勾选

#### Scenario: 未授权自动上传
- **WHEN** 用户未勾选反馈诊断、未开始诊断会话或仅正常使用应用
- **THEN** 系统不生成或上传诊断快照
