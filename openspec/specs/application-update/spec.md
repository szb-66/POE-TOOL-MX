# application-update Specification

## Purpose

定义 Windows 客户端在应用内安全地获取稳定版本信息、下载更新并在用户明确确认后安装的可观测行为，同时保证网络或清理失败不影响主要功能。

## Requirements

### Requirement: 应用内更新信息
系统 SHALL 在设置页展示当前版本、检查状态，并在发现稳定新版本时展示版本号、发布时间和纯文本发布说明。

#### Scenario: 发现新版本
- **WHEN** 更新源返回高于当前版本的稳定版本
- **THEN** 设置页展示可用版本、发布时间、纯文本发布说明和下载操作

#### Scenario: 已是最新版本
- **WHEN** 手动检查未发现更高的稳定版本
- **THEN** 系统明确显示当前已是最新版本

### Requirement: 可配置的检查与下载
系统 SHALL 默认使用手动更新模式，并 SHALL 持久化用户选择的手动或自动模式。

#### Scenario: 手动模式
- **WHEN** 应用以手动更新模式启动
- **THEN** 系统不发起后台更新检查，只在用户点击后检查或下载

#### Scenario: 自动模式
- **WHEN** 应用以自动更新模式启动
- **THEN** 系统在启动稳定后检查，之后每六小时检查，并在发现更新后自动下载

#### Scenario: 防止并发检查
- **WHEN** 检查或下载已在进行且又收到同类请求
- **THEN** 系统拒绝重复操作并保持当前任务

### Requirement: 可观测的下载状态
系统 SHALL 在下载期间向界面发布进度、传输量和下载完成状态。

#### Scenario: 下载进行中
- **WHEN** 更新包正在下载
- **THEN** 设置页持续显示百分比和已传输数据量

#### Scenario: 下载完成
- **WHEN** 更新包验证并下载完成
- **THEN** 系统显示重启安装操作且 MUST NOT 自行重启

### Requirement: 安全的确认安装
系统 MUST 只在用户明确确认后安装已下载更新，并 MUST 在安装前完成受管资源清理。

#### Scenario: 清理成功
- **WHEN** 用户确认重启安装且受管资源全部清理成功
- **THEN** 系统退出并启动安装器

#### Scenario: 清理失败或超时
- **WHEN** 用户确认重启安装但资源清理失败或超时
- **THEN** 系统不得调用更新安装，并通过共享退出流程受控结束当前实例

### Requirement: 更新失败隔离
网络、元数据或下载失败 MUST NOT 阻止应用启动或影响离线功能，并 SHALL 仅对界面暴露脱敏错误。

#### Scenario: 自动检查失败
- **WHEN** 自动检查因网络不可用而失败
- **THEN** 应用继续正常运行，更新状态记录可重试错误且不泄露本地路径或凭据

#### Scenario: 预发布或降级版本
- **WHEN** 更新源出现预发布版本或低于当前版本的版本
- **THEN** 系统不下载且不安装该版本

### Requirement: 用户可选正式更新源
正式 Windows 客户端 SHALL 默认使用 CNB 仓库 `Auto-Tool-MX/POE-TOOL-MX` 的 Latest Release，并 SHALL 允许用户手动切换到同版本 GitHub Release；所选来源 MUST 持久化并统一用于更新元数据、安装包和差分块映射。

#### Scenario: 首次使用默认来源
- **WHEN** 用户没有保存过更新来源设置
- **THEN** 客户端选择 CNB 作为更新来源并在设置中标记为国内推荐

#### Scenario: 手动切换来源
- **WHEN** 当前没有进行检查或下载且用户选择 CNB 或 GitHub
- **THEN** 客户端持久化所选来源，并让之后的检查和下载使用对应 Latest Release

#### Scenario: 更新操作进行中
- **WHEN** 客户端正在检查或下载更新
- **THEN** 设置界面禁止切换来源，避免同一次更新跨来源混用资产

#### Scenario: 检查并下载稳定更新
- **WHEN** 已安装客户端从所选来源的 `latest.yml` 检查到高于当前版本的稳定版本并开始下载
- **THEN** 客户端从同一来源获取安装包及 `.blockmap`，并继续执行现有摘要校验、进度展示和确认安装流程

#### Scenario: 所选更新源不可用
- **WHEN** 所选来源的元数据或更新资产请求失败、超时或返回无效内容
- **THEN** 客户端按既有更新失败隔离规则继续运行，显示当前来源并允许用户手动切换后重试，不自动改用另一来源且不影响离线功能
