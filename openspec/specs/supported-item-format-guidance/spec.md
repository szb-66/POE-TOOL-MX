# Purpose

定义物品和地图代表性剪贴板格式样例、真实解析器回归覆盖及详细词缀结构化解析行为。

## Requirements

### Requirement: 解析格式回归覆盖
系统 MUST 维护可由当前解析器成功处理的代表性格式样例，并通过表驱动自动化测试验证每一种代表性结构的关键解析结果；这些测试样例无需展示在最终用户界面中。

#### Scenario: 运行格式回归测试
- **WHEN** 开发者运行项目测试
- **THEN** 每个受支持的代表性剪贴板样例都被提交给真实物品解析器
- **AND** 测试验证类别、稀有度、状态、阶级、六项地图基底、插槽、势力或词缀等适用字段

### Requirement: 结构化解析详细词缀
系统 SHALL 将详细复制格式中的每条词缀解析为包含种类、名称、等阶、标签和全部效果行的结构化记录，同时保持现有匹配字段兼容。

#### Scenario: 解析多行复合词缀
- **WHEN** 一个前缀或后缀头之后包含多条效果行
- **THEN** 系统将这些效果行归入同一条结构化词缀
- **AND** 可匹配文本包含该词缀的全部效果行

#### Scenario: 过滤说明和固定区段
- **WHEN** 剪贴板文本包含括号机制说明、奖励描述、地图使用说明或出售信息
- **THEN** 系统不将这些文本加入可匹配显式词缀

#### Scenario: 识别不可制作状态
- **WHEN** 地图文本包含“不可改变”
- **THEN** 解析结果标记该物品不可制作
- **AND** 制作流程不会尝试对其使用通货
