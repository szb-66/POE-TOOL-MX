# overlay-window-topmost Specification

## Purpose

定义业务与工具浮窗的窗口置顶层级要求，确保浮窗在游戏窗口以及开启常驻置顶的主窗口之上始终可见，避免浮窗被游戏或主窗口遮挡。

## Requirements

### Requirement: 浮窗保持最高置顶级别

系统 MUST 将所有业务与工具浮窗设置为最高置顶级别（等同于屏幕保护层级的窗口置顶），使浮窗在游戏窗口显示时保持可见，且在用户开启主窗口常驻置顶时仍位于主窗口之上。覆盖范围 MUST 包括：制作浮窗、剧情浮窗、调试浮窗、配方高亮预览浮窗、查价浮窗、物品检视浮窗、物品检视标记浮窗、装备控制浮窗和右键物品菜单。该置顶设置 MUST NOT 改变浮窗既有的透明、鼠标穿透、不可聚焦、尺寸与坐标行为。

#### Scenario: 游戏全屏时浮窗可见

- **WHEN** 游戏窗口以无边框全屏或窗口模式显示且制作浮窗已开启
- **THEN** 制作浮窗显示在游戏窗口之上，用户无需关闭游戏即可查看和操作浮窗

#### Scenario: 主窗口常驻置顶时浮窗不被遮挡

- **WHEN** 用户开启主窗口常驻置顶，且制作浮窗或配方高亮预览浮窗已开启
- **THEN** 浮窗仍显示在主窗口之上，不因两个窗口同为置顶状态而被压到主窗口之下

#### Scenario: 配方高亮预览与其他浮窗一致

- **WHEN** 用户在配方控制浮窗开启预览高亮且游戏位于前台
- **THEN** 配方高亮预览浮窗显示在游戏窗口之上，高亮标记可见

#### Scenario: 浮窗既有行为不受影响

- **WHEN** 浮窗的置顶级别提升后用户拖动、鼠标穿透或关闭浮窗
- **THEN** 透明区域、鼠标穿透、不可聚焦和位置持久化行为与改造前一致
