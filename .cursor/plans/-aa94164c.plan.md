## 6. 完善AHK2脚本的具体制作逻辑

**文件**: `src/utils/ahk2.js` (脚本生成部分)

### 6.1 词缀匹配流程

根据 `moduleTwo` 配置生成制作逻辑：

**改造石模式**:

- 读取剪切板获取物品信息，判断物品稀有度
- 预处理阶段（根据物品当前状态）：
  - 普通物品：使用蜕变石 → 变为魔法物品
  - 魔法物品：跳过预处理，直接进入改造循环
  - 稀有物品：使用重铸石 → 使用蜕变石 → 变为魔法物品
- 改造循环（最大1000次）：
  - 使用改造石 → 等待延迟 → 按Ctrl+C复制物品 → 读取剪切板到文件 → 等待Node.js解析
  - 检查词缀匹配结果
  - 如果匹配：检查是否需要增幅石/富豪石 → 使用后完成
  - 如果不匹配：继续循环
  - 检查是否达到最大循环次数

**混沌模式**:

- 读取剪切板获取物品信息，判断物品稀有度
- 预处理阶段（根据物品当前状态）：
  - 普通物品：使用点金石 → 变为稀有物品
  - 魔法物品：使用重铸石 → 使用点金石 → 变为稀有物品
  - 稀有物品：跳过预处理，直接进入混沌循环
- 混沌循环（最大1000次）：
  - 使用混沌石 → 等待延迟 → 按Ctrl+C复制物品 → 读取剪切板到文件 → 等待Node.js解析
  - 检查词缀匹配结果
  - 如果匹配：检查是否需要崇高石 → 使用后完成
  - 如果不匹配：继续循环

**点金石模式**:

- 预处理阶段（根据物品当前状态）：

## 实现细节

### AHK2脚本结构

```ahk2
#Requires AutoHotkey v2.0
; 全局变量（从配置生成）
; 延迟配置
; 通货坐标
; 物品位置坐标
; 最大循环次数（1000）
; 文件通信路径

; 快捷键绑定
; 主制作函数
; 词缀匹配函数（改造石/混沌/点金石模式）
; 插槽制作函数（开孔/链接/颜色）
; 文件通信函数
; 辅助函数（鼠标移动、点击、读取剪切板等）
```

### 文件通信格式

**请求文件** (`temp/item_info.txt`):

```json
{
  "clipboard": "剪切板原始文本内容"
}
```

**响应文件** (`temp/item_info_result.json`):

```json
{
  "rarity": "稀有",
  "socketsCount": 4,
  "links": 4,
  "socketsColors": {"red": 4, "green": 0, "blue": 0},
  "affixMatch": true,
  "socketMatch": true,
  "isLegendary": false
}
```

### 脚本执行流程

1. 用户按下快捷键（如 Alt+1）
2. Electron主进程捕获快捷键
3. 读取当前预设和设置配置
4. 生成AHK2脚本并保存到临时文件
5. 执行脚本（spawn进程，保存进程引用）
6. 脚本循环执行制作逻辑：

   - 使用通货 → 复制物品 → 写入文件 → 等待解析 → 检查匹配

7. Node.js端监听文件变化，解析物品信息，写入结果文件
8. 用户按下停止快捷键（Alt+3）时kill进程

### 注意事项

- 脚本需要以管理员权限运行（Electron应用已配置）
- 需要处理脚本执行失败的情况
- 需要支持动态更新配置后重新生成脚本
- 脚本执行过程中需要防止重复触发
- 传奇物品检测到后立即停止并提示
- 达到最大循环次数后停止并提示
- 文件通信需要处理文件锁和并发问题
