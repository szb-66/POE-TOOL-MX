# 流放助手

流放之路物品制作辅助工具，通过Python脚本自动执行游戏内操作。

## 功能特性

- 🎯 **物品制作**：支持改造石、混沌石、点金石三种制作模式
- 📝 **词缀匹配**：配置必选和挑选词缀，自动匹配目标词条
- 💎 **插槽制作**：支持开孔、链接、颜色配置
- ⚙️ **预设管理**：支持多预设配置，方便切换不同方案
- 🎮 **设置中心**：全局快捷键、通货坐标、操作延迟配置
- 📚 **帮助文档**：内置使用说明和帮助文档

## 技术栈

- Vue 3 (Composition API + `<script setup>`)
- Vite
- Element Plus
- Pinia
- Vue Router
- Electron (打包成exe)
- Python 3 (pynput + pyperclip)

## 安装依赖

### Node.js 依赖

```bash
npm install
```

### Python 依赖

确保已安装 Python 3，然后安装以下依赖包：

```bash
pip install opencv-python mss numpy pynput pyperclip
```

应用会优先选择已安装上述全部依赖的 Python 解释器。**注意**：pynput 在 Windows 上可能需要管理员权限才能正常工作。

## 使用说明
用于通过 流放之路自动使用游戏内物品制作装备，通过 ahk2 脚本进行游戏界面的操作，使用 element plus 开发可视化界面，运行平台为 windows，需要默认以管理员身份运行

功能描述
物品
通过使用游戏内的通货改变游戏物品的属性，达到制作想要的词条的效果
模块一：
开始：制作物品开始的快捷键
结束：制作物品结束的快捷键
预设词库：对当前页面编辑的面板信息进行保存，可在选择器中新增预设，具体的操作逻辑为，开始默认带一个“默认预设”，用户在这个界面操作的所有步骤都会自动保存，当用户点击新建预设时则会新建预计预设保存配置，并且当前面板切换到新创建的预设配置
模块二：
这个模块主要是选择通过游戏内什么通货来改变物品的词缀。魔法物品最多拥有一个随机前缀和一个随机后缀，稀有物品通常最多拥有三个随机前缀和三个随机后缀；传奇和基底固定属性不占用这个随机前后缀上限。词缀等阶通常以 T1、T2 等表示，T1 通常是同类词缀中更高的等阶，物品等级会限制可出现的词缀。复合词缀虽然可能显示多条效果，仍属于同一条词缀；不同词缀的相同效果也可能合并显示。更完整的概念可参考 [PoEDB 词缀说明](https://poedb.tw/cn/Modifiers)。

做装规划目录按 POEDB 的受支持装备分类与特殊底材配置生成；护甲底材会进一步标注力量、敏捷、智慧及其组合。词缀外层保持 POEDB Mod Family 分组，绿色标签显示内部等级行数，红色标签显示当前可生成记录的总权重；展开后可选择具体效果和最低等级。物品等级不足的记录会置灰且不进入概率计算；权重越高，随机出现的概率越大。天然生成或工艺台收尾由规划器自动比较，工艺台只有在全部数值分量的最低值达到目标门槛时才算满足。
开头的复选框为是否要启用这个模块的词缀匹配，如果整个页面都没有配置匹配条件的话，则不能开始，提示用户“请启用匹配配置”，默认启用
这个模块匹配到需要的词缀后就查看下边的插槽要求是否有开启，有开启就执行插槽的匹配，没有就停止

物品的制作分为3种模式
改造石模式：通过改造石来重置魔法物品的词缀，达到匹配的词缀后完成。当物品为普通物品时，自动使用蜕变石把普通品质变为魔法之后再开始使用改造石，当物品为稀有物品时，自动使用重铸石之后接蜕变石把物品变为魔法品质后再开始改造模式

混沌模式：通过混沌石来重置稀有物品的词缀，匹配到符合条件的词缀后完成。当物品为普通时，自动使用点金石把物品升级为稀有后再开始，当物品为魔法物品时，自动重铸后点金再开始

点金石模式：通过点金石来重置物品的品质，刷新物品词条来匹配想要的词缀，匹配到符合的词缀后完成，魔法物品和稀有物品就先重置再开始点金模式

必选词缀：词缀随机过程中检查到剪切板词缀同时满足这个模块中词缀要求就停止
挑选词缀：词缀随机过程中检查到剪切板词缀只要满足了其中几个数量的词缀就停止
必选和挑选，必选是一定要有的词缀，挑选是有几个就行，几个可以配置
点击删除icon可以把对应词缀移除出要匹配的词库，点击添加则新增一行空词缀，词缀为空时不参与匹配
模块三
这个模块是对物品的插槽状态进行制作
复选框选中就启用，不选中不启用
开孔：通过工匠石随机装备孔数，达到要求就完成，检测链接和颜色是否启用，启用就继续，没有就停止
链接：物品的连接数量，达到要求就完成，颜色是否启用，启用就继续，没有就停止
颜色：因为可以随机出3种颜色，所以对每种颜色配置单独的数量要求，空为不要求

地图
模块1
洗地图的全局设置，洗图方式分为点金石模式和混沌石模式，这个两个模式跟物品制作的点金和混沌应该也是逻辑一致的，点金模式先对地图进行预处理，把地图预处理成普通品质，魔法物品用重铸变成普通。混沌模式预处理要把地图预处理成稀有品质，普通地图用点金，魔法地图用重铸再点金
开始为制作地图的开始快捷键设置
结束为所有脚本的结束快捷键，跟制作物品是一样通用的
预设的逻辑跟物品的一致，可以增加、删除、修改预设名称
瓦尔宝珠是在地图基底匹配完成，外延词缀也匹配完成的情况下给地图使用瓦尔宝珠，把地图变成已腐化，腐化有概率导致地图词缀变更，导致本来符合要求的地图变得不符合要求，所有才有后面一个配置项，在腐化后再检查一次地图是否符合要求，符合就ctrl+左键把地图存入仓库
地图制作流程：地图是存放在背包里面进行制作的，背包为12*5的60个格子组成的，所以设置里面要增加背包坐标的相关设置，首格背包位置用于告诉脚本第一个要制作的地图在哪里，单格宽高用于在第一个地图制作完成后向下移动多少距离对第二格的地图进行制作，取通货的逻辑和如何把通货使用在地图上跟物品制作的逻辑一样，以点金模式为例，洗地图的流程是预处理地图、通货处理地图、检测地图基底词缀和外延词缀是否满足要求，满足的话判断是否使用瓦尔宝珠，不使用就判断是否存入仓库，使用就使用后再检查一次词缀是否满足要求，满足的话存入仓库，不满足就把地图留在原地进行下一个地图的操作

模块二
地图分为普通、魔法、稀有、传奇品质，其中的特殊状态为已腐化，已腐化的地图无法再进行操作，所以遇到这种地图就直接跳过。
地图阶级分类1-17阶级

地图页面不再区分普通地图和高级地图，所有地图都使用同一套六项基底配置：物品数量、物品稀有度、怪物群大小、更多地图、更多圣甲虫、更多通货。地图文本未出现的字段按0处理。用户根据实际地图自行选择点金石或混沌石模式，系统不会根据地图名称或阶级自动切换通货。
地图基底分为必选记得和挑选基底，必选为地图必须要符合的条件，挑选为地图选择其中的几项符合就行，如果必选和挑选同时勾选了同一个属性，数量高的那个生效

战斗辅助
自动喝药通过指定坐标的像素颜色判断生命或魔力是否不足。生命读取红色分量，魔力读取蓝色分量；两项都可独立配置按键序列、持续回复/立即回复模式和触发间隔。默认 Numpad7 开始、Numpad8 停止，并且仅在“流放之路”或“Path of Exile”窗口位于前台时发送按键。Numpad2 默认触发一键回城：向游戏发送配置的开启传送门键，等待指定时间后左键点击传送门坐标。
