> 这是由社区维护的非官方工具，与 Grinding Gear Games、腾讯或《流放之路》运营方无隶属关系。部分功能会产生鼠标、键盘自动化操作；使用者应自行了解并遵守游戏服务条款，并对使用结果负责。

赛季初想做一把趁手的武器，却要在背包里一张张点通货？刷图刷到手酸，图还要一张张洗？仓库堆满杂物，混沌配方捡到眼花？把这些重复劳动交给流放助手：一键做装、自动洗图、配方挂机、悬停查价，它通过识别游戏界面来操作游戏，每一步都有安全预检和全局紧急停止。装好、校准、设好快捷键，剩下的时间专心打图。

## 功能介绍

### 装备打造

**一键做装**：选中物品后按预设自动使用通货，三种模式覆盖不同需求。

- 单件制作：抓取物品坐标，按预设顺序点通货；
- 背包批量制作：扫描整个背包、勾选类别后批量做装，中途被打断可从断点恢复；
- 词缀制作：用改造石、混沌石、点金石冲目标词缀；另支持开孔、链接、染色。

**更多工艺**：古灵隐式、精华、花园工艺都有独立页签和专属预设，切换玩法不丢配置。

**做装模拟器**：不消耗任何通货，先在离线环境里试错。

- 支持通货、精华、化石、花园、野兽、势力等工艺方式；
- 底材与词缀数据来自内置快照，纯离线运行；
- 带历史记录和撤销/重做，模拟满意后再去游戏里实操。

### 刷图效率

**自动洗图**：按词缀条件自动点金、点混沌，不再一张张手点。

- 覆盖异界地图、航海海图、契约蓝图三类；
- 自定义词缀条件，可选崇高、瓦尔；
- 满足条件的图自动存入仓库。

**一键入库与取件**：打开仓库和背包时，游戏里自动浮出“入库”按钮。

- 背包物品安全入库，支持黑名单保护；
- 从仓库按网格统计自动取件，君锋镇按高亮取件。

**自动喝药**：识别生命球、魔力球颜色，自动补喝药剂，带频率保护与冷却。

**刷图计时**：浮窗记录每张地图的名称、传送门数量和用时，数据看板汇总刷图节奏与入库记录。

### 赚钱搬砖

**商城配方**：登录国服账号后自动组装七类商城配方，混沌配方自动分拣。

- 读取仓库快照，预览配方进度和预计奖励；
- 游戏内浮出按钮组：刷新、预览、选配方、一键取出。

**国服查价**：游戏里悬停物品按快捷键，立刻浮窗显示国服市集挂单。

- 基于国服官方交易数据构建查询；
- 支持词缀筛选、DC 汇率、在线状态和挂单时间过滤。

**浮士德改价**：市集挂单按价格分段批量降价，一键调整，输出改价结果表格。

### 玩法辅助

**剧情攻略浮窗**：半透明攻略浮在游戏窗口旁，快捷键上一步/下一步翻页，带章节计时。

- 内置可编辑的章节、步骤、技能攻略库；
- 支持多预设、拖动排序、进度标记。

**正则生成器**：结构化生成商城、地图、野兽三类搜索正则，复制即用。

- 可视化选择词缀、排除项、价格区间，自动校验 250 字符上限。

**海图摆放**：S30 赛季玩法，自动识别仓库中海图碎片的形状与词缀，计算连通摆放方案并自动放置，识别结果可人工修正。

**工具站导航**：常用 PoE 网站卡片首页，支持自定义站点和拖动排序。

### 为什么选它

- **安全第一**：每次自动化前检查游戏前台窗口、坐标、通货和模板预检，任何一项失败都会在产生输入之前停止并说明原因；全局紧急停止快捷键（默认 Alt+3）始终可用，不可清空。
- **游戏内浮窗**：运行进度、通货消耗、查价结果、攻略提示、计时信息直接浮在游戏旁，不用切窗口。
- **全键盘操作**：制作、洗图、查价、攻略翻页都有全局快捷键，可设置仅在游戏前台时生效。
- **模块按需启用**：侧边栏“更多”里自由添加或移除功能，用不到的可以不装。
- **内置帮助**：每个页面都有帮助抽屉，不用翻文档；配置出错时有“重新配置”引导。

## 下载与安装

1. 打开 [GitHub Releases](../../releases/latest)，下载 `PoE-CN-Helper-<版本>-win-x64-setup.exe`。
2. 可同时下载 `SHA256SUMS.txt`，在 PowerShell 中运行以下命令核对安装包：

   ```powershell
   Get-FileHash .\PoE-CN-Helper-<版本>-win-x64-setup.exe -Algorithm SHA256
   ```

3. 运行安装程序并选择安装目录。安装包已携带 Python 运行时和所需模块，无需另行安装 Node.js、Python 或 pip 包。
4. 首版安装包尚未进行代码签名，Windows SmartScreen 可能显示“Windows 已保护你的电脑”。确认文件来自本仓库 Release 且 SHA-256 一致后，可选择“更多信息”继续运行。
5. 当前版本始终请求管理员权限，以便注册全局快捷键并与管理员权限运行的游戏窗口交互。

本项目首版不包含应用内自动更新。请从 Releases 页面手动下载新版本并覆盖安装，用户配置会保存在独立的数据目录中。

## 首次运行

1. 启动国服《流放之路》，使用**窗口化**或**无边框窗口**模式。
2. 以管理员权限启动流放助手，确认首页的运行环境和游戏状态。
3. 在“设置”中完成账号、快捷键、仓库/背包区域和界面模板配置。
4. 根据当前显示器与 DPI 完成坐标、模板校准；多屏用户要确认游戏所在显示器。
5. 先设置并测试“停止”快捷键，再用少量物品试运行自动化。
6. 自动化运行时保持游戏窗口位于前台。前台窗口、坐标、通货或模板预检失败时，应用会在产生输入前停止并说明原因。

## 常见问题

### 脚本无法启动

先查看首页运行环境状态。正式安装包只使用随应用提供的 Python，不受电脑上其他 Python 环境影响。若内置运行时或模块异常，请重新下载安装包，并检查杀毒软件是否隔离了应用资源。

### DPI、多屏或点击位置错位

将游戏切换到窗口化或无边框窗口，确认 Windows 显示缩放，然后重新校准模板和操作区域。移动游戏到另一台显示器或修改缩放比例后也应重新校准。独占全屏不在支持范围内。

### 杀毒软件或 SmartScreen 拦截

这是未签名安装包常见的信誉提示，并不等同于文件一定安全。请只从本仓库 Releases 下载，核对 `SHA256SUMS.txt` 与 GitHub 构建来源证明；若安全软件删除了内置 Python 文件，请恢复或重新安装后再次验证。

### 全局快捷键无效

确认流放助手和游戏使用相同权限级别，快捷键未被其他软件占用，并在设置页重新录入。任何时候都应保留一个容易触发的“停止”快捷键。

### 自动化提示游戏未处于前台

这是安全保护。点击游戏窗口使其处于前台，确保没有启动器、聊天窗口或系统弹窗遮挡，再重新开始。

### 配置保存在哪里

配置和缓存默认保存在 `%APPDATA%\流放助手`。覆盖安装不会主动删除该目录；卸载或反馈问题前可先备份。不要公开包含账号会话信息的原始配置文件。

### 如何导出诊断

在首页可直接选择“导出当前诊断”，也可先开始最长 15 分钟的诊断会话，选择受影响模块与问题现象后复现一次再结束导出。schema v3 单个 JSON 包含应用与运行时版本、安全设备兼容性信息、显示器布局、DPI、白名单健康状态、排序后的诊断结论，以及最近 7 天（最多 200 条）的结构化失败/恢复事件。

设备信息仅包含 Windows 版本与构建号、CPU 型号与逻辑核心数、内存总量、GPU 型号与驱动版本。诊断不会记录主机名、硬件序列号、MAC 地址、设备 GUID、原始日志、配置、物品、仓库、账号、网址或请求响应。

诊断只在你主动确认保存位置后写入本地，不会自动上传。生成阶段会遮蔽 POESESSID、Cookie、Authorization/Bearer、账号与邮箱、IP 地址、完整本地路径和 UNC 路径；提交前仍建议用文本编辑器快速检查内容。

## 数据与隐私

- 账号会话信息仅保存在本机 Electron 独立 Session 或本地配置中，不会写入诊断文件；诊断事件也不会保存原始错误文本。
- 应用只在执行对应功能时访问国服登录、交易接口和必要的数据源。
- 做装、物品名称、美术和物品占位快照包含来自 PoEDB、RePoE 与 Path of Exile 的公开数据；物品占位目录仅在开发期联网刷新，应用运行时只读取内置快照与仓库 API 已返回的尺寸。具体归属见 [第三方软件与来源说明](THIRD_PARTY_NOTICES.md)。
- 请勿在 Issue、截图或日志中提交 POESESSID、Cookie、账号信息、完整用户路径或个人仓库内容。
