# S30 数据依赖审计

当前发布基线：国服 S30“永火之咒”，POE1 3.29。统一值定义在 `shared/seasonBaseline.js`。

## 依赖清单

| 能力 | 当前数据来源 | 更新方式 | S30 结论 |
| --- | --- | --- | --- |
| 做装底材、词缀、工艺、古灵/腐化隐式、药剂参考 | POEDB 中文页面 | `npm run crafting:data:refresh` 抓取到 `crafting-raw/3.29` 后生成内置目录 | 必须刷新；3.29 大量改变法术武器词缀、长杖、深渊珠宝、工艺台和腐化隐式 |
| 剧情技能宝石目录 | POEDB `Skill_Gems` / `Support_Gems` | `npm run skills:data:refresh` | 必须刷新；3.29 新增誓约、魔能长杖、卓越辅助及多个变异宝石 |
| 查价传奇名称与图片 | POEDB `Unique_item` 与公开图片 | `npm run unique-items:data:refresh` | 必须刷新；3.29 新增 15 件传奇并修改多件现有传奇 |
| 国服查价物品与词缀 | 腾讯 `/api/trade/data/items`、`/api/trade/data/stats` | 应用启动时加载，失败回退内置 `catalog.json` | 两个公开目录仍返回有效 schema；内置目录版本需更新为 3.29 |
| 国服赛季和仓库页 | 腾讯 `/api/leagues` 与仓库接口 | 登录 Cookie 下运行时请求 | `/api/leagues` 未登录返回 401，不能作为无账号公开烟测；客户端保持官方 ID 透明传递 |
| Vendor 搜索正则 | 国服客户端中文物品文本 | 离线维护 + 语料回归测试 | 表达式语法未依赖赛季机制；更新版本元数据并回归现有语料 |

## 3.29 影响边界

- 直接由快照覆盖：新“珠光项链”底材、法术武器/长杖/深渊珠宝词缀变化、新工艺台选项、新增与移除的腐化隐式、新技能宝石及传奇。
- 需要固定规则调整：当前规则版本、污秽/瓦尔/孔位/催化剂/野兽规则版本；无常瓦尔宝珠在 3.29 的适用边界；S30 新通货仅在缺少完整物品状态模型时安全展示并禁用。
- 当前不实现：佣兵、海底航行、雾隐传奇转化、纪念币结果池。它们不是现有做装状态模型的一部分，不用近似逻辑伪装支持。
- 3.28 原始快照继续保留，只作为历史离线重建输入，不再作为当前运行基线。
