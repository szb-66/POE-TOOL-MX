# 流放助手 v1.0.5

## ✨ 新增

- 首页新增最长 15 分钟的诊断会话，可选择受影响模块和问题现象，在复现后结束并导出针对本次会话的结构化诊断。
- 诊断报告升级为 schema v3，新增 Windows 构建、CPU、内存、GPU 与驱动版本等安全的设备兼容性信息。
- 结构化诊断事件新增故障阶段、诊断会话关联和建议检查项，覆盖框选、截图、OCR、模板、坐标、网络与数据解析等失败原因。

## 🔧 优化

- 首页保留已结束、超时或异常中断的诊断会话，支持稍后导出或取消，并对诊断结论进行稳定排序。
- 背包入库、混沌配方、仓库取件、君锋镇、海图和系统 IPC 补充结构化诊断事件，提升跨模块问题定位能力。
- GitHub 与 CNB 同标签 Release 统一使用仓库内版本说明，CNB 发布前会验证说明文件和镜像资产完整性。

## 🐛 修复

- 修复多显示器或负坐标环境下框选窗口的屏幕归属与坐标换算问题，并补充安全回退与明确错误原因。
- 修复海图区域框选和页签坐标选择失败时错误状态未正确返回、持久化或记录的问题。
- 修复君锋镇预览、校准和取件异常缺少可诊断原因的问题。
