# 流放助手 v1.3.0

## 🔄 配置导入导出

- 设置 → 系统新增配置导入与导出，支持五类内容：物品制作预设、地图预设、剧情预设、剧情技能预设、工具站点，可逐项勾选、预览后导入。
- 导入只新增不覆盖：自动重新生成预设 ID 并处理重名，当前使用中的预设保持不变。
- 默认剥离地图预设中的本机网格坐标；旧配置包中不再支持的区块标记为"不支持"并跳过，不阻塞其余内容导入。

## 🧭 上下文配置引导

- 启用或开始游戏交互功能时，若缺少阻塞配置（坐标、模板等），一次性列出全部缺失项并引导补齐；补齐前不发送任何键鼠输入。
- 纯资料浏览、离线工具不再要求配置引导，应用启动也不会主动弹窗。

## 🗺️ 地图与海图洗练

- 新增崇高石补满：对稀有地图/海图先逐颗补满六条词缀再判断目标条件，之后可衔接瓦尔宝珠收尾与存仓。
- 崇高石逐颗确认，词缀无法可靠统计或读取失败时安全停止并保留恢复位置。

## 🧩 海图识别

- 新增海图校准向导：分页逐格校准，对照原图识别结果逐格修正。
- 支持复制碎片物品文本，自动识别形状与朝向填入棋盘。

## 🛠️ 制作浮窗

- 制作浮窗新增操作日志，物品与地图分离显示，各保留最近 100 条。

## 📦 更新体验

- 应用内更新弹窗与设置页"发布说明"改为富文本渲染（标题、列表），标题栏更新入口防重复点击。

## 🖥️ 稳定性

- 主窗口前台恢复逻辑加固，减少最小化/失焦后无法唤回的情况。
