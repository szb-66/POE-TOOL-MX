# 流放助手 v1.8.0

本次更新新增圣所路线规划，支持游戏内识别房间、奖励与效果并推荐下一房；同时优化制作词缀配置，修复查价和浮窗交互问题。

## 🏛️ 圣所路线规划

- 新增圣所模块，提供楼层规划、路线策略和识别校准三个页面。
- 支持识别房间连线、已走路径、当前位置、房间奖励及恩赐／痛苦，结合资源和策略偏好推荐路线。
- 游戏内显示当前房间与推荐下一房，支持通过悬浮按钮启动采集。
- 支持配置目标奖励、房间玩法偏好，以及可容忍和禁选痛苦，提供搜索选择与效果说明。
- 信息不足时明确显示待确认项，推荐路线仅延伸至已识别或手动确认的房间。
- 保存本轮进度与识别结果，支持重启后恢复查看。

## 📷 圣所识别与校准

- 支持通过游戏截图自动收集校准元素，多张截图累积核对并保存，保留高级手动校准。
- 支持查看识别截图、纠正效果或排除非效果文字；纠正规则可记忆、修改和删除。
- 完善暗色房间、首领出口、斜向路径、奖励提示框及不同资源栏布局的识别。
- 优化采集和识别流程，减少重复扫描；识别中断或部分失败时保留已完成结果。

## 🛠️ 制作词缀配置

- 必选、挑选词缀新增单条启停开关，临时关闭时保留原配置。
- 已关闭词缀不参与匹配、高亮及最低物等计算，挑选包含数随有效条件联动。
- 合并符合条件的跨来源重复词缀联想，保留来源与适用信息，明确区分数值示例。

## 🔎 查价修复

- 修复部分官方查询编号导致“有结果总数但无挂单”、无法跳转交易页的问题。
- 网页跳转失败时显示原因并保留结果，支持重试。
- 修复传奇装备背景描述和署名被误识别为未知词缀的问题。

## ⚡ 体验优化

- 减少启动阶段重复探测和不必要的依赖加载。
- 优化游戏界面标题检测响应。
- 改善控制浮窗拖动跟手性，修复圣所浮窗拖动时的干扰。
