# 流放助手 v1.0.4

## ✨ 新增

- 新增海图词缀识别：自动读取两页碎片词缀，并通过 OCR 识别大海图 12 段外边缘词缀。
- 新增海图词缀悬停展示和识别结果持久化，支持一键识别、单独识别边缘词缀以及完成识别后自动补充。
- 新增「当前海图已完成」操作：一键扣除已使用碎片、清理当前出口与执行状态，并直接使用剩余库存计算下一张海图。
- 新增航海九宫格「最高相对收益」自动策略，会结合当前格子和库存选择收益最高的可行方案。
- 新增做装词缀达标组合开关，可临时停用某个组合而不丢失已配置的词缀条件。

## 🔧 优化

- 完善国服查价词缀覆盖，强化破碎词缀、多行复合词缀、同文案多 ID 和歧义词缀的解析与选择。
- 统一背包入库、仓库取件和君锋镇奖励取件的转移流程，加入点击前判空、转移确认、失败重试和背包已满检测。
- 自动操作时序改为统一全局配置，并应用到战斗辅助、混沌配方取件等流程，运行中修改可即时生效。
- 商店混沌配方首页与浮窗实时同步，支持在浮窗中切换取件配方，取件后立即更新剩余数量。
- 生成版本化的精确物品占位目录，补充非装备类物品和同名异尺寸数据，提高仓库拾取与排布准确性。
- 统一一级页面的内容区、间距和滚动行为；设置页按「通用、自动操作、界面识别、覆盖层、系统」分类展示。
- 更新设置支持在 GitHub 与 CNB 之间选择正式更新源，并完善不可用时的明确错误提示。

## 🐛 修复

- 修复做装、地图和海图连续复制时，陈旧剪贴板内容或延迟返回的解析结果可能被误当作当前物品的问题。
- 修复海图词缀探测失败时无提示、识别过程覆盖用户剪贴板，以及完成海图后旧方案状态残留的问题。
- 修复地图或海图目标尚未达成时可能提前切换下一格，以及解析失败后继续执行的问题。
- 修复自动取件中 Ctrl 未正确生效、鼠标按键残留、重复点击或物品未转移仍继续的问题。
- 修复游戏内属性浮窗暂时遮挡标题时，入库、取件和君锋镇流程被误判为已离开游戏的问题。
- 修复海图边缘 OCR 在动态背景、浮窗动画和文字粘连情况下的识别不稳定，并允许单格或单段失败时继续保留其他有效结果。
