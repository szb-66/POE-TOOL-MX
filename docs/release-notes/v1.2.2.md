# 流放助手 v1.2.2

## 💬 反馈与通知

- 反馈收到新回复时提供应用内未读提醒，侧边栏与设置页反馈入口可见红点提示。
- 做装剪贴板复核加固：模板以哨兵区分"同文本未变化"，仅在解析分发失败重试时放行，避免误判与无效重跑。

## 📖 帮助体系调整

- 移除独立帮助中心页面，帮助主题下沉为各一级页面内的帮助抽屉，就近可查。
- 设置页新增"关于"标签页，集中展示版本信息。

## 🛠️ 制作与识别加固

- 解析器识别到未适配的词缀补丁格式时，在制作开始前终止并明确提示，不再盲目执行。
- 制作解析支持破碎、前后缀、古灵词缀格式。
- 背包网格改为框选后换算首格坐标，取点更直观。
- 模板文件名按安装版/开发版隔离，避免两套环境互相覆盖。

## ⚙️ 配置校验与默认值

- 传送门辅助等自动化配置新增启动校验，异常配置会被拦截并提示。
- 新增设置重置逻辑，按环境收敛默认值；查价浮窗与混沌配方控制浮窗默认位置改为按环境动态生成。

## 🖥️ 稳定性

- 主窗口主题热更新后重新应用，引导失败时由内联看门狗兜底提示。
- 屏幕区域选择器加固，提升识别与选择可靠性。
