# 流放助手 v1.2.1

## 🚀 启动与响应优化

- 做装数据改为首次进入相关功能或请求图片时按需加载，启动首页不再提前解析完整数据。
- 海图识别反馈浮窗改为首次识别时创建，避免启动阶段加载隐藏窗口和前端资源。
- 管理员权限、Python 运行环境与游戏 DPI 探测改为异步并发执行，并复用进行中的任务或短时缓存，减少主进程阻塞与重复探测。
- 开发服务器预构建 Element Plus 组件样式，降低首次启动时因依赖补构建触发整页重载的概率。

## ⌨️ 快捷键可靠性

- 应用启动恢复快捷键时，单个组合键冲突不再撤销其他已成功注册的快捷键。
- 首页与设置页会区分“部分快捷键注册失败”和“全部注册失败”，并保留冲突组合以便后续前台状态变化时重试。
- 用户在设置页保存新快捷键时继续保持事务式回滚，避免失败配置覆盖原有可用组合。

## 🛡️ 稳定性

- 做装数据首次加载失败时通过现有错误路径明确提示，同时保持首页和其他模块可用。
- 首页状态刷新复用启动阶段的系统探测结果，减少重复子进程与重复 DPI 检测带来的卡顿。
