# 流放助手 v1.9.2

本次更新新增圣所策略自动保存，修复批量制作浮窗提前关闭，并改善游戏进程探测、物品名称兼容和运行稳定性。

## 🏛️ 圣所体验

- 策略预设、奖励优先级、房间偏好及痛苦选择修改后自动保存，无需再点击保存按钮。
- 显示保存中、已保存和失败状态；保存失败时保留修改并支持重试，切换页签也不会丢失待保存内容。
- 游戏进程查询超时延长至 10 秒，减少系统繁忙时无法开始或重试的问题；查询失败会显示具体原因。
- 后台进程查询失败时保留有效区域记录，避免将临时探测失败误判为游戏退出。

## 🛠️ 批量制作

- 修复单件物品或单个制作阶段完成后，点击下一件物品导致制作浮窗提前关闭的问题。
- 浮窗以整个制作流程或批次的完成结果判断成功；手动停止、异常停止和批次续作时显示对应状态。

## 🔎 物品识别与查价

- 兼容词缀、价格等补丁在物品名称和底材中添加的方括号标记，避免标记干扰底材识别和查价。
- 保留正文中的词缀、数值和等阶信息，支持带补丁标记的装备及海图。

## 🩺 稳定性与安装包

- 修复界面完成首次加载后，GPU 子进程异常仍触发启动恢复或应用退出的问题；保留故障诊断记录。
- 补全安装包内界面标题识别的共享脚本依赖，修复相关识别脚本因缺失依赖无法运行的问题。
- 增加业务脚本分发和本地导入检查，在发布前发现遗漏的脚本依赖。
