# 流放助手 v1.6.0

本次更新新增剧情计时、自动刷图记录和独立入库统计，扩展契约、蓝图与裂隙之石制作支持，并优化词缀等级提示、正则筛选和窗口操作体验。

## ⏱️ 剧情计时

- 剧情流程支持开始、暂停、继续和重置计时，切换页面不影响计时状态。
- 支持游戏切到后台时自动暂停，返回游戏后继续。
- 重置时保存本次剧情预设和用时，最多保留最近 100 条记录。
- 重启助手后恢复已保存用时为暂停状态，不计入离线时间。

## 🗺️ 自动刷图记录

- 根据游戏日志自动追踪地图，记录刷图用时、死亡和传送门使用情况。
- 离开地图、断线或退出游戏时自动保存；返回同一地图实例时继续累计，避免重复统计。
- 切到游戏后台或加载区域时暂停计时，游戏前台无操作时仍正常计时。
- 提供历史战绩、筛选、分页和 CSV 导出，设置与战绩分别管理。
- 游戏内紧凑浮窗展示用时、地图名称和传送门，支持拖动并记住位置。
- 今日刷图、入库记录和游戏内浮窗默认关闭，可按需开启；保留已明确保存的开关选择。

## 📦 独立入库统计

- 开启刷图追踪和入库记录后，自动入库成功的物品独立统计，无需正在刷图。
- 按物品实际堆叠数量累计，支持今日数量、近期趋势和物品汇总。
- 部分成功后中止时，仅统计已成功入库的物品，避免重复累计。

## 🛠️ 制作功能扩展

- 新增契约与蓝图洗练配置，支持抢劫相关属性筛选和词缀联想。
- 异界地图制作支持裂隙之石类别，包括蠕动的邀请、咆哮的邀请等物品。
- 词缀组合展示所需最低物品等级，阶级选择同步显示物等要求。
- 普通、精华、花园及背包批量制作增加目标物等预检，避免对物等不足的物品继续消耗通货。
- 修复关闭普通制作词缀模块后，保留的词缀配置仍可能拦截插槽或古灵隐式制作的问题。

## 🔎 正则与查价

- 新增野兽正则，支持名称包括、排除、价格区间筛选和独立预设。
- 地图查价增加“更多地图、更多圣甲虫、更多通货”可选筛选条件，在交易目录支持时参与查询。

## 🖥️ 界面与稳定性

- 支持配置关闭主窗口时直接退出或收起到系统托盘。
- 优化制作完成后的浮窗关闭、窗口恢复和浮窗置顶行为。
- 修复配方预览浮窗显示及地图记录重复保存相关问题。
- 简化首页，仅保留检测与制造模块分组；剧情指引和模拟功能仍可从侧边栏进入。

## 开发版数据调整

- 使用过中间开发版刷图功能的用户请注意：经验统计已移除，含经验字段的旧地图记录不再载入。
- 旧地图记录中的入库数据不迁移到新的独立入库统计。
