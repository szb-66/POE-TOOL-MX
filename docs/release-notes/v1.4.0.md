# 流放助手 v1.4.0

本次更新重点加入批量物品制作、浮士德市集改价和地图词缀联想，同时进一步完善自动化安全机制、制作浮窗与新手引导。

## ✨ 批量物品制作

- 物品制作新增批量模式，可扫描角色原生背包，并以 12×5 网格直观展示识别到的物品。
- 支持按装备、武器、盾牌、首饰、珠宝、药剂等类别批量选择制作目标。
- 扫描时可智能跳过高置信度空格和已识别物品的占位格，缩短背包扫描时间。
- 开始制作前会逐件核对物品身份，全部通过后才会使用通货，避免背包内容变化导致误操作。
- 批量制作过程中实时显示当前目标、完成数量和剩余数量，并在背包预览中标记已完成物品。
- 中途出现读取或制作异常时，可在当前运行期间从失败物品继续，无需重新处理已经完成的目标。
- 批量模式默认关闭，原有固定坐标单件制作流程保持不变。

## 💰 浮士德市集改价

- 新增独立的“浮士德”页面，可对游戏中当前打开的浮士德市集页执行分段降价。
- 支持配置神圣石与混沌石比例，以及多组价格区间、降价百分比和输出通货。
- 价格分段支持拖拽排序和键盘调整，并会自动检查区间重叠、无效比例等配置问题。
- 新增市集网格校准和价格窗口识别测试，可在正式改价前确认识别环境。
- 完整复制价格输入框数值，正确处理四位数及以上价格，不依赖输入框中可能被截断的视觉数字。
- 改价提交前会再次核对价格和通货单位；单件识别失败时安全跳过，页面或前台环境失效时立即停止。
- 提供处理进度与逐件结果日志，并接入全局紧急停止。
- 只处理用户当前打开的市集页面，不会自动寻找 NPC、切换页面或在后台定时运行。

## 🗺️ 地图与海图词缀联想

- 异界地图和航海海图的黑白名单输入新增离线词缀联想。
- 可通过词缀文本、完整示例或标签搜索，并显示词缀类型和实际保存的稳定关键词。
- 联想关键词不包含可变数值，可稳定匹配同一词缀的不同数值档位。
- 异界地图候选覆盖低阶、中阶、高阶及 Uber 地图词缀。
- 航海海图只提供有效的可洗前后缀，自动排除传奇词缀和无效说明。
- 保留自由输入能力，旧版地图与海图预设无需迁移。

## 📦 永火接收舱一键入库

- 背包模块新增默认关闭的“永火接收舱一键入库”功能。
- 支持分别配置背包和永火接收舱识别模板，两个界面稳定识别后才允许执行入库。
- 复用现有安全入库的背包布局、排除格、黑名单、物品占位和转移确认机制。
- 永火接收舱与普通仓库入库可独立启停，互不影响。

## 🛠️ 制作与浮窗优化

- 物品制作浮窗现在会完整显示普通前缀、普通后缀和破碎词缀，并标注位置、等级和效果。
- 修正破碎词缀参与显式词缀数量计算时的增幅石判断。
- 批量制作异常时，浮窗会显示批次总数、已完成数、失败目标和具体原因，并提供继续制作或返回重新扫描。
- 优化制作启动状态同步，避免预检失败后仍显示为运行中。
- 扫描准备提示支持选择“不再显示”，并可通过重置设置恢复。

## 🧭 引导与使用体验

- 扩充各一级模块的新手帮助，集中说明准备条件、启动方式、安全停止和成功判定。
- 首页健康状态新增更明确的处理入口，可直接前往对应页面修正问题。
- 批量制作缺少背包网格、扫描结果或候选类别时，会一次列出相关问题并引导处理。
- 优化部分配置页面、导航和自动化状态提示。

## 🖥️ 稳定性与安全

- 加固自动化结束后的主窗口恢复，减少扫描或游戏交互完成后窗口未能正常显示的问题。
- 完善游戏前台检查、自动化互斥、全局紧急停止和键鼠状态释放。
- 配置、物品身份或识别结果不可信时会在使用通货前停止，降低误操作风险。
- 优化背包扫描、制作恢复和浮层状态之间的同步稳定性。
