# 流放助手 v1.0.2

## ✨ 新增

### 主动式循环喝药

- 战斗辅助新增主动循环：可配置多个按键条目，各自独立循环间隔，启动时立即触发一次。
- 与被动喝药、一键回城并行独立运行，互不影响。
- 首页战斗卡片可直接启停主动循环，并分别显示被动喝药与主动循环的运行状态。

### 快捷键前台门禁

- 新增“仅在游戏窗口前台时生效”开关（默认开启）：游戏未启动或切到其它窗口时，用户全局快捷键自动暂停注册，不再拦截普通按键（例如把回城设为 B 时，游戏外仍可正常输入 B）。
- 关闭开关即恢复无条件全局生效；前台监视异常时自动回退为全局注册，保证功能可用。
- 快捷键整组注册失败时回滚到上一组成功配置，避免部分快捷键生效造成状态不一致。

## 🔧 优化

### 海图（九宫格）识别与自动放置增强

- 海图识别支持“敏感 / 标准 / 严格”三档识别强度，切换后立即重新识别，自动放置复用同一档位。
- 新增网格对齐置信度提示，框选偏差较大时提醒重新框选，且不阻塞识别。
- 方向识别兼容不同机型图标布局，不再依赖固定像素坐标。
- 新增右键逆时针旋转角度修正，待确认碎片与已拼入方案来源格具有独立视觉标记。
- 自动放置优先使用手动修正后的来源格，旋转确认失败自动重试，失败重扫后保留人工修正结果。

- 自动化时序：统一“自动操作等待”悬停稳定时间（20–500ms，默认 80ms），旧延迟配置自动迁移；支持固定时序与自适应超时，制作、洗图、背包、取件等脚本同步适配。
- 主窗口启动加载块，避免启动白屏。

## 🐛 修复

- 修复 exe 启动时窗口等待时间过长的问题。
- 统一游戏物品复制快捷键为 Ctrl+C，移除高级复制回退逻辑。
- 修复查价浮窗内部重新查询时浮窗位置被重置的问题，仅外部捕获新物品时才重新定位。
