# 流放助手 v1.5.0

本次更新重点加入精华与花园自动制作、独立正则工作台和功能模块管理，同时统一窗口切换与加载反馈机制，进一步提升自动化安全性和操作体验。

## ✨ 精华与花园自动制作

- 物品制作拆分为“通用制作、精华制作、花园工艺”三个独立 Tab。
- 精华制作支持选择精华位置、配置词缀目标并自动循环制作。
- 花园工艺支持配置工艺按钮位置和词缀目标，自动执行工艺循环。
- 三种制作类型分别保存预设、物品位置和首次识别设置，互不干扰。
- 快捷键及首页入口会启动当前选中的制作类型。
- 配置导入导出新增精华和花园制作预设。

## 🧪 高阶点金石支持

- 通用物品制作、异界地图和航海海图的点金石模式新增“使用高阶点金石”选项。
- 高阶点金石使用独立坐标，并接入启动预检、消耗统计和制作浮窗。
- 该选项仅替换点金石模式中的普通点金操作，不影响混沌石模式。
- 旧预设默认关闭该功能，保持原有制作行为。

## 🔎 独立正则工作台

- 新增独立“正则”一级页面，商城正则与地图正则不再和配方取件混在同一页面。
- 商城正则改为按分类配置“包括”和“排除”，并扩充 S30 常用物品属性、词缀和装备类型。
- 新增地图数值门槛、地图状态、普通地图与 T17 词缀筛选。
- 新增地图批量购买价格筛选，支持价格区间及六种交易币种。
- 自动生成经过候选目录验证的安全短表达式，并提供摘要、250 字符提示、复制和独立预设。
- 商城配方改为独立“配方”页面；旧商城地址会自动跳转，不影响原有自动取件能力。

## 🧩 功能模块管理

- 侧边栏新增“更多功能”，可以添加或移除不常用的一级功能。
- 首页固定在顶部，“更多功能”和设置固定在底部，中间功能列表可独立滚动。
- 停用功能时会同步停止对应任务、监听、浮窗和专属快捷键。
- 重新添加功能后保留原有业务配置。
- 首页入口、旧书签及程序内部跳转均不能绕过已停用状态。
- 全局紧急停止不受模块停用影响，始终保持可用。

## ⏳ 长操作加载反馈

- 仓库取件、君锋镇取件、背包批量扫描和制作模拟器初始化等耗时操作新增统一准备提示。
- 根据当前操作目标，在助手窗口或游戏窗口显示对应加载状态。
- 专用业务浮层或真实进度出现后，准备提示会自动交接和消失。
- 多项操作并发时按优先级展示，短暂切换不会产生闪烁提示。

## 🖥️ 窗口切换与自动化安全

- 制作、地图、背包、配方、君锋镇、海图、浮士德、查价和屏幕选取统一使用同一套游戏窗口激活机制。
- 游戏窗口必须同时匹配窗口标题和客户端进程，避免将标题中带有游戏名称的浏览器误识别为游戏。
- 自动化启动前若无法确认游戏窗口，将在创建输入进程或截图前安全停止。
- 运行中失去游戏焦点仍会停止输入，不会主动抢回前台。
- 优化自动化结束后的助手主窗口恢复稳定性。

## 💰 浮士德改价识别优化

- 视觉模型漏判多格物品的部分格子时，会结合复制文本和物品尺寸进行局部确认。
- 相邻物品形成连续占位时，可通过剪贴板证据进行消歧。
- 只有物品身份与占位矩形唯一确认后才会打开价格窗口。
- 未知尺寸、越界、重叠或存在多解时仍会安全跳过，同一件物品最多处理一次。

## 🛠️ 制作界面优化

- 达标词缀组合支持单独展开和收起，组合较多时更容易浏览。
- 收起后仍保留启停、名称、复制和删除操作。
- 新增或复制的组合默认展开，折叠状态不会修改预设或词缀匹配逻辑。

## ⚠️ 快捷键调整

- 设置页集中展示目前支持的全局快捷键。
- 自动喝药和海图分析改为仅通过页面按钮启动。
- 配方开始、暂停/继续和专用停止快捷键已移除，停止操作统一使用全局紧急停止。
- 升级后会自动清理上述废弃快捷键字段，其他自定义快捷键保持不变。
- 一键回城快捷键可在设置页和回城模块中编辑同一个配置。
