# 流放助手 v1.7.0

本次更新新增亮色、深色与跟随系统主题，以及洗图条件可行性提示；完善特殊物品查价、海图碎片识别和地图名称，并优化浮士德改价速度与启动反馈。

## 🖥️ 主题与启动体验

- 设置中新增亮色、深色和跟随系统三种外观模式，重启后保留选择。
- 标题栏支持一键切换亮色与深色，跟随系统模式可随系统外观自动变化。

## 🗺️ 洗图条件提示

- 异界地图、航海海图和契约蓝图制作页面新增条件可行性提示。
- 配置数值目标与黑名单后，后台检查是否存在同时达标的合法词缀组合，区分黑名单冲突与目标本身超出理论范围。
- 提示按当前类别所有适用底子的理论上限计算，不含品质加成，仅供调整配置参考，不阻止洗图；数据不足时不会误报无解。

## 🔎 查价适配

- 完善j技能宝石的变体识别，修复角色需求等级影响宝石等级解析的问题，避免将技能说明当作装备词缀。
- 菌潮与菌潮灭绝地图查价保留特殊类型、区域和阶级；身份无法确认时给出提示。
- 先祖秘藏日志支持区域、派系及隐式词缀筛选，同类词缀合并数值，并保留各区域的原始来源说明。
- 完善赏金猎人工具、披风和胸针的底材与词缀识别，修正费用减免等负向词缀的查询边界。
- 退化传奇无法精准区分版本时，先提示并由用户选择是否仅按传奇名称进行宽泛查询。

## 💰 浮士德改价优化

- 同轮改价复用已识别的价格窗口布局，减少重复大区域识别；局部确认失败时重新完整识别。
- 减少读取旧价后的重复定位与选中操作，保留逐件价格读取和提交结果检查。
- 点击开始后立即显示准备状态，按实际流程展示激活游戏、加载、扫描和改价等阶段。
- 完善准备期间的重复启动拦截和紧急停止处理。

## 🧩 海图识别与校准

- 自动识别时，对未能取得词缀的碎片再尝试复制一次。
- 碎片形状与词缀分别保存识别结果，形状未识别成功时仍可保留已识别词缀。
- 校准沿用自动识别结果；缺少本轮对应格子的原图时提示重新识别，避免保存错误素材。

## 📍 地图名称统一

- 按编年史译名补齐并修正地图名称，减少直译和名称错配。
- 历史记录、筛选、统计及 CSV 导出统一使用更新后的名称，兼容已有记录。
