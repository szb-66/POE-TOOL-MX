# 流放助手 v1.9.0

本次更新新增 POB 导出与启动助手：国服角色可一键导出为 PoB 导入码，并在助手内安装、更新和启动中文 PoB。

## 📤 POB 导出

- 新增侧栏 POB 页面，支持选择本人或公开角色（论坛 ID）的赛季与角色。
- 自动获取装备、技能、天赋和珠宝，翻译并生成可直接粘贴到 PoeCharm 的构筑码。
- 提供一键复制与生成时间提示，未识别数据明确标注，失败原因反馈清晰。

## 🚀 POB 启动助手

- POB 页面新增启动卡片，可保存、选择或清空本地中文 PoB 目录。
- 支持从官方 GitHub 自动安装及更新 PoeCharm 与 PoB Portable，显示各阶段真实进度。
- 支持启动已有安装、更新前自动备份、失败自动回滚和中断后恢复。
- 下载与解压全程校验完整性，解压前检查归档路径与文件类型，保障本机安全。
