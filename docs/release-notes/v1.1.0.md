# 流放助手 v1.1.0

## ✨ 新增

- 新增应用内“问题反馈”：支持问题分类、附件、可选联系方式以及脱敏诊断信息，提交失败时保留现场和表单内容。
- 海图仓库新增固定格锁定：被锁定的碎片不会参与方案计算、自动放入或完成扣除。
- 海图识别新增本机校准素材：可保存人工修正结果，后续识别与自动放入会优先复用。
- 国服查价新增地图、航海海图、星团珠宝、佣兵凭证、经典势力及回忆束丝等物品支持。
- 查价新增综合属性、词缀来源、三态物品状态以及可选名称筛选。
- 设置页新增真实查价浮窗预览，可直接检查和调试筛选布局，不会读取游戏或发起网络请求。

## 🎨 界面升级

- 主窗口全面升级为统一深色主题，重新设计标题栏、侧栏、首页、设置页及主要业务页面。
- 制作、查价、剧情、背包、海图和混沌配方浮窗统一采用紧凑深色视觉。
- 页面布局升级为统一的 24 列响应式栅格，改善不同窗口尺寸下的排列与留白。
- 页面与设置中的标签页会记住最后选择，并在应用重启后恢复。
- 战斗辅助页面重新整理为战斗配置、被动喝药、主动喝药和一键回城四个独立模块。
- 君锋镇取件浮窗精简为单按钮操作，并显示当前处理进度。

## 🔍 国服查价优化

- 查价支持先解析物品、确认筛选条件后再手动搜索；也可开启“立即查价”保留原有快捷体验。
- 地图和海图可按阶级、区域等级、数量、稀有度、怪群大小、亡者硫磺和海图形状等条件查询。
- 佣兵凭证支持按 BD、主动技能及所属辅助技能分组查询。
- 星团珠宝支持天赋数量、珠宝槽数量及小天赋效果查询。
- 势力物品支持塑界者、裂界者、圣战者、救赎者、狩猎者和督军条件。
- 自动合并官方交易目录中语义相同的重复属性，减少无法理解的 ID 选择和错误零结果。
- 查价浮窗会记住用户调整后的尺寸；主动关闭后可安全恢复游戏焦点，方便连续查价。
- 优化状态过滤、属性网格、数字输入、下拉选择和结果提示布局。

## 🔧 自动化与操作优化

- 全局结束快捷键升级为统一紧急停止，可一次停止制作、地图、入库、取件、喝药、回城和海图等正在运行的自动化。
- 背包入库统一为满足条件后由浮窗手动启动，减少启用模块即自动操作的误解。
- 新增默认关闭的“传奇物品强制入库”，仅在普通转移确认失败后尝试一次强制转移。
- 额外背包列数缺失或异常时，默认值调整为 6 列。
- `Ctrl+Shift+R` 现在会安全清理运行资源并完整重启应用；普通刷新快捷键保持不变。

## ⬆️ 更新体验

- 应用启动后会在后台检查更新，不阻塞主窗口使用。
- 标题栏新增更新提示，可显示发现新版本、下载进度和等待安装状态。
- 更新下载完成后可直接静默安装并自动重启。
- 新版本首次启动时会显示一次对应版本说明。
- 发布元数据将同步携带版本说明，GitHub 与 CNB 更新源保持一致。

## 🔒 安全与隐私

- 问题反馈只有在用户明确勾选后才会附带脱敏诊断，不会自动上传本地诊断内容。
- 附件在渲染进程和主进程均执行数量、类型和容量校验。
- 自动化紧急停止采用并行、尽力停止策略，单个模块停止失败不会阻塞其他模块。

## 🐛 修复

- 修复传奇物品说明文字被错误识别为查价词缀的问题。
- 修复负向属性以错误数值方向提交、导致查不到结果的问题。
- 修复未鉴定传奇药剂、佣兵凭证价格标签及复杂查询提示异常。
- 修复查价浮窗关闭后游戏未恢复前台，导致下一次快捷键被安全门禁拒绝的问题。
- 修复部分重复官方交易属性产生歧义选择或错误零结果的问题。
- 修复海图识别结果无法复用人工修正、锁定碎片仍被消耗等问题。
- 修复开发版强制刷新后 Electron 主进程不能可靠重新启动的问题。
