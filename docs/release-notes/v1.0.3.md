# 流放助手 v1.0.3

## 🔧 优化

- 自动更新改用 CNB Release 国内镜像，改善国内网络环境下的版本检查和更新包下载稳定性。
- GitHub 正式发布完成后自动同步相同安装包、差分块映射、更新元数据、校验文件和第三方声明到 CNB。
- 主窗口先加载轻量首页外壳，再按需初始化完整运行时，减少启动阻塞和白屏时间。
- 页面预加载复用进行中的加载任务，启动阶段增加可重复执行的性能基准。

## 🐛 修复

- 完善主进程、渲染进程和首页就绪阶段的启动诊断，故障原因记录更准确。
- 拆分训练功能 IPC，正式版不再初始化仅开发环境使用的训练接口。

## 🔒 安全

- CNB 同步凭据仅由 GitHub Actions Secret 注入，不写入仓库、发布资产或客户端。
- CNB 镜像复用 GitHub 已验证产物，不进行第二次安装包构建；发布验收会比对两端安装包 SHA-256。
