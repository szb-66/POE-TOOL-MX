# 流放助手 v2.0.0

本次大版本更新正式引入国服 / 国际服双服模式与国际服汉化支持，新增按需提权自动化宿主、战斗辅助安全区自动暂停与统一启停，并以纯 NumPy 轻分类器重构取件识别，同时全面升级改造制作、查价与浮士德改价体验。

## 🌍 双服模式与国际服适配

- 新增国服 / 国际服双服模式，支持在设置中一键切换并独立保存两服账号、预设、坐标校准与自动化配置。
- 新增运行中游戏客户端与当前助手服务器模式不匹配检测，在标题栏显示服别徽标，不匹配时通过顶部提示条支持一键切换并重启。
- 补齐国际服英文数据、查价、制作、洗图、背包存取、浮士德、圣所与 PoB 适配，支持跨服词缀联想与双语展示。

## 🈳 国际服汉化与市集翻译

- 支持国际服受管简繁汉化及 Steam 客户端汉化安装、更新与一键恢复。
- 新增原生市集翻译与跨版本词缀匹配，修复合并词缀查询方向、物品前缀和跨服查价展示问题。

## 🛡️ 提权自动化宿主

- 主程序改为默认普通权限（`asInvoker`）启动，需要操作管理员权限游戏窗口时按需通过独立提权宿主执行输入与窗口激活。
- 提升窗口激活、查价复制与多模块自动化稳定性，并保留统一安全预检与全局紧急停止。

## ⚔️ 战斗辅助整合与安全区保护

- 整合被动喝药与主动循环为统一启停控制，支持运行中热开关各项辅助，全部关闭后自动停止。
- 新增「进入安全区自动暂停」开关：城镇、藏身处、圣域大厅、过图加载及断线时自动暂停，进入战斗区域与兽园自动恢复。
- 战斗脚本新增修饰键保护：按住 Alt、Ctrl 或 Win 键时自动暂缓触发且不报错，按住 Shift 不受拦截。

## 🛠️ 装备制作与词缀增强

- 改造石制作新增增幅可达性判定、富豪前瞻与未中回退，并采用低延迟 stdin/stdout 管道解析与批量制作优化。
- 新增星团珠宝核心天赋词缀目录与联想支持，完善词缀条件配置与制作完成浮窗展示。

## 🔎 查价与浮士德改价

- 新增秽生传奇查价支持，升级查价条件自动预选与跨服适配。
- 浮士德市集改价新增国际服 poe.ninja D/C 汇率支持，优化提交后局部快速确认关闭与常驻 Worker 预热复用。

## 📦 取件识别重构与体验优化

- 用纯 NumPy 双通道轻分类器重构仓库自动取件、君锋奖励取件、批量存仓空槽检测与浮士德占位检测，大幅降低推理延迟与体积。
- 将 S30 永火接收舱与 S30 海图统一收纳至「过期赛季」页面，精简存取与设置页面。
- 优化模板采集显示环境容差与缩放变化提示，支持一次性聚合展示多项配置缺项并引导修复。
