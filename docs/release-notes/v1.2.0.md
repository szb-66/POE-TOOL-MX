# 流放助手 v1.2.0

## ✨ 新增功能

- 问题反馈新增“我的反馈”，支持查看历史反馈、管理员回复和完整消息时间线，并可继续发送文字或附件。
- 制作浮窗新增“本次消耗”账单，按通货图标实时统计装备、地图和海图制作消耗。
- 海图识别期间新增游戏内进度提示，展示当前阶段、识别进度及成功、部分成功或失败结果。
- 海图识别失败时可在本地暂存游戏窗口、识别区域和网格分析证据；只有用户明确勾选诊断后才会随反馈提交。

## 🛡️ 自动化安全与恢复

- 装备、地图和海图读取失败时最多串行尝试三次，补读过程不会重复使用通货、切换格位或重复提交统计。
- 异常停止后可直接从制作浮窗安全重试；地图和海图会从失败格继续，并保留已经完成的统计。
- 装备制作重试和完成后重新开始时会重新读取最新预设与设置，不再沿用过期脚本。
- 制作运行期间隐藏不可用的浮窗关闭按钮，停止或完成后恢复操作入口。
- 制作浮窗会记住最后拖动位置；显示器布局变化导致位置失效时自动回到可见区域。

## 🔍 查价与界面优化

- 查价浮窗根据当前显示器工作区全高展示，统一使用单层滚动，并保留用户调整的宽度。
- 优化词缀属性卡片布局，强化名称筛选的选中状态；状态过滤在每次打开新物品时默认展开。
- 设置页跨页面入口会直接定位到对应分类，首页环境异常入口也会定位到相关设置。
- 快捷键因游戏不在前台而正常暂停时显示为“已就绪”，不再误报为异常。
- 支持清空非紧急停止类快捷键；清空后对应快捷键不再注册。
- 优化坐标输入、位置选择、表单间距及设置说明。
- 自定义背景历史仅在选择自定义背景时显示，切换模式不会删除已有记录。
- 移除制作、地图和海图页面中占用空间的“支持格式”说明面板，不影响实际解析能力。

## ⬆️ 更新体验

- 发现新版本时，下载前先展示目标版本、发布时间和完整更新说明。
- 下载完成后仍需用户确认才会进入安装，并继续显示真实下载进度。
- 更新安装改为可见进度窗口，安装完成后自动重新启动应用。

## 🔒 隐私与稳定性

- 诊断信息继续执行凭据、账号和本地路径脱敏。
- 海图截图证据不会自动上传；反馈未成功时保留以便重试，成功后自动清理。
- 完善反馈附件校验、异常停止信息和自动化统计一致性。
