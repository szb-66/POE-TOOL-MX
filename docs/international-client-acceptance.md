## 开发版启动

先在“设置 → 通用”切换到国际服并重启，确认当前为国际服。验收参数只选择测试模块，服务器模式仍取已保存的设置。

在项目目录使用管理员 PowerShell，正常退出旧助手开发实例及其开发服务，再运行：

```powershell
npm run electron:dev -- --verify-international-features=items,map,bag,stash-pickup,junfeng,combat,story
```

可缩小参数列表，仅开启需要验收的模块；`bag` 为自动存仓、`stash-pickup` 为仓库高亮取件、`junfeng` 为君锋镇奖励取件。参数只在未打包开发版生效，不写入持久功能状态。所有任务由用户手动开始；主进程仍拒绝任意 Python 执行、游戏内查价捕获及范围外模块。

## 用户操作与结果核对

游戏内操作由用户执行，制作使用用户指定物品与预算。先配置英文客户端进程、DPI、坐标、背包／仓库及奖励标题模板。请勿复用国服标题截图。

| 功能 | 要检查的行为 | 实测状态 |
|---|---|---|
| 制作 | 通用、精华、花园及批量；英文通货预检、首次达标不消耗、身份变化或未变化时停止、详细词缀与工艺判断 | 待用户实测 |
| 地图 | 普通／T17、海图、契约蓝图；Atlas Drops、Threads、黑白名单、六词补满和九词腐化结果 | 待用户实测 |
| 存仓 | 黑名单与保留格不入库、传奇策略、尺寸未知跳过、不重复操作多格物品、异常即停 | 待用户实测 |
| 仓库取件／君锋镇 | 英文标题、网格和 DPI 校准；预览后只取高亮，满背包或转移失败停止 | 待英文样本与用户实测 |
| 战斗 | 颜色采样、喝药阈值与冷却、循环按键、一键回城；切后台和紧急停止释放按键 | 待用户实测 |
| 剧情 | 英文技能搜索与自由编辑、浮窗上下步、计时后台暂停及双服预设隔离 | 待用户实测 |
| 正则 | 商店／地图／野兽复制到英文搜索框，核对正反例、包括排除和组合条件 | 待用户实测 |

每项还应覆盖切后台、紧急停止、失败恢复及切服。仅报告成功／失败与脱敏现象，不保存账号、会话、仓库完整响应或角色导入码。

取件模型发布沿用现有门槛：至少 3 个独立人工审计测试会话，与训练会话隔离；至少 20 个高亮格、200 个非高亮格和 1 个无高亮场景。阈值 0.995、误取为零、召回率至少 0.99、无高亮场景点击为零。未达标只保留候选，不替换活动模型。

## 维护数据

```powershell
node scripts/generateCraftingData.js --server international --patch 3.30.0 --live
node scripts/generateInternationalMapData.js --game-version 3.30.0
node scripts/generateSkillGemData.js --server international --game-version 3.30.0 --live

```

制作生成器不带 `--live` 时复用对应版本原始缓存；候选完整解析、版本哨兵及校验通过后替换国际服快照。失败不会更新活动数据或国服目录。当前国际服在线制作更新入口不加载中文来源，须使用上述显式维护入口。技能、占位目录的维护入口与来源清单见各生成脚本。

自动化脚本与物品通信文件也保存在国际服独立目录，主进程只使用本服内部路径，渲染端传入的路径不会被执行。国服沿用原临时通信路径。
