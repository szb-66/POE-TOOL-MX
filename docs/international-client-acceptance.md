# 国际服功能与离线验收

## 当前行为（2026-11-15）

国际服正常启动开放物品制作、地图制作、背包、仓库取件、君锋镇、战斗、剧情、快捷与手动查价、配方自动取件、圣所、浮士德和地图跟踪。ready 表示代码适配及离线验证，不表示游戏内实测；不需要开发版验收参数。

海图拼图、海图制作与做装模拟排除，已有预设保留。异界地图 Low／Mid／Top／Uber 统一走一个地图制作流程；契约、蓝图及实际制作词缀查询继续可用。用户未启用的任务不会因开放而启动，国际服启动不自动恢复存取任务。

本轮不增加游戏内操作验收步骤、不打包安装、不部署服务。原有前台、进程、DPI、模板、网格、预算、紧急停止及异常停止检查保留。

## 英文与受管汉化

- 英文无需汉化词库；简体、繁体回退和混合文本只使用当前已应用且本机验证有效的资源，不使用下载候选或国服词库猜身份。
- 制作保留原始文本，规范为英文身份、属性及词缀后判断。普通、精华、花园、古灵、插槽与批量流程共用识别；通货与精华预检使用可信名称集合。
- 底材、词缀、古灵、地图条件及剧情技能支持多语言搜索，目录选择保存稳定身份及英文模式；自由关键词保留原文并兼容可靠别名。
- 资源更新、恢复或失效时停止旧自动化、取消旧查询、刷新联想。未知关键身份、歧义及无法完整识别的条件不会静默放行。
- 四类地图统一规范为“异界地图”，不以旧地图阶级区分普通图或T17，也不因17阶拒绝点金。正则与联想使用完整统一目录；旧region预设兼容迁移，所选条件及稳定ID保留。
- 商店、地图及野兽正则使用当前词库。缺映射或超出长度限制时明确提示并阻止复制不完整结果。
- 商店词缀范围跟随国际服物品目录，使用受管简繁译文的正负例压缩；不展开怪物、技能及场景描述。指定移速和宝石等级保留数值约束，类别头按字段压缩，组合超过250字符仍需减少条件。
- 关闭快捷查价后仍支持手动查询；捕获浮窗和配方取件通过原有开关启用。

圣所奖励按稳定ClientStrings区分数量、通货及领取时机，支持简繁参数重排和单数量。下一楼层领取独立展示；当前路线无法确认兑现时保留计算缺口，不算作本层已经获得。
