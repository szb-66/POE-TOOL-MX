# 国服与国际服维护

## 当前实现

一套 Electron 应用，通过 `shared/serverMode.js` 的 `cn`／`international` 上下文选择服务器。设置 → 通用 → 游戏服务器提供“切换并重启”。默认国服；清理失败不保存新模式。现有国服存储键、会话分区和用户目录保持兼容。

游戏服务器区域仅保留模式选择和切换按钮，与后续设置区块保留独立间距。适配状态说明、会话接口验证和独立英文物品解析入口已移除；当前服未适配的模块在“更多”的“未适配功能”中置灰展示，不能添加或打开，切回支持的服务器后按原功能偏好恢复。

国际服使用独立持久会话和 `servers/international` 文件目录，业务 LocalStorage 使用 `server:international:` 前缀。通用主题、快捷键、外观和操作延迟共享；坐标、窗口配置、赛季、文字预设与业务状态分别保存。配置包升级为 v2，旧 v1 包按国服处理；旧助手会拒绝新格式，跨服只能导入工具站点，凭据不会进入配置包。

国际服正常开放除海图和做装模拟外的功能，支持英文与当前有效受管简繁汉化。制作、地图、存取、战斗、剧情、快捷查价、配方取件、圣所、浮士德和地图跟踪不再要求开发版验收参数；ready 表示离线适配，不表示游戏内实测。页面、IPC、快捷键与浮窗统一检查能力，任意 Python 执行仍不开放。完整范围、语言支持与已知边界见 [国际服离线验收](international-client-acceptance.md)。

## 数据更新

使用同一入口，维护者必须明确提供目标服的实际补丁版本，不根据国服推断国际服版本：

```powershell
node scripts/generateServerTradeCatalog.js --server cn --game-version <实际补丁版本>
node scripts/generateServerTradeCatalog.js --server international --game-version <实际补丁版本>
```

应用内国际服查价使用自己的已登录 Session 自动更新目录，缓存到该服用户数据目录中的 `trade-catalog.international.json`。官方交易目录未提供补丁号时使用明确的 `live` 标记，记录生成时间、来源与哈希；它仅供在线交易，不用于推断制作规则、识别素材或 PoB 版本。命令行也可显式选择 `--game-version live`；未登录的 Node 请求可能被官网拒绝，应使用应用内刷新。

默认分别输出现有 `catalog.json` 与 `catalog.international.json`。国际服输出禁止覆盖国服文件。候选包含服务器、语言、版本、来源和 SHA-256 清单，通过结构与覆盖校验后原子替换；网络或校验失败不更新活动数据。国际服不会以国服目录作为运行时兜底，也不使用国服神圣／混沌汇率。

相同版本的规则与稳定 ID 共用，翻译、交易目录与识别素材按服务器／语言选择。新增适配应修改输入或接口边界，不复制页面、store 和计算流程。英文物品结构字段在 `shared/itemTextLanguage.js` 归一化；身份和完整词缀原文保留，不猜译。

## 当前维护检查

- 数据版本、源哈希和独立活动目录必须校验，不根据在线交易目录推断制作或 PoB 规则。
- 运行专项回归、全量 npm test、构建和 OpenSpec 严格校验，开发版启动确认可交互。
- 不将游戏内操作、补充图像样本或训练模型作为本轮开放门槛；训练候选发布仍遵守原有独立评估规则。
- 国际服 PoB 已使用独立当前 3.30 数据，国服保留 3.29。使用支持 3.30 的 PoB 导入。
- 汉化映射来自当前有效已应用资源；更新、恢复或失效后停止旧任务并刷新缓存，不读取下载候选继续运行。

### 开发版手动检查

使用管理员 PowerShell 在项目目录运行 `npm run electron:dev`，界面和游戏内体验由用户验收：

1. 确认当前为国际服，并在账号与赛季中选择 `Covens`；查价页显示“官网实时快照”和 17,261 条词缀。点击“刷新官方目录”后没有旧的“尚未验证”提示；断网刷新失败时原目录仍可用。
2. 从英文游戏客户端复制完整物品文本，手动粘贴查价，核对挂单、复制私聊和官网链接。合法零结果也应正常显示；有超过 10 条结果时再检查“加载更多”。改变物品、账号或赛季后旧结果应清除。
3. 放入一些新赛季仓库物品后读取仓库，核对物品数量和配方结果；不启用自动取件。
4. 导出当前新赛季角色，确认页面展示 3.29 兼容性警告；在支持当前赛季的 PoB 中核对装备、技能和天赋。
5. 复制一条商店基础正则到英文客户端，核对匹配；尚未适配的游戏捕获、制作、圣所等功能继续保持关闭。

维护者后续可在关闭助手后复用现有登录会话运行：

```powershell
# 只读验证，报告只含计数、状态和错误码
.\node_modules\.bin\electron.cmd scripts/verifyServerReadOnly.js --league Covens

# 同时原子更新国际服缓存和仓库快照
.\node_modules\.bin\electron.cmd scripts/verifyServerReadOnly.js --league Covens --update-catalog
```

验证工具必须显式指定赛季，并拒绝在国服模式或已有助手实例运行时读取会话。它没有内置新赛季日期或自动切服逻辑。报告中的 `not-verified` 表示缺少实测样本，不能视为全部功能验收通过。
